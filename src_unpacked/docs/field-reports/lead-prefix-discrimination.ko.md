## 4. Miss 분석 (동일 → 미탐)

1. **시작 오프셋 미흡수**: 30~60초 리더가 타임라인 전체를 이동시킨다. 매처는 첫 kept 대응 고정 + 단조 강제만 수행하므로 시작 오프셋을 흡수하지 못하고 정렬이 붕괴한다. 동일 파이프라인·지오메트리에서도 99.9 → 6~53으로 붕괴 (L05 45초 리더 48.8, L03 60초 리더 6.1).
2. **증거 부족**: 숏폼은 본편 1~13초に対し 리더 30~60초라 파일의 80~95%가 공백이다. kept 중 내용이 1~2장에 불과하다.
3. 결론: 광고 삽입본 탐지율 손실 (recall gap). V4 삽입 정렬 / V6 부분-클립 범위.

## 5. 오탐 분석 (상이 → 중복)

1. **공통 블랙 앞부분의 동일 지문**: 모든 리더 파일 앞부분은 바이트 동일한 검은 화면이다. 기본 kept 선택(segmented, variance floor 없음)은 평탄 프레임을 보관하므로 서로 다른 영상이 동일한 블랙 해시를 공유한다. 공통 구간에서 강하게 정렬되면 본편 차이가 묻혀 50을 넘는다 (f02-f06 95.50).
2. **구조화의 완화**: 조밀 plan + 구조 윈도우 선택이 공유 평탄부를 덜 담아 오탐@87.5 16 → 0, f02-f06 95.5 → 70.7. 완전 제거는 P1 floor의 기본 승격이 필요하다.
3. 생산 임계(87.5)에서는 전부 0건 — 현 출하 기준 안전. 50 임계 운용 시 리더 공유쌍 주의.

## 10. 부록: Miss와 오탐은 왜 다른가

결과만 보면 "중복 판정에서 빠진다"는 점이 같아 보이지만, 중복 정리 제품에서의 피해 방향이 정반대다.

- **Miss (False Negative, 못 찾음)**: 동일 콘텐츠가 그룹에 안 들어간다. 파일은 그대로 있고 목록에도 있다. 피해는 수고(수동 정리)이며 **데이터는 안전**하다.
- **오탐 (False Positive, 잘못 묶음)**: 다른 콘텐츠가 중복 그룹으로 묶인다. 중복 정리의 목적이 삭제이므로, 사용자는 고유 파일을 "중복"으로 믿고 지울 수 있다. **고유 데이터 삭제 = 복구 불가**.

생산 임계 87.5가 정밀도 우선(보수적)인 이유다. 본 평가 측정치는 설계와 일치한다: @87.5 오탐 0건·miss 다수. 50 임계로 내리면 miss가 오탐으로 전환된다 (리더 공유쌍 오탐 ordered 52건). 한 줄 요약: **miss는 남는 쓰레기, 오탐은 잃는 원본**이다.
