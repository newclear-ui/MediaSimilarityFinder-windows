## 2. 새 판독 방식이 하는 일 (쉬운 설명)

기존 V3는 "영상 전체를 일정 간격으로 훑어 대표 장면을 뽑고, 두 영상을 시간 순서대로 맞대보는" 방식이다. 앞에 광고 30초가 붙으면 전체가 30초씩 밀려서 맞대기가 깨진다 — 이게 지금까지의 miss다.

TemporalAnchorV1은 이렇게 읽는다:

1. **오프닝 지문**: 원본 앞부분(텍스트·로고가 아닌 진짜 본편이 시작되는 곳) 3~10초를 외운다. 앞부분이 검은 화면이면 건너뛰고 진짜 장면부터 외운다.
2. **위치 찾기**: 후보 영상 처음부터 그 지문을 찾는다. 30초 지점에서 발견되면 "오프셋 = +30초". 순서가 뒤바뀌면 인정 안 하고, 한 장면만 같아도 인정 안 한다.
3. **앵커 확인**: 본편 시작 직후·5분·10분·15분·엔딩 직전, 각 지점 전후 3장면을 대조한다. 3장 중 2장 이상이 순서대로 맞아야 1개 앵커 인정. 평탄한(정보 없는) 화면은 증거로 안 친다.
4. **오프셋 일관성**: 여러 앵커의 오프셋이 같아야 한다(전부 +30초). 중간에 달라지면(예: 중간 광고 삽입) DUP로 확정하지 않고 기록만 남긴다.
5. **엔딩**: 마지막 9초 3장면을 본다. 엔딩만 맞거나 크레디트만 같다고 DUP 확정하지 않는다.
6. **판정**: 독립 앵커 2개 이상 + 오프셋 일치 = DUP. 증거 부족 = UNCERTAIN(모르겠다). 다르면 DIFF. 검은 화면·로고·인트로만으로는 절대 DUP 안 낸다.

## 3. 단위 테스트 13개 (전부 PASS, 합성 프레임)

| # | 테스트 | 의미 |
|---|---|---|
| 1 | 플랜 형태 | 탐색 시간표가 1초 간격으로 정렬·생성되는지 |
| 2 | 30초 리더 탐색 | 앞에 30초 검정을 붙인 영상에서 시작점 30초를 찾는지 + 반대 방향도 |
| 3 | 단일 프레임 거부 | 1장만 같아도 시작점으로 인정하지 않는지 |
| 4 | 역순 거부 | 순서를 뒤집으면 거부하는지 |
| 5 | 좌우반전 허용 | 뒤집힌 영상도 알아보는지 (상하반전은 미지원) |
| 6 | 700초+30초 리더 DUP | 오프셋 30, 앵커 2개 이상으로 DUP 판정하는지 |
| 7 | 다른 영상 DIFF | 강제 판정하지 않는지 |
| 8 | 전부 검정 UNCERTAIN | 억지로 DUP/DIFF 정하지 않는지 |
| 9 | 엔딩만 같으면 비확정 | 본편이 다르면 DUP 안 내는지 |
| 10 | 공통 검은 리더 비확정 | 앞부분이 같아도 본편이 다르면 DUP 안 내는지 |
| 11 | 중간 삽입 드리프트 | 오프셋이 바뀌면 기록하고 DUP 강제하지 않는지 |
| 12 | 짧은 영상 UNCERTAIN | 증거 부족 시 모른다고 하는지 |
| 13 | 실제 디코딩 경로 | 진짜 32x32 프레임에서 지문이 만들어지는지 |

각 핀은 실제 측정 실패에서 도출됐다 (예: 동점 정렬 불안정, 검은 오프닝 오출발, (0,0) 가설 누락).
