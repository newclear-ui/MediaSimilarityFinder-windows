# MediaSimilarityFinder v0.9.3.1 — 검색 벤치마크 로그(JSON)

> 번호 승격: 이 릴리스는 `v0.9.2.91`로 빌드·검증·푸시된 내용과 동일하며,
> 벤치마크를 중대 기능으로 격상하면서 새 마이너 라인 `0.9.3.x`로 번호만 승격했다.
> 이후 수정 빌드는 `0.9.3.2` → `0.9.3.3` 순으로 간다.

## 변경 필요성
- 검색 성능을 비교·개선하려면 단계별 소요 시간, 파일당 디코드/해시 비용,
  비디오 재생시간·용량당 스캔 시간, CPU/GPU 자원 활용의 실측이 필요했다.
- 완료·중단 시점에 사람이 읽는 요약과 기계가 파싱하는 원본을 함께 남겨야 했다.

## 기존 구조
- 단계별 타이머·자원 샘플러·결과 로그가 없었다. GPU 가동은 상태 표시용 플래그만 있었다.

## 변경 구조
- `src/benchmark.{h,cpp}` 신설. `BenchmarkRecorder`의 수집 항목:
  - 단계 시간: walk / revalidate / image / video / analyze.
  - 이미지별: 디코드 ms, 해시 ms, crop ms, GPU 여부, 바이트, 경로 (집계 + slowest 20).
  - 비디오별: 빌드 ms, 재생 초, 프레임, 바이트, 경로 (집계 + slowest 20).
  - GPU 배치 시간 합계.
  - 250ms 자원 샘플: 프로세스 CPU%·시스템 CPU%·작업집합 MB·GPU 플래그 (최대 5만점, 초과분 절단 표시).
- `MediaPipeline::imageBatch`에 레코더 인자를 추가해 워커 스레드에서 직접 기록한다
  (합계는 atomic, slowest는 mutex). `chrono::steady_clock` 기준이며 디코드(ms급) 대비 오버헤드는 무시 수준이다.
- 엔진 `scan()`은 시작 시 설정(root·거리·워커·배치·종류·CUDA 가용·버전 3종)을 기록하고
  샘플러를 시작한다. `finishScan` 람다가 모든 return 경로(실패·중단 포함)에서 확정하므로
  취소된 스캔도 `completed:false` 로그가 남는다. `ScanControl`에 `revalidateMs`/`buildVersion`을 추가했다.
- GPU 활용율은 기존 `gpuActive_` 원자 플래그의 듀티사이클로 산출한다:
  가동 샘플 비율(`gpuDutyPct`), 최장 연속 유휴(`gpuLongestIdleMs`), 원시 시계열
  (`[tMs, cpuProc, cpuSys, memMB, gpu]`). 외부 의존성·프로세스 스폰이 없다.
- CPU 사용률: `GetProcessTimes`(프로세스, 코어 수 정규화)와 `GetSystemTimes`(시스템 busy)를
  샘플마다 델타로 계산한다. 평균·최대·표준편차(널뛰기 지표)를 함께 기록한다.
- JSON은 의존성 없이 수작업 생성한다. 섹션 7개: `meta`(빌드·엔진·DB·시각·완료·루트),
  `config`(거리·워커·GPU 설정·CUDA 가용), `summary`(단계 시간·스캔/분석/무변경 수·filesPerSec),
  `images`(개수·바이트·GPU/CPU 분할·평균·gpuBatchMs·slowest),
  `videos`(개수·바이트·프레임·재생초·평균·secPerPlayMin·secPerGB·slowest),
  `resources`(샘플 수·절단 여부·CPU 통계·메모리 최대·GPU 듀티·유휴·series),
  `matches`(후보·쌍·그룹·절감율·GPU 이미지·폴백). 경로는 JSON 이스케이프한다.
- `ScanWorker::benchmarkReady(QString)` 신호 → `MainWindow::onBenchmark` 팝업.
  `QJsonDocument` 파싱 후 한/영 요약(상태·소요·파일·이미지·비디오·CPU·메모리·GPU·매치,
  slowest 각 5개)을 표시하고 JSON 저장 버튼을 제공한다(기본 `benchmark-<시각>.json`).
  완료·중단 모두 표시하고 하드 실패 시에는 표시하지 않는다.
- 버전 표기 통일 → 0.9.3.1, 테스트 59개(`benchmark_test`: JSON 키·집계·듀티 0·시계열 구조 검증).

## 해결된 상황
- 이미지: 개수·용량·GPU/CPU 해시 수·디코드/해시 평균·GPU 배치 시간·느린 파일 20.
- 비디오: 개수·재생초·프레임·평균 빌드·재생분당 초·GB당 초·느린 파일 20.
- 자원: CPU 평균/최대/표준편차·시스템 평균·메모리 최대·GPU 듀티%·최장 유휴+원시 시계열.
- 요약 팝업은 slowest 5개까지, JSON은 20개 전체를 담는다.
