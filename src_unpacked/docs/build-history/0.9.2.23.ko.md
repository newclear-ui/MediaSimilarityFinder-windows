# MediaSimilarityFinder 0.9.2.23

## 중요 변경

**영상 Temporal Crop-Aware 2차 분석의 디코드 비용을 줄이고 실시간 Monitor telemetry를 추가했다.**

### 변경 사항

- `VideoDecoder::framesAt()` 추가
  - 여러 timestamp를 한 번에 처리하는 API
  - FFmpeg 연결 빌드에서는 첫 timestamp로 한 번 seek한 뒤 순차 디코드
  - 기존 `frameAt()`은 새 API를 통해 동작하도록 통합
- `VideoFingerprintEngine::build()` 최적화
  - 32×32 normal/mirror fingerprint와 96×96 crop fingerprint를 timestamp 단위 반복 seek 대신 두 번의 순차 디코드 pass로 생성
- `buildCropAware()`도 단일 batch decode를 사용
- FFmpeg 미연결 환경의 기존 command-line fallback 동작 유지
- Monitor telemetry 추가
  - 마지막 분석 시간(ms)
  - 평균 분석 시간(ms)
  - 마지막 분석 종류(image/video)
- 기존 Load Protection 및 expensive-stage guard 정책은 그대로 유지

## 검증

- `msf_core` Release 빌드 성공
- 핵심 회귀 테스트 4/4 PASS:
  - video_crop_similarity_test
  - video_similarity_test
  - video_sampling_test
  - monitor_load_policy_test
- 전체 CTest는 빌드 환경의 장시간 전체 테스트 타깃 빌드가 시간 제한에 도달하여 완주하지 못했다. 따라서 이번 버전은 전체 34개 PASS라고 표기하지 않는다.

## 후속

0.9.2.24에서는 Monitor 안정성/예외 복구와 telemetry UI 연결을 우선 검토한다.
