# MediaSimilarityFinder v0.9.4.138 — Preview cell width follows the preview size (dynamic text fitting)

Baseline `0.9.4.137` -> this build `0.9.4.138`.
CPU CTest **125/125**, GPU CTest **126/126**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` unchanged (display-only).

## 1. Why the change was needed

- Field request: shrinking the preview (right file grid) still shows only three items per row. The cell width is pinned by the **longest text line** (`393.0 KB · 2048x1798`), so reducing the icon never narrows the cell. Text wider than the preview should shrink automatically.

## 2. Previous structure

- File cell text had three lines (name / size·resolution / similarity). Only the name was middle-elided to the icon width; the other two lines were full-length. `QStyledItemDelegate::sizeHint` used the widest line as the cell minimum width, freezing the column count. Two creation paths (`refreshFileViews` fill and `refreshFileMetaRow` metadata refresh) assembled the strings independently.

## 3. Changed structure

- New `MainWindow::fileGridItemText(path, ref, pct)` -- fits each line to the icon width (`textW = max(48, iconSize)`) with **priority fallbacks**:
  - name: `ElideMiddle` (extension kept, unchanged),
  - size·resolution: full -> **resolution only** -> middle-elided resolution,
  - similarity: full (e.g. `100% · identical content`) -> **`100%` only** -> middle-elided value.
- Both creation paths share the helper (deduplicated). The full-path tooltip stays. The list view (column table) is unchanged.
- Result: cell width follows the icon size, so smaller previews fit more items per row (e.g. 128 px 3 columns -> around 6-8 columns at 51-64 px, depending on pane width).

## 4. What was resolved

- Shrinking the preview now narrows the cells because name, size/resolution and similarity lines all fit the width.

- At very small sizes the text is mostly ellipsized (the full path is in the tooltip, the full information in the detail pane). Column count follows the cell width, checkbox and margins.
