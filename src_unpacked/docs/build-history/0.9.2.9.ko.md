# 0.9.2.9 — 빌드 로그

## 0.9.2.8 → 0.9.2.9

**중요 변경**

- Windows 실시간 감시를 polling 중심에서 `ReadDirectoryChangesW` 이벤트 기반으로 변경했습니다.
- 감시 이벤트가 짧은 시간에 여러 번 발생해도 동일 파일을 하나의 대기 항목으로 합칩니다.
- 비교 대상 인덱스는 모니터 세션 동안 미리 열어 두어 매 파일마다 SQLite 인덱스를 다시 여는 비용을 제거했습니다.
- 기존의 안정 파일 판정과 시스템 부하 보호 정책은 유지했습니다.
- Windows가 아닌 환경에서는 기존 polling을 fallback으로 유지합니다.
- 0.9.2.9 다음 버전은 **0.9.2.10**으로 진행합니다.
