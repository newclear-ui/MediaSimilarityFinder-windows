# MediaSimilarityFinder v0.9.2.76 — Console-Flash Removal + Spawn-Free Resolutions

## Need for change
Selecting a similar group flashed a terminal window with momentary lag. Root cause confirmed: `fileResolution()` ran `ffprobe` via `_popen` for every format Qt lacks plugins for (PNG etc.). Console-subsystem children pop a visible console on GUI apps, and each ~100ms spawn ran serially on the UI thread — repeated per file on group selection.

## Previous structure
- Resolution: QImageReader → ffprobe `_popen` on failure (flash + spawn). Cached, but first display spawned per file
- Two `video_decoder` CLI fallbacks shared the same `_popen` defect (unlinked-FFmpeg branch, unused in current builds)

## New structure
- **New `captureSilent`** (`src/proc_capture.h`, header-only): `CREATE_NO_WINDOW` + pipe capture. Binary-safe. popen elsewhere. Exit-code and empty-output failures
- **PNG/JPEG header parser** (`ImageDecoder::dimensionsFast`): direct IHDR read + SOF marker walk (baseline/progressive/extended, SOS stop, fully bounds-checked). 256KB cap. No decode, no spawn
- **`fileResolution` order**: QImageReader → header parser → ffprobe (windowless). Removes ~99% of spawns in photo libraries. Non-ASCII paths keep local 8-bit handling as before
- Both `video_decoder` fallbacks moved to the same helper (defect class removed)
- New `image_dim_test` (JPEG/PNG 160x90 + garbage/truncated rejection). Version strings unified → 0.9.2.76

## Resolved situation
- Console flash on group selection eliminated at the source. Resolutions come from cache hits or microsecond header parses
- ffprobe remains a one-time, windowless last resort

## Validation
- Core+GUI Release build: PASS, **CTest 55/55 PASS** (incl. new `image_dim_test`)
- `--version` 0.9.2.76, `--smoke` exit 0 (offscreen)
- CUDA algorithms unchanged (common layers only)

## Future impact
- Rare formats (TIFF/WebP) still cost one ffprobe each (windowless). Extend the header parser as needed
- Oversized Exif beyond the 256KB cap falls back to ffprobe (correct, just slower)
