# MediaSimilarityFinder v0.9.4.148 — Re-verify button missing from the toolbar layout

Baseline `0.9.4.147` → this build `0.9.4.148`.
CPU CTest **125/125**, GPU CTest **126/126**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` unchanged (display only).

## 1. Why the change was needed

- Field report: the "Re-verify" button overlapped behind the address path field.
- Cause: 0.9.4.134 created the button object (`reverifyBtn_`) but never added it to the toolbar (`toolBar_->addWidget` missing), so the button floated at toolbar position (0,0), hidden underneath the folder path field with only a sliver visible.
- Real users could not click the button, so the re-verify feature was unreachable from the GUI.

## 2. Previous structure

- Created in `buildToolbar()`: `reverifyBtn_ = new QPushButton(...)` with `setObjectName`/`setToolTip`/`connect` all wired.
- Layout missing: no `toolBar_->addWidget(reverifyBtn_)` call, so it belonged to no layout.
- The e2e (`backend_e2e_test` test1c) finds it via `findChild("reverifyBtn")` and clicks it programmatically, so it passed regardless of layout and masked the defect.

## 3. New structure

- One added line: `toolBar_->addWidget(reverifyBtn_)`. Order: Load > Re-verify > Scan (same as creation order and panel data flow).
- No other code changes (signal/slot and enable/disable wiring was already in place).

## 4. Resolved state

- The Re-verify button is laid out in the toolbar, visible and clickable.
- A toolbar-order assertion in `ui_settings_test` pins the layout (Load > Re-verify > Scan) against regression.

## 5. Verification

```text
CPU Release CTest 100% tests passed out of 125
GPU CTest 100% tests passed out of 126
GUI/Backend --version 0.9.4.148
```

- New assertion: `ui_settings_test` checks the `reverifyBtn` toolbar-layout membership and order. It fails before the fix and passes after it.
- Existing regressions: full suites pass, including backend_e2e Test 1c (re-verify done/counters).

## 6. Impact and limits

- Display-only change (verdicts/storage/protocol/engine/DB/schema/cache unchanged).
- Going forward, toolbar widgets must be created and `addWidget`-ed in the same block, with a layout-membership assertion alongside.
