# MediaSimilarityFinder 0.9.2.15

## 중요 변경
- 상주 실시간 모니터에 명시적 Pause/Resume 제어를 추가했다.
- `MediaMonitor::setPaused()`, `paused()` 및 `MonitorStatus.paused`를 추가했다.
- 일시정지 중에는 기존 대기 파일을 유지하고 분석을 수행하지 않는다.
- 시스템 트레이에서 `Pause/Resume analysis`로 즉시 제어할 수 있다.
- 상태 표시에서 `RUNNING / PAUSED / STOPPED`를 구분한다.
- Pause API 회귀 테스트를 추가했다.

## 안정성 원칙
사용자 작업 보호가 실시간 분석 속도보다 우선한다. 자동 부하 보호와 사용자의 수동 일시정지는 독립적으로 적용된다.
