# MediaSimilarityFinder 0.9.2.16

## Changes

- Added a dedicated GUI for real-time Monitor Settings.
- Added individual add/remove controls for watched folders.
- Added individual add/remove controls for comparison folders.
- Added a monitor-specific similarity threshold.
- Added stable-file delay configuration.
- Added fallback polling interval configuration.
- Added monitor GPU permission setting.
- Monitor startup now uses the persisted monitor settings.

## Design Intent

The previous semicolon-separated text entry was replaced with an actual folder-list editor to reduce configuration mistakes when monitoring multiple drives/folders. The monitor similarity threshold is now independent from the normal search tolerance slider.

## Verification

Core Release build and tests are run in the current development environment. Real Windows + Qt6 + NVIDIA CUDA GUI/runtime verification still requires the target Windows environment.
