# MediaSimilarityFinder v0.9.2.85 — 자가진단 경로 버그 수정(GetModuleFileNameW)

## 변경 필요성
- 0.9.2.83의 자가진단이 플러그인이 멀쩡한데도 실패 대화상자를 띄웠다. `--smoke`는 exit 0이었으나 무인자 실행은 exit 1로 끝났다.
- 임시 파일 로그로 확인한 결과, `QCoreApplication::applicationDirPath()`가 `QApplication` 생성 전 호출 시 빈 문자열을 반환했다. 검사 경로가 `/platforms/qwindows.dll`이 되어 항상 미발견 판정이 났다.

## 기존 구조
- `platformPluginPresent()`가 `QCoreApplication::applicationDirPath()`에 의존했다.

## 변경 구조
- Win32 `GetModuleFileNameW(nullptr, ...)`로 실행 파일 경로를 직접 구하고 `QFileInfo::absolutePath()`로 디렉터리를 확정한다. Qt 인스턴스 상태와 무관하게 항상 정확하다.
- 판정 로직·CUDA 알고리즘 변경 없음. 버전 표기 통일 → 0.9.2.85.

## 해결된 상황
- 무인자 실행(더블클릭 조건)이 10초 후에도 살아 있어 정상 구동함을 확인했다.
- 플러그인 누락 디렉터리에서는 기존대로 exit 1 가드 경로를 탄다.

## 검증
- Core+GUI Release 빌드: PASS, **CTest 56/56 PASS**
- 양성 검증: 무인자 실행 10초 생존(정상 구동), 패키지 `--smoke` exit 0
- `MediaSimilarityFinder-v0.9.2.85-Portable-Windows-x64.zip` 생성

## 향후 영향
- 시작 경로 판정은 Qt 초기화와 무관해졌으므로 실행 방식(cmd·더블클릭·바로 가기)에 따라 결과가 달라지지 않는다.
