# MediaSimilarityFinder v0.9.2.38 — Unified 3-Pane UI + Video/Ignore/Throughput

## Need for change
UI review settled on the unified 3-pane layout (mockup B), scrapped A/C, dropped CSV export, and required an Explorer-style view button plus keyboard marking in the results pane. Additionally selected: video durations/thumbnails, throughput display, and an ignore list on its own tab. Excluding ignored files from re-scans needed engine support.

## Previous structure
Single middle group list (combo view switcher), no duration in details, no video thumbnails, no throughput in the status bar, no ignore feature. `MediaFile` had no duration; `ScanControl` had no exclusion paths.

## New structure
- Engine: `duration` added to `MediaFile` (in-memory only, schema untouched). `ScanControl::ignoredPaths` added — excluded from analysis and results while DB rows are kept (unignore restores instantly on rescan). New `scan_ignore_test` → 37 tests total
- Middle pane: `QTabWidget` [Folders | Results: Images (N) | Results: Videos (M) | Ignored (K)]. Image/video tabs each own a table+grid pair; shared logic operates on the active pair
- Combo replaced by Explorer-style **View ▾** button + dropdown (7 modes, checked sync). Preview-pane item toggles the right pane
- **Duration** column in the video tab. Filmstrip/grid thumbnails decode the first frame (`VideoDecoder::frameAt`, 160 px, cached). Duration row in details; resolution via `VideoDecoder::info` probe
- Status bar/message: `NN% — file — MM:SS` elapsed display guarantees liveness
- Ignore: menu actions on files/groups, ignore tab (list + unignore/clear), persisted in `QSettings(ui/ignored)`, passed to the worker. Ignoring prunes groups immediately
- Folders tab: current folder + browse + scan-here + recent folders (max 8)
- CSV export removed (button, slot, menu)
- Mockup B v3 updated, A/C deleted

## Resolved situation
- Per-tab image/video split, view button, ignore tab, and throughput display all work
- Version strings unified → 0.9.2.38

## Future impact
- `MediaFile.duration` is in-memory only. Persisting it needs a schema migration (separate version)
- First-frame video decoding stays lazy + cached. Extend with background prefetch if needed
- `ScanControl::ignoredPaths` matches paths exactly against scanner-canonical paths
