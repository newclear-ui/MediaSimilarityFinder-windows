# MediaSimilarityFinder v0.9.2.80 — 기준 파일 동률 해소(해상도→용량)

## 변경 필요성
- 유사 그룹의 기준 파일은 `bestPct_`(그룹 내 최고 유사도) 내림차순으로 정해졌고, 동률일 때 순서는 정렬 구현에 의존해 사실상 임의였다.
- 사용자 건의(최고 해상도·최대 용량 기준)를 그대로 1순위로 올리면 업스케일 파일이 원본을 앞지르거나, 화질과 무관한 용량 차이가 대표 선택을 좌우할 수 있다.
- 따라서 유사도 1순위는 유지하고, 동률일 때만 해상도→용량으로 해소하는 절충안이 필요했다.

## 기존 구조
- `rebuildGroups()`가 `g.paths`를 `bestPct_` 내림차순으로만 정렬했고, 동률 구간에는 추가 규칙이 없었다.
- 기준 파일(`paths[0]`)은 그룹 대표 표시·100% 표식·대표 썸네일에 사용됐다.

## 변경 구조
- 1순위 유지: `bestPct_` 내림차순 정렬 그대로.
- 동률 구간(`bestPct_` 정확히 같은 연속 run)에만 2순위 해상도 픽셀 수 내림차순, 3순위 파일 크기 내림차순을 적용한다.
- `filePixels()`가 캐시된 `fileResolution()` 문자열(`WxH`)을 파싱해 픽셀 수를 구하고, 크기는 기존 `fileSizeCached()`를 재사용한다.
- 해상도/크기 조회는 동률 run 멤버에만 수행해 불필요한 디코더·ffprobe 호출을 피한다.
- 정렬 커널 `MainWindow::sortTiedReferencePaths()`를 정적 함수로 분리해 테스트 가능하게 했다.
- 판정 로직·CUDA 알고리즘 변경 없음. 버전 표기 통일 → 0.9.2.80.

## 해결된 상황
- 유사도가 다르면 기존과 완전히 동일하게 동작한다.
- 유사도가 동률이면 해상도가 큰 파일이 기준이 되고, 해상도까지 같으면 용량이 큰 파일이 기준이 된다.
- “디테일”은 정의된 지표가 없어 규칙에 넣지 않고 미리보기 확인 용도로 남긴다.

## 향후 영향
- 기준 파일 변경은 표시·선택 마킹 범위이며, 자동 삭제 기준은 바꾸지 않는다. 보존 후보 표시가 따로 필요하면 기준 파일과 분리해 추가하는 것을 권장한다.
- 동률 판정은 `bestPct_` double 정확 일치 기준이므로, 근소하게 다른 유사도에는 타이브레이커가 동작하지 않는다(의도된 동작).
