# MediaSimilarityFinder v0.9.2.63 — 디스크 썸네일 캐시 + fav 중복·파일명·해상도·0B 수정

## 변경 필요성
스크린샷 4건: (1) 즐겨찾기에 동일 폴더 2개 표시, (2) 가운데 그룹창이 파일 아이콘뿐(우측은 실사진 표시), (3) 우측 파일 리스트에서 긴/짧은 파일명 혼재 시 어긋남, (4) 상세 정보 해상도 "-".

## 기존 구조
- (2) 썸네일 메모리 캐시는 스캔 시작 시 초기화. 재검색 quick load 그룹은 실사진 없이 placeholder로 시작해 11k개를 예산으로 재디코딩(수십 분). 우측 3개는 예산 내 즉시 디코드라 실사진이 나오는 비대칭
- (1) 최근폴더 중복 제거가 정확 문자열 비교라 구분자/대소문자 변형이 따로 저장됨
- (3) 파일명 전체 표시 3줄 고정이라 긴 이름 줄바꿈이 행 높이 깸
- (4) `QImageReader::size()` 단일 경로. 플러그인 없는 포맷(PNG 등)은 "-" 확정

## 변경 구조
- **디스크 썸네일 캐시**(`thumbs` 테이블: path/PK·mtime·size·JPEG): 디코드 성공 시 192px JPEG 저장, 재검색 시 SQLite 인덱스 읽기로 즉시 표시(예산 미소모). mtime·size 불일치는 stale 처리 후 재디코드. 스캔 종료 시 인덱스 이탈분 정리(`pruneThumbs`). GUI 전용 2번 연결(WAL 동시성 준수, 실패 무시)
- **fav 정규화**: 저장 시 `cleanPath`+대소문자 무시 비교로 변형 중복 제거, 렌더 시 이중 방어
- **파일명 elide**: 우측 그리드 1줄을 중간 생략(전체 경로는 툴팁 유지). 줌 변경 시 즉시 재구성
- **해상도 폴백**: QImageReader 실패 시 ffprobe 헤더 프로브(디코드 없음, 실측 `64,48` 파싱 확인). 영구 캐시라 1회성. WIC `GetSize` 직접 호출은 유효 프레임에서 AV가 나 headless 확정 불가로 채택하지 않음(원인 미해결 기록으로 남김)
- **0 B 수정**: `fileSizeCached()`로 미인덱스 파일도 live stat 1회 후 캐시. 로드 그룹도 실크기 표시
- 버전 표기 통일 → 0.9.2.63

## 해결된 상황
- 재검색 시 이전 썸네일 즉시 표시. 첫 스캔도 점진 충전(기존 예산 유지)
- 즐겨찾기 1폴더 1항목. 긴 파일명 1줄+호버 전체 경로. 해상도 대부분 표시. 로드 그룹 크기 표시
