# 0.9.2.10 — Build Log

## 0.9.2.9 → 0.9.2.10

### IMPORTANT
This build strengthens **real-time synchronization of comparison indexes** for the resident monitor.

- Watch roots and comparison roots are handled by role.
- New/changed media in comparison roots updates the corresponding SQLite index without generating duplicate notifications.
- Removed/renamed comparison files are removed from the index.
- Added `MediaSearchEngine::upsertFingerprint()` and `removePath()` APIs for live index maintenance.
- When watch and comparison roots overlap, comparison media is not incorrectly treated as incoming media.
- Stable-file detection and workload-protection policies remain in place.

### Tests
- Full regression suite: **27/27 PASS**
- CPU fallback was used because the CUDA toolkit is unavailable in this build environment.
- Actual Windows `ReadDirectoryChangesW` and NVIDIA CUDA runtime validation still require a Windows/NVIDIA environment.
