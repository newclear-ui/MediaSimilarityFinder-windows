# MediaSimilarityFinder v0.9.4.56 — scanFinished hang diagnostics

기준선 `0.9.4.55` → 본 빌드 `0.9.4.56`.
CPU CTest **105/105**, GPU CTest **106/106**.
`kEngineVersion 1.5.0` / `kDatabaseVersion 1.0.4` / `kBenchmarkSchemaVersion 9` /
`kCacheFormatVersion 9` — 전부 불변. 테스트 수 불변.

## 1. 변경 필요성

Stop 후 "검색 리포트 작성중" 팝업이 닫히지 않는다는 보고가 반복됐다.
엔진은 Stop 후 즉시 반환이 실측으로 확인됐고(`finishedAt` = Stop 시점),
flush(≤1000 bound) / prune(단일 DELETE) / walker(cancel-aware bounded)도
코드로 확인됐다. 남는 미확인 구간은 GUI 스레드의 `scanFinished` 내부뿐인데,
headless에서는 관측이 불가하다.

## 2. 변경 구조

`scanFinished` 진입/종료에 `scanLog` 추적 2줄을 추가했다. 동작 변경 없음.

- 진입: `scanFinished enter: <msg 앞 80자>`
- 종료: `scanFinished exit` (팝업 close + idle 복귀 후)

다음 hang 발생 시 `msf_scan.log`로 구분된다.
- enter 없음 → worker 미반환 (엔진 측)
- enter 있고 exit 없음 → scanFinished 내부 stall (GUI 측, 위치 특정 가능)
- 둘 다 있음 → 팝업 close 이후 문제 (별도 경로)

## 3. 인덱스가 안 되는 이유 (코드 변경 없음, 설명)

첨부 로그는 fingerprint 단계 취소 실행이다
(`cancelledDuring=fingerprint`, 71초, 11GB, scanned=0).
walk/분석에 도달하기 전에 멈췄으므로 인덱싱 없음은 정상이다.

즉시 확인된 우회로: **[Detailed Logs] 체크 해제** → `telemetryEnabled=false` →
fingerprint 스킵 (0.9.4.51) → walk 즉시 시작. 체크박스 기본값은 ON이다.
fingerprint는 telemetry 전용이라 해제해도 스캔 동작에 영향이 없다.
