# MediaSimilarityFinder v0.9.2.89 — 우클릭 항목 선택(탐색기 보기 오동작 수정)

## 변경 필요성
- “탐색기에서 보기”가 새 창을 열면서도 엉뚱한 폴더를 열었다. `revealPath()` 자체는 검증됐으므로(`reveal_window_test` PASS), 잘못된 경로가 들어오는 쪽을 추적했다.
- 원인은 컨텍스트 메뉴였다. Qt는 우클릭으로 항목을 자동 선택하지 않는데, 파일·그룹 메뉴는 이전 선택을 그대로 사용했다. 우클릭한 파일이 아닌 다른 파일의 폴더가 열리는 것이 정상 동작처럼 보였다.

## 기존 구조
- 파일 그리드/리스트, 그룹 트리/그리드의 `customContextMenuRequested` 핸들러가 커서 아래 항목을 선택하지 않고 메뉴만 열었다.

## 변경 구조
- 4개 핸들러 모두 메뉴 표시 전에 커서 아래 항목을 먼저 선택한다. 이미 선택된 항목을 우클릭하면 다중 선택을 유지하고, 아니면 해당 항목만 선택한다. 그룹 패널은 current 항목을 지정해 `currentGroup_`이 우클릭 행을 가리키게 한다.
- 판정 로직·CUDA 알고리즘 변경 없음. 버전 표기 통일 → 0.9.2.89.

## 해결된 상황
- 우클릭한 파일·그룹에 대해 열기·탐색기 보기·삭제·이름 변경 등 모든 메뉴 동작이 일관되게 동작한다.
