# MediaSimilarityFinder v0.9.4.136 — Preview-size gauge: 1.0 reference, drag ratio, disabled in list view

Baseline `0.9.4.135` -> this build `0.9.4.136`.
CPU CTest **125/125**, GPU CTest **126/126**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` unchanged (verdicts unchanged; display-only).

## 1. Why the change was needed

- Field request for the right-pane preview-size gauge (slider): (1) show the **1.0 reference point visually** (e.g. a light gray vertical line), (2) show the **ratio while dragging** (0.5, 1.1, 1.5, ...), (3) in **list view** make the gauge **gray and non-draggable** (disabled).
- Previously the 1.0 position (default 128 px) was invisible, there was no current-scale readout while dragging, and the slider stayed active in list view, inviting ineffective input.

## 2. Previous structure

- `zoom_` was a plain `QSlider` (48..256, default 128, width 130); `zoomChanged(v)` set the file-grid icon size. `setViewMode(0/1)` only switched the stack (grid/list) and left the slider state untouched.

## 3. Changed structure

- **ZoomSlider** (QSlider subclass, gui/mainwindow.h/.cpp):
  - Draws a **light gray vertical line + small triangular tick** at `setReferenceValue(128)` (1.0x); dimmed when the widget is disabled.
  - While the handle is dragged (mousePress..mouseRelease) draws a **ratio bubble** above the handle (`value / 128`, one decimal: 0.5/1.1/1.5). The handle position is derived from the style groove/handle metrics and clamped to the widget. Minimum height 30 leaves room for the bubble.
  - Marker/bubble use the QStyle groove coordinates, so the positions stay consistent across styles.
- **List-view disable**: `setViewMode(i)` calls `zoom_->setEnabled(i == 0)` -- list view renders the gauge gray and non-interactive via Qt's disabled style; grid view re-enables it.
- New tooltip key `zoomTip` ("Preview size (1.0 = default)"), refreshed on language change. objectName `zoomSlider` (automation hook).

## 4. What was resolved

- The 1.0 reference is visible at a glance, the current scale is readable while dragging, and list view no longer offers a gauge that does nothing.

## 6. Impact and limitations

- Display-only (verdicts/storage/protocol/engine/DB/schema/cache unchanged).
- The bubble shows only during mouse dragging (keyboard/wheel change the value without it). The marker position is style-metric based (an approximation where styles differ) and is drawn dimmed while disabled in list view.
