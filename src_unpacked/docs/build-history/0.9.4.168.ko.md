# MediaSimilarityFinder v0.9.4.168 — V3 구간기반 개수 선택 production 기본값 + V2 차선 보존

기준선 `0.9.4.167` → 본 빌드 `0.9.4.168`.

## 1. 변경 필요성

- 사용자 결정: V3 채택, V2 차선 보존. 현장 근거 1 (50쌍 재인코딩/좌우반전)에서 V3는 평탄 구간 보장 효과를 기존 방식과 상동 거래없이 얻었다 (49/50 동일 개수, 1개 +1프레임). 중복 누락 방지에 직결된 유일한 변경이다.

## 2. 기존 구조

- 기본값은 legacy 분산 순위 경로, `MSF_VIDEO_KEPT=segmented`에서만 V3 실행. 캐시 정체성은 `policyId()`만으로 구분했다.

## 3. 변경 구조

- 기본값 뒤집힘: 항상 segmented, `MSF_VIDEO_KEPT=legacy`에서만 legacy (롤백).
- 선택방식이 캐시 식별자에 합류 (`+seg`/`+var` 접미사): 반대 방식 행은 miss로 1회 재구축한다 (0.9.4.156 policy 컬럼과 동일 메커니즘, 포맷/엔진 범프 없음).
- V2 프로브 코드 변경 없음. `video_structure.h`에 차선 보존 사유 + 재사용 진입점을 명시했다 (구조-윈도우 개수 선택의 소비자가 될 유일한 관찰자이며, 삭제하면 재작성이 필요하다).
- 테스트: `video_kept_select_test`가 기본값(segmented 평탄 보장) + legacy 롤백을 고정한다. `video_cache_test`가 legacy `v1` 행 miss + `v1+seg` 행 hit을 고정한다 (전환시 1회 재구축 핀).

## 4. 해결된 상황

- 기본 경로가 시간축 커버리지를 보장한다. legacy가 필요하면 환경 변수로 복원 가능하다.
