## 1. 변경 필요성

- 외부 리뷰 합성 결과: (a) 현 커버리지가 SSIM 이전 Hamming 셀을 세어 점수 근거와 어긋난다, (b) 커버리지 전용 게이트가 판정 임계값과 결합되어 있어 올릴 수 없다, (c) clip05 0점의 확정 진단이 없다, (d) BUILD_STATUS·V-brief·아키텍처 문서가 구현 상태를 따라가지 못한다, (e) safe_remove.ps1이 C: 휴지통 경로를 고정해 D:에서 오동작한다.
- 기록 정정: 현장 근거 2의 "Hamming 게이트(유사도 60)"는 오기다. 하네스는 구조체 기본값 50을 썼고, 제품 기본값은 distance 8 → 임계값 87.5다. 60이라는 숫자는 어떤 경로에도 없다.

## 2. 기존 구조

- 커버리지는 첫 번째 루프의 Hamming `sim>=threshold`에서 행/열을 표시했다. 실제 점수는 두 번째 루프의 블렌드(`0.4*ham+0.6*ssim`) 뒤에 정해졌다.
- 한 개의 `threshold`가 셀 게이트·커버리지·최종 판정을 겸했다.

## 3. 변경 구조

- 커버리지 표시를 블렌드 이후로 이동: `sim>=covGate`인 셀에서만 `rowCovered/colCovered`를 올린다. 기존 Hamming 전용 값은 `rawCovShort/rawCovLong`으로 보존한다 (쌍별 비교용).
- `coverageGate` 분리: `max(threshold, coverageGate)`, `<0`이면 threshold. 커버리지에만 영향, 점수·판정 불변. strict 게이트 임계값(0.5/0.2/1)은 그대로, 기본 OFF 유지.
- `MSF_VIDEO_DUMP_MATRIX=<파일>`: 쌍별 tx/ty + ham/ssim/final 행렬 TSV 덤프. 미설정 시 완전 OFF (성능·동작 영향 0).
- `sim_perf` 신규 핀: 해시 동일·썸네일 무관 쌍에서 raw=1/1, verified=0/0, score=0 + coverageGate 하한 테스트.
- `safe_remove.ps1`: 휴지통 루트를 항목의 드라이브에서 유도 (`C:` 고정 제거). D: 테스트 디렉터리로 검증됨 (경고 없이 재활용 확인).
- 문서: BUILD_STATUS 19행(0.9.4.168 검증 요약의 0.9.4.167 잔재) 수정, V-brief 머리말 기준선 0.9.4.169 + 상태 분리(V3 채택/V4 진단·미검증/V2 차선), 아키텍처 문서 구현-상태 주석.

## 4. 해결된 상황

- 커버리지가 점수와 같은 근거를 쓴다. Negative 1225쌍: (thr=50) raw 0.998/0.990 → verified 0.0014/0.0013, fullCov 1149 → 0. Positive 100쌍: verified 0.998/0.998 유지. **점수는 패치 전후 소수점까지 동일** (POS/NEG/PART 전 구간).
- clip05 확정 진단: 덤프에서 ham 26~30셀 통과·ssim 최대 8~30·final 최대 37~47(통과 0). 시간 페널티가 아니라 SSIM이 전부 기각했다. 클립 kept(원본환산 17.6/22.6/27.6/32.3초)와 원본 kept(0/5/10/25/35초)가 어긋나 겹치는 kept 구간이 없고, 2.4~2.6초 떨어진 최근접 프레임은 장면이 달라 SSIM이 기각 — 샘플링-순간 불일치가 SSIM 기각으로 나타난 것이다. (b) 가설 기각 확정, (a) 방향 확정.
- 생산 임계값(87.5) 기준 보정 측정: POS pass87=94/100 (6쌍 미스, min 74.46), NEG 전부 0점·cov 0, PART pass50=1/11. 전영상 분리는 여전히 깨끗하나, 생산 임계값에서 합성 중복 6건을 놓친다.
