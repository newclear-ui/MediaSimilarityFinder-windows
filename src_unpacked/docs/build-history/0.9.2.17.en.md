# MediaSimilarityFinder 0.9.2.17

## IMPORTANT — Mirror-Aware Similarity

This version makes horizontally mirrored images and videos searchable as the same/similar media.

### Changes
- Images now produce both a normal pHash and a horizontal-mirror pHash.
- Video representative frames now store both normal and mirror fingerprints.
- CandidateIndex uses both fingerprint orientations for candidate discovery.
- Final image similarity uses the best of normal↔normal, normal↔mirror, mirror↔normal, and mirror↔mirror.
- Video similarity applies the same orientation-aware scoring at frame level.
- Existing SQLite indexes are automatically migrated with a `mirror_fingerprint` column.
- Existing video fingerprint caches are rebuilt when their payload does not match the new mirror-aware format.
- Resident real-time Monitor now generates, stores, and compares mirror fingerprints.

## Crop-Aware Foundation
This release does not yet perform the final crop-aware comparison. It extends the fingerprint/index model so the planned 4:3, 1:1, and 9:16 center-crop second-stage comparison can integrate cleanly with the existing CandidateIndex architecture.
