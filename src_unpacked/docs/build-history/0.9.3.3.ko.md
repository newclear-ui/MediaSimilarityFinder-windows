# MediaSimilarityFinder v0.9.3.3 — 그룹 미리보기 실시간 채움

## 변경 필요성
- 유사그룹 창에 처음 몇 그룹만 미리보기가 뜨고 이후 그룹은 파일 아이콘으로 남았다.
  원인은 3겹이었다.
  1. `fillPair`가 스캔 중 처음 60행에만 실썸네일을 시도하고 나머지는 강제 플레이스홀더로 굳혔다.
  2. 틱당 디코드 버짓(heavy 4 + shell 24)이어서 한 번의 fill로 다 채울 수 없는데,
     스캔 종료 후에는 fill이 한 번만 일어나 버짓 밖의 행이 영구히 플레이스홀더로 남았다.
  3. 스캔 중 일시적 디코드 실패(파일 사용 중 등)가 `thumbFail_`에 영구 기록돼
     이후 틱에서 재시도조차 안 됐다.

## 기존 구조
- 60행 캡 + 스캔 중 실패 영구 블랙리스트 + 종료 후 단일 fill.

## 변경 구조
- 60행 캡을 제거했다. 모든 행이 `fileThumb`를 거치고, 버짓 고갈 시 플레이스홀더를
  반환하되 실패로 캐시하지 않는다. 캐시 적중·디스크 썸네일은 버짓을 쓰지 않으므로
  틱이 지날수록 점진적으로 채워진다. fill당 작업량은 버짓이 상한을 걸어 응답성을 유지한다.
- 스캔 중 디코드 실패는 블랙리스트에 넣지 않고 다음 틱에 재시도한다(스캔 종료 후 실패만 기록).
- 버짓 고갈을 `thumbStarved_`로 추적한다. 유휴 상태(스캔 종료 후)에서 고갈이 있었으면
  틱당 1회씩 최대 12회까지 추적 fill을 돌려 마저 채운다. 새 매치가 오면 카운터가 리셋된다.
- 버전 표기 통일 → 0.9.3.3.

## 해결된 상황
- 스캔 중에도 매치 배치마다 새로 들어온 그룹부터 점진적으로 썸네일이 붙는다.
- 스캔 종료 후에도 남은 플레이스홀더가 유휴 틱에 자동으로 메워진다.
