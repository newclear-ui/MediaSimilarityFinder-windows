# Media Similarity Finder v3.7.0 — integrated core

## Included in v3.3–v3.7 bundle
- Recursive media scanner for common image/video extensions.
- Real image decoding on Windows through WIC; portable PGM decoder for core/Linux tests.
- Real video metadata/frame decoding through FFmpeg. When FFmpeg development libraries are available, the native libav path is used; otherwise the FFmpeg executable fallback is used for portable verification.
- Adaptive video sampling: <=10s 1s, <=1min 2s, <=5min 5s, <=30min 10s, <=1h 15s, >1h 30s.
- 64-bit perceptual-style average hash and Hamming similarity.
- Candidate index and similarity grouping pipeline.
- Persistent SQLite index with fingerprint/kind/duration fields.
- Incremental scanning: unchanged files reuse stored fingerprints; added/modified files are analyzed; deleted files are removed from the index.
- Integrated MediaSearchEngine API.
- 14 automated tests including actual FFmpeg-generated video decoding and incremental-search integration.

## Important scope note
This release is the integrated search-engine core, not the final Windows GUI release. Windows WIC and CUDA paths remain part of the source tree and are intended for the Windows build. Native NVDEC and more advanced visual embeddings can be added in later stages.
