# MediaSimilarityFinder v0.9.2.58 — 빈 그룹창 수정(placeholder 아이콘 폭풍)

## 변경 필요성
유사 그룹 11,084개가 데이터에는 존재(상태바·탭 카운트 정상)하는데 가운데 창이 완전히 비어 있었다(스크롤바만 표시). v0.9.2.56 디코드 예산이 만든 placeholder 경로가 범인이었다.

## 기존 구조
- 예산 초과 시 `fileThumb()`이 `return QFileIconProvider().icon(QFileInfo(path))` — 호출마다 Provider 생성 + 파일별 SHGetFileInfo(수 ms). 11k 그룹 × 매 600ms 틱 = 틱마다 수십 초 GUI 블로킹
- placeholder는 캐싱하지 않아(재시도 목적) 매 틱마다 전량 반복. 페인트 이벤트 기아로 빈 화면 + 스크롤바만 남음. 일시정지/중지 클릭도 처리 불가

## 변경 구조
- **확장자별 placeholder 캐시**(`phCache_`, 소문자 suffix 키): 11k 파일 → 10여 개 고유 아이콘으로 수렴. 예열 후 틱당 비용 0. 실패 폴백 2곳도 동일 경로로 통일(공유 Provider 사용)
- **공유 Provider**(`sharedIconProvider()` 함수-로컬 static): 호출당 생성 비용 제거. GUI 스레드 전용이라 안전
- `phCache_`는 파일과 무관해 스캔 시작 시 비우지 않음(다음 스캔 예열됨). 64개 가드만 유지
- 버전 표기 통일 → 0.9.2.58

## 해결된 상황
- 틱당 GUI 작업이 예산 디코드 4개 + 캐시 히트로 상한. 그룹 목록이 실제로 표시되고, 썸네일은 점진 충전. 일시정지·중지·창이동 정상
- 스크롤바만 있던 빈 창 문제 원천 해소
