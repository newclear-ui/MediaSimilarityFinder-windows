# MediaSimilarityFinder v0.9.2.73 — 감사 수용분 (SSIM 게이트·QuickLook·문서)

## 변경 필요성
v0.9.2.68 종합 감사에서 확정된 항목 중 수용 결정분: (1) L3 SSIM이 탈락 셀에도 실행되고 블렌드로 승격까지 시킴 (주석 "게이트"와 불일치 + CPU 낭비), (2) QuickLook 첫 실행 시 GUI 스레드 최대 2.5초 입력 제한, (3) 파이프 와일드카드 타 세션 오선택, (4) exe 경로 static 캐시 stale, (5) 문서 drift 4건 (llms 버전·테스트수, STRUCTURE 테스트수, README.ko/en 중복행).

## 기존 구조
- SSIM 블렌드가 임계 Pre-check 없이 전 셀 실행. 탈락 셀도 `0.4H+0.6S` 후 판정
- QuickLook 미실행 시 `msleep` 루프로 대기. 파이프 첫 매치 선택. 빈 경로 영구 캐시

## 변경 구조
- **SSIM 명시 게이트**: `sim>=threshold` 셀만 SSIM 실행. 탈락 셀은 기존 거부식 그대로 (비용 0, 승격 불가). 통과 셀 블렌드는 기존 유지
- **QuickLook 비동기**: 실행 후 `QTimer::singleShot` 100ms 폴링(최대 25회) + `quickLookStarting` 상태 표시. GUI 블로킹 제거
- **SID 대조**: 현 사용자 SID 파이프와 정확 매치, 불가 시에만 첫 매치 폴백
- **재탐색**: 비어있거나 stale한 캐시는 매번 재탐색 (메뉴 open 빈도라 비용 무의미)
- **문서**: llms 0.9.2.72/54테스트, STRUCTURE 54, README.ko/en 중복 0.9.2.65행 삭제
- 버전 표기 통일 → 0.9.2.73

## 해결된 상황
- SSIM 비용이 통과 셀만으로 축소. 탈락 셀 승격 경로 제거 (Grok 게이트 설계와 일치)
- QuickLook 첫 실행도 입력 정상. 다중 세션 오선택·재시작 요구 해소
