# MediaSimilarityFinder 0.9.2.21

## IMPORTANT CHANGE
Added a **selective second-stage temporal crop-aware comparison foundation for video**.

### Changes
- The existing fast video stage remains normal + mirror fingerprinting.
- Crop fingerprints are generated only when the second stage is explicitly requested, reusing the existing sample timestamps.
- Each sampled frame produces centered 4:3, 1:1, and 9:16 crops plus mirrored variants.
- Temporal alignment is preserved while evaluating crop↔full, full↔crop, and same-ratio crop↔crop matches.
- Direct cross-ratio crop↔crop comparisons are intentionally blocked.
- The existing persistent video fingerprint cache fast path is unchanged.
- The real-time Monitor load gate is not bypassed; expensive crop analysis is not automatically run continuously.

### Design impact
The system keeps the intended **normal/mirror first-stage candidate → selective temporal crop second-stage analysis** architecture instead of reanalyzing every video at every aspect ratio. This preserves the foreground-workload protection priority.

### Tests
- Full CTest: **34/34 PASS**
- New `video_crop_similarity_test` passes.
- Existing video similarity, real video decode, mirror, crop, monitor, and GPU policy regression tests all pass.
