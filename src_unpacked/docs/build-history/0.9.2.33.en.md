# 0.9.2.33-test — Windows CPU Test Interim (Not a Baseline)

## Need for change
While preserving the official v0.9.2.32 baseline, the CPU build/tests had to be exercised on the real Windows + Visual Studio 18 2026 + MSVC environment to collect platform-common compatibility issues.

## Previous structure
Only the Linux-validated 0.9.2.32 baseline existed, with no recorded Windows MSVC/Qt/FFmpeg/SQLite runtime validation.

## New structure
Configured/built/tested the Windows CPU configuration (`MSF_ENABLE_CUDA=OFF`) and collected shared-layer issues (SQLite target, `NOMINMAX`/WIC/Qt, `M_PI`, FFmpeg 9 API, UTF-8 filesystem, `ReadDirectoryChangesW`, `std::popcount`, `SystemLoad` collision). No CUDA algorithm/kernel was changed.

## Resolved situation
The collected shared fixes were applied to the next validation line, v0.9.2.34. Version 0.9.2.33 itself is not kept as a separate release baseline.

## Validation
Build/tests were run in the Windows CPU environment. See `0.9.2.34.en.md` for the full shared-fix details.

## Future impact
Subsequent Windows validation uses 0.9.2.34 as the baseline in CPU→CUDA order. The official preserved baseline remains 0.9.2.32.
