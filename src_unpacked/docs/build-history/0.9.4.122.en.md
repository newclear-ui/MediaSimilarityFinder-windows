# MediaSimilarityFinder v0.9.4.122 — External I/O off the right-click path (QuickLook probe negative cache)

Baseline `0.9.4.121` -> this build `0.9.4.122`.
CPU CTest **124/124**, GPU CTest **125/125**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` unchanged.

## 1. Why it was needed

Field report: right-clicking the right-hand file list (after selecting a group in the middle) pauses the whole system briefly (frozen mouse + browser playback continuing + no CPU hog). A full trace of the menu path showed:

- The only external call at menu construction is `quickLookTarget()` (pipe enumeration + exe existence checks + Uninstall-registry enumeration). While QuickLook is absent, the **registry walk re-ran on every right-click** (single-to-tens of ms, synchronous on the GUI thread).
- The codebase has no system-wide input-blocking means (`BlockInput`/grabs/hooks/broadcasts: none) and the menu path does zero GPU work, so the menu code has no mechanism to stop the OS cursor. The symptom signature matches a GPU TDR or a third-party global-hook deadlock; the click is trigger context, not the cause.
- Even so, removing synchronous external I/O from the click path takes the product fully out of suspicion and removes the per-click registry cost. The precondition ("as long as QuickLook keeps working") was user-confirmed.

## 2. Previous structure

`quickLookTarget()` = live pipe check -> `quickLookExePath()` (cache hit / five well-known-path checks / registry walk). A negative result was never cached, so the full probe repeated on every click while QuickLook was absent.

## 3. New structure

- **120 s negative cache** (`lastRegProbeMs`) on the Uninstall-registry walk only. The five path checks and cache hits still run on every call, and the pipe check is untouched, so a QuickLook start/stop still reflects immediately. A mid-session install is discovered with at most 120 s delay.
- The send path (`previewSelectedQuickLook` -> `quickLookSendMessage`) and the poll loop are unchanged. QuickLook behavior (pipe/launch/poll) is semantically identical.

## 4. What is fixed

- The registry walk now runs at most once per 120 s per click path. Pipe/exe immediacy is preserved.
- The expensive external I/O is gone from menu construction, excluding the product side from the system-freeze suspects.
