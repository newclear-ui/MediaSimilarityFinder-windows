# 0.9.2.9 — Build Log

## 0.9.2.8 → 0.9.2.9

**IMPORTANT**

- Windows real-time watching now uses `ReadDirectoryChangesW` events instead of polling-first detection.
- Duplicate filesystem notifications are coalesced into a single pending path.
- Comparison indexes remain open for the lifetime of the monitor session, removing repeated SQLite index-open overhead.
- Stable-file detection and foreground workload protection remain active.
- Non-Windows builds retain polling as a fallback.
- The next version after 0.9.2.9 is **0.9.2.10**.
