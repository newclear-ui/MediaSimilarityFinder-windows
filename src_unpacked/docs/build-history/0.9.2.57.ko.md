# MediaSimilarityFinder v0.9.2.57 — 최종 분석단계 정지 불능 수정 + 최근폴더 즐겨찾기

## 변경 필요성
(1) 정지 버튼이 먹지 않았다. 워크/분석 단계는 취소를 폴링하지만, 수백만 후보쌍(+ 비디오 재디코드)을 도는 최종 `analyze()`에는 취소 체크가 전혀 없어, 이 단계 진입 후 정지·일시정지가 끝날 때까지 무응답이었다. 사용자는 강제종료할 수밖에 없었고, `saveMatches`가 스캔 종료 시점에 있어 그동안 스트리밍된 매치가 전부 유실됐다 — "정지 시 파악된 내용"과 "이전 검색 결과"가 표시되지 않은 원인이다. (2) 최근 검색한 폴더 2개를 좌측 즐겨찾기에서 바로 열 수 있게 해달라는 요구가 있었다.

## 기존 구조
- `ScanPipeline::analyze()`의 후보쌍 루프(`forEachCandidatePair` 경유)에 정지 조건 없음. `MediaSearchEngine::scan` 말미 호출이라 정지해도 반환까지 대기
- 체크포인트는 신규 25개+5초 조건이라 첫 매치 저장까지 지연. 강제종료 시 소량 결과 유실
- 즐겨찾기는 바탕화면/다운로드 등 고정 6종만 표시

## 변경 구조
- **`StopCheck` 협력 취소**: `analyze()` 3인자 오버로드 추가. 1024쌍마다 폴링(일시정지 인식 포함), 발동 시 내부에서 잡고 부분 통계 반환 — 예외는 엔진을 빠져나가지 않음. 엔진은 `control->cancel` 기존 채널로 보고서 incomplete 처리. 워크 스레드는 스트리밍된 부분 매치를 그대로 저장하고 `CANCELLED` 종료 → 가운데 창에 부분 그룹 표시
- **첫 매치 즉시 저장**: 개수 조건 제거, 매치 1개 이상 + 5초 경과면 체크포인트. 저장은 항상 전체 누적이라 wholesale DELETE와 충돌 없음
- **최근폴더 즐겨찾기(최대 2)**: 스캔 시작 시 `ui/recentFolders` 갱신(중복 제거·순서 유지), `refreshFolders()`가 존재하는 폴더만 전체 경로로 표시. 클릭 시 기존 `folderActivated` 경로로 폴더 설정. 목록 변경 시에만 트리 갱신
- `scan_pipeline_test`에 취소 케이스 추가(200 동일지문→부분 통계 반환 확인). 버전 표기 통일 → 0.9.2.57

## 해결된 상황
- 분석 막바지라도 정지·일시정지가 최대 수백 쌍 이내에 반응. 강제종료 불필요
- 정지해도 그때까지 찾은 동일 파일 쌍이 저장·표시되고, 다음 재검색에서 quick load로 이어짐
- 즐겨찾기에서 최근 2폴더 바로 선택 가능

## 향후 영향
- 폴링 간격 1024쌍은 튜닝 가능. 단일 초대형 비디오 1개 디코드 중에는 여전히 그 파일 완료까지 대기(디코더 중단 불가) — 잔여 리스크로 명시
- 체크포인트 5초 주기는 대용량 스캔 오버헤드와 안전성 간 절충으로 유지
- 즐겨찾기 2개 제한·표시 형식(전체 경로)은 요구 변경 시 조정
