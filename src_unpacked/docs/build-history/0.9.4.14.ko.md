# MediaSimilarityFinder v0.9.4.14 — C4.1 빌드 복구

0.9.4.13 동기화 검증에서 발견된 컴파일 break를 복구한다.
엔진 1.5.0·DB 1.0.3·캐시 v9·schema 2 불변.

## 변경 필요성
- 0.9.4.13의 `kDefaultMaxAgeDays`가 `ProfileStore`에 선언됐으나 모든
  사용처 5곳이 `PerformanceProfile::`을 참조해 C2039/C2065로 빌드가
  깨졌다. 원격은 검증을 pending으로 정직하게 표기했으나, PASS 수치
  없이는 C4.1이 미완성 상태로 남는다. profile_test의 신규 케이스도
  같은 이유로 깨졌다.

## 기존 구조
- 상수 선언 위치(`ProfileStore`)와 사용 위치(`PerformanceProfile::`)
  불일치.

## 변경 구조
- 상수를 `PerformanceProfile`으로 이동(사용처 의도대로). 동작 변경
  없음, 주석만 정리.
- profile_test 신규 케이스의 비修飾 `PerformanceProfile::`에 `msf::`
  접두 추가.

## 선택 이유
- 선언을 사용처에 맞추는 쪽이 diff 최소이며, 상수의 의미(프로파일
  정책값)도 `PerformanceProfile` 쪽이 맞다.

## 해결된 문제
- 양쪽 트리 컴파일·전체 스위트 복구.

## 정확성 영향
- 없음. 선언 위치만 이동, 값·의미 동일.

## 호환성 영향
- 없음. INI·JSON 키 불변.

## 검증
- CPU Release 빌드 PASS, **CTest 66/66 PASS**.
- GPU Release 빌드 PASS, **CTest 67/67 PASS**.
- 양쪽 `--version` 0.9.4.14, `--smoke` PASS.

## 향후 영향
- 0.9.4.13의 검증 수치는 이 버전에서 확보한 것으로 읽어야 한다.
  다음부터 원격 동기화는 로컬 빌드로 확인한다(이번에 규칙화).
  CPU-only 검증 수치(64/64)도 0.9.4.12 기준 66/66으로 바로잡았다.
