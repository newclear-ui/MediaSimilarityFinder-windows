# MediaSimilarityFinder v0.9.2.67 — L3 SSIM Verification Cells + thumb48 Cache v5

## Need for change
Phase 3 (Grok): among pairs passing L1, same-low-frequency/different-scene false positives are hard to split with pHash Hamming alone. A structural-similarity (SSIM) scoring layer over aligned frame pairs was needed. SSIM is a scoring function, not a key, so it belongs in the DP cell — not candidacy.

## Previous structure
- `video_similarity()` DP cells scored `hash_similarity` only. Cache v4 stored no pixels, so structural comparison was impossible

## New structure
- **`thumb48`**: 48×48 gray per kept frame (2304B), 1:1 with `hashes[]`. Built by 2×2 box-downsampling the already-decoded 96×96 crop pass (no extra decode). Zero-filled where the 96 pass is short, preserving alignment
- **Cache v5**: v4 + thumbCount + thumbs. `kCacheFormatVersion=5`, all v4 rows retired (one full rebuild). Mismatched thumb blocks reject the row; thumbCount 0 means Hamming-only (hand-built/legacy compatible)
- **SSIM cells**: uniform-8×8-window MSSIM, clamped [0,1]. B side pre-flipped once, scored `max(SSIM, SSIM-flip)` (mirror coverage). Hamming-failing cells keep the cheap reject path (zero SSIM cost). Passing cells re-scored 0.4·Hamming + 0.6·SSIM. Flat/missing thumbs skip to Hamming, i.e. legacy-identical
- `crop_temporal_score` stays Hamming (crop-hash cells, no pixels). Final `max()` coexists with the SSIM gate
- Pure-function `frame_ssim()` + `video_ssim_test` (identity≈1, black-white≈0, mid detail, fallback equivalence, noise-cut proof). `video_cache_test` updated to v5
- Version strings unified → 0.9.2.67

## Resolved situation
- At scan threshold (87.5): H=90/S=60 pairs cut to 72, H=90/S=88 re-encodes held at 88.8. False-positive cutting and true-detection retention hold simultaneously
- Memory: ~55KB per row at 24 frames (within SQLite and in-memory cache budgets, documented)

- Adjacent-SSIM rhythm filter (optional item) stays unimplemented, per Grok's warning against standalone-rhythm fingerprints
- Thumb size fixed at 48. Higher-res SSIM would need its own version bump
- Cache-miss videos degrade gracefully to the XOR+anchor path (.65-level behavior without L3)
