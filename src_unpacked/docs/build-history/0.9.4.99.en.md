# MediaSimilarityFinder v0.9.4.99 — Kind dropdown + reference-excluded marking + detail-blank fix

Baseline `0.9.4.98` -> this build `0.9.4.99`.
CPU CTest **122/122**, GPU CTest **123/123**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` unchanged.

## 1. Why

Three user requests:

1. Merge the top bar's photo/video highlight toggles into one dropdown like the resource-amount menu on its left (1st Photos, 2nd Videos, 3rd All).
2. Checking a similar-group box for marking selects everything except the reference (representative) image, so move/recycle act on the rest.
3. Fix the bug: after checking then unchecking a group box, selecting a file blanks the bottom detail info (path/name/size).

## 2. Previous structure

- Two photo/video toggle buttons plus a both-off refusal rule. Scan scope (`scanImages/scanVideos`) read the button states.
- The group checkbox (`setGroupMarked`) marked every file in the group, with whole-group row states.
- `refreshDetail()` cleared rows with a `QFormLayout::takeAt()` loop. Emptied rows stayed in the layout, so `rowCount()` grew by ~9 per refresh forever, pushing live rows out of view.

## 3. New structure

- **Kind dropdown** (`gui/mainwindow.cpp`, `gui/mainwindow.h`): `kindBox_` (Photos/Videos/All; existing `kindImages`/`kindVideos` + new `kindAll` key). Single-select by construction, so the both-off refusal is gone. Same `ui/kindMask` bits (1/2/3) persisted/restored, same scan-scope mapping. Toggle button members removed.
- **Reference-excluded marking**: `setGroupMarked(..., true)` skips `paths[0]` and marks the rest; unchecking clears the whole group (cancel semantics). Row states go through the unified `groupMarkState()` helper (new): fully marked means all non-reference files marked. Creation (`addGroupItems`), sync, and the Space toggle follow the same rule. The "Mark all" menu (`markAll`) is untouched.
- **Detail-blank fix**: `refreshDetail()` rebuilds the form object instead (harvest widgets, delete the layout, create a fresh one — depending only on the stable `QLayout` contract). Sidesteps `takeAt`/`removeRow` ownership and orphaned-row issues.
- Test hooks `testMarkedPaths()`, `testDetailFileName()`.

## 4. Result

- One kind dropdown (Photos/Videos/All, default All). Scan scope identical.
- One group check marks everything but the reference, ready for move/recycle menus. Uncheck clears all.
- Path/name/size still show after check→uncheck→select. Form row count no longer diverges.
