# MediaSimilarityFinder v0.9.4.96 — 자원 정책 UI 개편 (Minimum 개명 + Custom 삭제 + 설정 이전)

기준선 `0.9.4.95` → 본 빌드 `0.9.4.96`.
CPU CTest **122/122**, GPU CTest **123/123**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` 불변.

## 1. 변경 필요성

사용자 지시: 실행 전략(AUTO/CPU 단독/GPU 최대)은 절대 유지하고, 자원 프리셋은 Maximum/High/Balanced 그대로, Gaming은 Minimum으로, Custom은 삭제한다. 툴바의 CPU 사용량 % 표기 + 미세 수정창은 숨기고, 설정 일반 탭의 체크박스로 표기 여부를 선택한다. 모니터 아이콘 옆 GPU 가속 체크박스도 설정 일반 탭으로 이동한다.

## 2. 기존 구조

- 툴바: 실행 전략 콤보 + 프리셋 콤보(Maximum/High/Balanced/Gaming/Custom) + `CPU %` 스핀박스(표시+편집 겸용, 편집 시 Custom 강제) + 모니터 버튼 + GPU 가속 체크박스.
- 정책 계층(`ResourceMode`, 스케줄러 Gaming 분기, 모니터 Gaming reserve, 백엔드 Custom 기본값)은 엔진·테스트 전반에 엮여 있었다.

## 3. 변경 구조

- **프리셋 4종**: 콤보에서 `Gaming`을 `Minimum`으로 개명(값 25/25 유지), `Custom` 제거. 인덱스 기반 매핑(`i+1`) 그대로라 `resourceChanged()` 무수정. 정책 계층·스케줄러·모니터·테스트의 enum/값은 전부 불변.
- **CPU 박스 읽기전용 + 숨김**: 스핀 버튼 제거 + 필드 읽기전용. `ui/showCpuPercent`(기본 OFF)로 툴바 액션 표시 전환. `customResourceChanged()` 삭제(선언·연결 포함) — 도달 불가 + 인덱스 4 무효라 지뢰 제거.
- **GPU 가속 설정 이전**: 툴바 체크박스 삭제, 저장 스위치 `gpuOn_`(`ui/gpuEnabled`, 기본 ON)으로 대체. CPU 단독 강제 OFF/AUTO·GPU 최대 복귀 ON의 덮어쓰기 의미 그대로 유지. 설정 일반 탭에 `GPU 가속` 체크박스(`monitorGpu` 라벨 재사용)로 이동, 저장 시 백엔드에 즉시 반영.
- **설정 일반 탭**: `CPU 사용량 % 표기` 체크박스(`showCpuPercent` 신규 키) + `GPU 가속` 체크박스 추가, 기존 저장 흐름과 동일하게 저장·적용.
- 번역키 `showCpuPercent` (+ `monitorGpu` 커버리지). `ui_translation_keys_test` 65 → 67 keys.
