# MediaSimilarityFinder v0.9.2.74 — Monitor Toolbar Cleanup (Pause Removed, Toggle Highlight, Menu Right)

## Need for change
Toolbar-right monitor buttons needed role cleanup: (1) the pause (⏸) button suspends realtime analysis with the watcher alive — redundant with start/stop, so deleted; (2) the monitor button auto-opened settings; stripped to a running-state highlight toggle; (3) the menu (☰) button moved to the far right, enlarged.

## Previous structure
- `monBtn_` toggle + auto `configureMonitor()` when unconfigured. Separate `monPauseBtn_` pause. Small menu button left of monitor

## New structure
- **Pause deleted**: button, slot, and members removed. Engine `MediaMonitor::setPaused` API and its test stay (re-exposable later)
- **Pure monitor toggle**: settings auto-open removed; unconfigured clicks show a guidance status message. Checked state paints green bold highlight
- **Menu docked right**: placed after the spacer so it pins right. Font +4, bold, minimum 46×32
- Version strings unified → 0.9.2.74

## Resolved situation
- One fewer toolbar button. Monitor state readable from button color. Menu more reachable

## Validation
- Core+GUI Release build: PASS, **CTest 54/54 PASS**
- `--version` 0.9.2.74, `--smoke` exit 0 (offscreen)
- CUDA algorithms unchanged (common layers only)

## Future impact
- With no configuration, the monitor button only guides to the menu. Settings live under ☰
- Pause can return on top of the intact `setPaused` API
