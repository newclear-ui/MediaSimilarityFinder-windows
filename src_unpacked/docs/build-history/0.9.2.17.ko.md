# MediaSimilarityFinder 0.9.2.17

## 중요 변경 — Mirror-Aware Similarity

이번 버전부터 이미지와 동영상의 좌우 반전본을 동일/유사 미디어 검색에서 인식한다.

### 변경 내용
- 이미지에 `normal pHash`와 `horizontal-mirror pHash`를 함께 생성.
- 동영상의 각 대표 프레임에도 normal/mirror fingerprint를 생성하고 캐시한다.
- CandidateIndex가 두 방향의 fingerprint를 모두 후보 선별에 사용한다.
- 최종 이미지 비교는 normal↔normal, normal↔mirror, mirror↔normal, mirror↔mirror 중 최고 유사도를 사용한다.
- 동영상 비교도 동일한 방향 조합의 최고 프레임 유사도를 사용한다.
- 기존 SQLite index에는 `mirror_fingerprint` 컬럼을 자동 추가하는 migration을 적용했다.
- 기존 동영상 fingerprint cache는 새 mirror payload 형식과 일치하지 않으면 자동 재생성된다.
- 실시간 Monitor도 mirror fingerprint를 생성/저장하고 비교한다.

## 크롭 대응을 위한 기반 정비
이번 버전에서는 최종 crop-aware 비교 자체를 넣지 않고, 이후 0.9.2.19 이후 구현할 4:3/1:1/9:16 중앙 크롭 2차 비교가 기존 CandidateIndex와 결합될 수 있도록 fingerprint 구조를 확장했다.
