# MediaSimilarityFinder v0.9.4.138 — 미리보기 셀 폭이 텍스트가 아닌 미리보기 크기를 따르도록 (동적 텍스트 축약)

기준선 `0.9.4.137` → 본 빌드 `0.9.4.138`.
CPU CTest **125/125**, GPU CTest **126/126**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` 불변 (표시 전용).

## 1. 변경 필요성

- 실기 요청: 미리보기(오른쪽 파일 그리드)를 줄여도 한 줄에 3개만 보인다. 원인은 셀 폭이 **가장 긴 텍스트 줄**(`393.0 KB · 2048x1798`)에 고정되어, 아이콘을 줄여도 셀이 좁아지지 않기 때문이다. 미리보기 폭을 넘는 글자는 자동으로 축약되어야 한다.

## 2. 기존 구조

- 파일 셀 텍스트는 3줄(이름/용량·해상도/유사도)로 만들어졌고, 이름만 아이콘 폭으로 `ElideMiddle` 처리, 나머지 두 줄은 원문 전체였다. `QStyledItemDelegate::sizeHint`가 가장 긴 줄의 폭을 셀 최소 폭으로 잡아 열 수가 고정됐다. 두 생성 경로(`refreshFileViews` 채움, `refreshFileMetaRow` 메타 도착 갱신)가 각자 문자열을 조립했다.

## 3. 변경 구조

- 신규 `MainWindow::fileGridItemText(path, ref, pct)` — 아이콘 폭(`textW = max(48, iconSize)`) 기준으로 줄마다 **우선순위 폴백**:
  - 이름: `ElideMiddle`(확장자 유지, 기존과 동일).
  - 용량·해상도: 전체 → **해상도만** → 해상도 `ElideMiddle`.
  - 유사도: 전체(예 `100% · 동일 내용`) → **`100%`만** → 값 `ElideMiddle`.
- 두 생성 경로가 이 헬퍼를 공용한다(중복 제거). 전체 경로 툴팁은 그대로. 리스트 보기(컬럼 표)는 변경 없음.
- 결과: 셀 폭이 아이콘 크기를 따라가므로 미리보기를 줄이면 한 줄에 더 많은 항목이 들어간다(예: 128px 3열 → 51~64px에서 6~8열 수준, 창 폭에 따라 다름).

## 4. 해결된 상황

- 미리보기 축소 시 이름뿐 아니라 용량·해상도/유사도 줄도 폭에 맞춰 자동 축약되어, 셀 폭이 미리보기 크기를 따른다.
