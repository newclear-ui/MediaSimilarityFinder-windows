# MediaSimilarityFinder v0.9.4.52 — two embedded image-path issues fixed

Baseline `0.9.4.51` -> this build `0.9.4.52`.
CPU CTest **105/105**, GPU CTest **106/106**.
`kEngineVersion 1.5.0` / `kDatabaseVersion 1.0.4` / `kBenchmarkSchemaVersion 9` /
`kCacheFormatVersion 9` — all unchanged. Test count unchanged.

## 1. Why the change was needed

The image search processing path (`MediaPipeline::imageBatch` -> `ImageDecoder`
-> fingerprint/crop) was traced end to end and two embedded problems were
confirmed.

## 2. Fix 1: `mbstowcs` locale dependence removed

The XMP `VT_LPSTR` branch in `src/image_decoder.cpp` converted with
`std::mbstowcs`, which depends on the thread C locale (default "C" accepts
ASCII only). `VT_LPSTR` is ACP-encoded by definition, so it now uses explicit
`MultiByteToWideChar(CP_ACP, ...)`. Same outcome for the ASCII digits this
parses ("1"-"8"); deterministic rather than locale-dependent otherwise.
Failure stays graceful (`ok=false`).

## 3. Fix 2: `parallelFor` catch intent pinned

The `catch(...) {}` in `src/media_pipeline.cpp` is load-bearing: worker
threads must never terminate, and a throw becomes `ok=false` for that slot,
which the analysis-failure state model settles as `failed`. Behavior kept;
the reason it must not be "cleaned up" is now pinned in a comment.
Per-file diagnostics belong in `DecodeTelemetry`, not in the fan-out.

## 4. Items verified sound (no change)

- **Zero fingerprint impossible**: `bits_from` compares against the median, so
  valid input cannot return 0 (the median is itself one of the values, setting
  at least one bit). Fingerprint 0 therefore always means "not computed",
  consistent with the 0.9.4.46 state model. `perceptual_hash` returning 0 for
  invalid input flows correctly into the failure model.
- **PGM fallback path**: already uses the `path_from_utf8` wide path. Safe.
- **Crop zero handling**: empty-input guards separate 0 from uncomputed. Safe.
- **GPU/CPU mirror consistency**: mirrors always come from CPU, consistent
  regardless of GPU success. Not redundant work.
- **`parseOrientationText`**: strict 1-8 verdict, rejects trailing garbage. Safe.
