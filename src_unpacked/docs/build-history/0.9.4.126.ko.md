# MediaSimilarityFinder v0.9.4.126 — Benchmark journal recovery CLI (`--benchmark-recover`)

기준선 `0.9.4.125` → 본 빌드 `0.9.4.126`.
CPU CTest **124/124**, GPU CTest **125/125**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` 불변.

## 1. 변경 필요성

- S3는 처음부터 "저널이 권위이며 `summary.json`은 재생성 파생물"이라고 선언했고, `BenchmarkSession::regenerateSummary()`도 "recovery용"으로 존재했다. 그러나 정작 그 함수를 호출하는 CLI 진입점이 없어, 강제 종료(kill)되거나 `summary.json`이 지워진 suite는 저널이 온전해도 summary를 되살릴 방법이 없었다.
- 실제 사례: headless suite `XMP-REAL-001`(사용자 dataset 273,773 files, 7 cases × 3 modes = 21 mode_result 전부 SUCCESS)이 강제 종료 후 `summary.json` 없이 남았다. 저널 29 records는 `case_complete`까지 온전했으나 summary가 없어 S5 측정 증거로 닫히지 않았다.
- Ctrl+C 정상 취소 경로는 기존대로 동작한다. 이번 변경은 kill·삭제 같은 비정상 종료 뒤의 복구 경로를 노출하는 것이며, 실행·취소·집계 계약(S2/S3)을 바꾸지 않는다.

## 2. 기존 구조

- `finalize()`만이 terminal 기록 + `regenerateSummary()`를 호출했다. 프로세스가 그 전에 죽으면 summary는 영원히 미생성이다.
- `replay()`는 `cfg_.runId` 범위로 재생하며 빈 문자열이면 suite 전체 run을 재생한다(`replayJournal` 계약).
- `BenchmarkSuiteLock`은 OS 핸들 기반이라 프로세스 종료 시 자동 해제된다. 0바이트 `suite.lock` 파일 잔재는 잠금이 아니다.

## 3. 변경 구조

- 새 진입점 `--benchmark-recover <log-dir> --suite <id> [--run <id>]` (파서·help·dispatch·실행 함수).
  - `--log-dir`은 저장소 루트 locator(위치 인자, `--benchmark <folder>`와 같은 모양), `--suite`는 필수, `--run`은 선택(생략 시 저널 전체 run 재생).
  - `--mode`·`--media`·`--log`·`--scan`·`--benchmark`와의 조합은 거부한다. 복구는 스캔하지 않으므로 소비자가 없는 옵션을 조용히 무시하지 않는다.
- `runConsoleBenchmarkRecover()`: suite id 안전 검사 → `runs.jsonl` 존재 확인 → live run이 lock을 쥐고 있으면 거부(부분 view 방지) → lock 없이 `regenerateSummary()` → exit 0/1.
  - 저널에는 쓰지 않는다(읽기 전용 replay). fingerprint 재계산·스캔·index 변경 없음.
- 테스트: parser 17 checks(`command_line_test`), 복구 동작 6 checks(`console_benchmark_cli_test`: 빈 요청·위험 id·저널 없음·손상 저널·busy lock 거부·정상 재생성).

## 4. 해결된 상황

- `XMP-REAL-001` 실저널에 신규 바이너리로 `--benchmark-recover` 실행 → exit 0, `summary.json` 생성(7 committed cases 전부 SUCCESS, `runFinished:false` — kill 종료라 terminal 기록이 없으며, 복구가 terminal을 invent하지 않는 계약대로다).
- 저널 불변 확인(29 lines 유지). 존재하지 않는 suite는 exit 1.
- `command_line_test` 117 checks, `console_benchmark_cli_test` 32 checks PASS.
