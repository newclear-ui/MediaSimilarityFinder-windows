# MediaSimilarityFinder v0.9.2.75 — 툴바·상세·요약 UI 라운드

## 변경 필요성
스크린샷 기반 UI 피드백 10건: 모니터 일시정지 버튼 용도 불명, 모니터 버튼의 설정 자동 오픈, 메뉴 버튼 위치·크기, 보기/종류 버튼 화살표 중복, 상세 경로 침범, 휴지통 표기, 모니터 GPU 체크박스 위치, 요약 모니터 행·RAM 무의미·GPU/CPU 표시.

## 기존 구조
- 모니터 일시정지 버튼(워처 유지 분석 중단)이 시작/중지와 중복. 모니터 버튼이 미구성 시 설정창 자동 오픈. 메뉴가 모니터 좌측 소형 배치
- 보기/종류 QToolButton이 텍스트 "▾" + 자체 화살표 이중 표시
- 상세 전체 경로 QTextEdit 박스 단독 돌출. 파일명 포함 전체 경로로 파일명 중복 표시
- 요약 모니터 행은 모니터 미실행 시 항상 "-". RAM/CPU 행은 모니터 실행 시에만 갱신. GPU 행은 "GPU"/"CPU" 고정 텍스트

## 변경 구조
- **일시정지 삭제**: 버튼·슬롯·멤버 제거. 엔진 `setPaused` API·테스트 유지
- **모니터 순수 토글**: 설정 자동 오픈 제거, 미구성 시 안내 메시지. 체크 시 녹색 굵은 하이라이트
- **메뉴 우측 고정**: spacer 뒤 배치, 폰트 +4·굵게·최소 58×32
- **보기 콤보박스화**: QToolButton+메뉴 → QComboBox (프리셋 콤보와 동일 양식, 화살표 1개). 언어 전환·탭 전환 동기화 유지
- **종류 버튼**: 라벨 "▾" 제거 (자체 화살표만). 사진/영상 명칭 유지
- **상세 경로**: 폴더 전용 QLabel (파일명 중복 제거), 줄바꿈·드래그 선택, 타 행과 동일 모양. 상세창 최대 430 고정
- **휴지통**: fileBar 아이콘 제거, "휴지통으로" 텍스트 (동작은 기존 FOF_ALLOWUNDO 그대로)
- **모니터 GPU**: 모니터 버튼 옆으로 이동
- **요약**: 모니터 행 삭제. CPU 행은 프로세스 실시간 사용률(GetProcessTimes/코어 정규화), RAM 행은 작업집합(GetProcessMemoryInfo)으로 실측 표시 (의미 부여). GPU 행은 켜짐/꺼짐 + 가속 중에만 표시
- 버전 표기 통일 → 0.9.2.75

## 해결된 상황

- 상세 경로 침범 해소. 요약이 스캔 중에도 전부 살아있는 값
