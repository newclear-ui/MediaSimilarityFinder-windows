# MediaSimilarityFinder 0.9.2.11 — 빌드 기록

## 중요 변경
실시간 모니터의 작업 대기열을 조건변수 기반의 지연 스케줄러로 개선했습니다.

### 주요 변경
- 유휴 상태에서 polling sleep 대신 condition variable로 대기하여 불필요한 CPU wake-up을 줄였습니다.
- 안정 파일 판정 실패와 시스템 부하 보호로 분석을 연기할 때 즉시 재큐잉하지 않고 지수형 backoff를 적용합니다.
- 최대 재시도 지연은 30초로 제한합니다.
- 새로운 파일 이벤트가 들어오면 대기 중인 작업을 즉시 깨울 수 있습니다.
- 모니터 중지 시 대기 중인 스레드를 즉시 깨워 빠르게 종료합니다.
- 분석 성공/비교 인덱스 갱신/삭제 처리 후 retry 상태를 정리합니다.
- 스케줄러 전용 회귀 테스트를 추가했습니다.

## 설계 의도
실시간 감시에서 가장 중요한 것은 즉각적인 분석보다 사용자의 foreground 작업을 방해하지 않는 것입니다. 특히 다운로드 중인 파일이나 고부하 상태에서 같은 파일을 짧은 간격으로 계속 재검사하는 busy loop를 방지합니다.
