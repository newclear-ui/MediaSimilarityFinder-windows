# MediaSimilarityFinder 0.9.2.22

## 중요 변경
영상 Crop-Aware 기능을 실제 검색 후보 생성과 최종 비교 흐름에 연결했다.

### 1. 영상 Crop CandidateIndex
- 기존 normal/mirror fingerprint 후보 인덱스는 그대로 유지한다.
- 영상 분석 시 4:3, 1:1, 9:16 중앙 crop의 경량 aggregate fingerprint와 mirror aggregate를 함께 생성한다.
- 각 비율별 CandidateIndex를 추가해 full fingerprint가 달라도 crop 기반 후보가 검색될 수 있도록 했다.
- 서로 다른 crop 비율의 crop↔crop 후보 비교는 허용하지 않는다.

### 2. 영상 temporal 2차 분석 실제 연결
- 1차 fingerprint 비교만으로 threshold를 넘으면 즉시 종료한다.
- 영상 후보가 threshold에 근접하지만 1차 결과만으로 확정되지 않는 경우에만 기존 timestamp를 재사용해 temporal crop-aware 분석을 수행한다.
- 4:3 / 1:1 / 9:16 각각에 대해 mirror를 포함해 비교한다.
- temporal alignment와 gap/time penalty는 기존 `video_crop_similarity()` 경로를 재사용한다.

### 3. Persistent cache 확장
- 영상 fingerprint cache payload에 6개의 crop aggregate fingerprint를 추가했다.
- 기존 payload는 새 형식과 크기가 맞지 않으면 자동으로 무효화되어 재생성된다.
- cache unit test를 새 payload 형식에 맞게 강화했다.

### 4. 실시간 Monitor 보호
- Monitor가 사용하는 `MediaSearchEngine`에 expensive second-stage guard를 추가했다.
- Monitor는 temporal crop 2차 분석 직전에 현재 CPU/GPU/메모리 상태를 다시 확인한다.
- 사용자 작업 보호 조건을 통과하지 못하면 2차 분석을 수행하지 않는다.
- 기존 stable-file detector, pause/resume, retry/backoff 정책은 유지한다.
