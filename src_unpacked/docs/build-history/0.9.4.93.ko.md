# MediaSimilarityFinder v0.9.4.93 — "불러오기" (인덱스 로드 전용) + 팝업 분리

기준선 `0.9.4.92` → 본 빌드 `0.9.4.93`.
CPU CTest **122/122**, GPU CTest **123/123**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` 불변.

## 1. 변경 필요성

- 검색(스캔)과 인덱스 조회를 분리할 필요. 현재 쓰임이 없던 새로고침 버튼을 **"불러오기"** 로 바꿔,
  폴더를 선택하고 누르면 **스캔 없이 인덱스 내용(유사그룹 목록 + 미리보기)** 을 불러오게 한다.
- 불러오기 시 정렬은 **없음**으로 자동 변경·고정.
- 팝업 분리: 불러오기 중에는 "검색 리포트 작성중"이 뜨면 안 되고, 검색 완료/중단 시에만 원래 문구가 떠야 한다.
- 불러오기 버튼은 1회 누르면 비활성(중복 클릭 방지) + "인덱스 목록 로딩중" 안내.

## 2. 기존 구조

- 툴바의 새로고침 버튼은 좌측 폴더 트리만 재구성(`refreshFolders`)했고 검색 결과와 무관했다.
- 인덱스 로드(quick-load)는 **스캔 시작 시에만** 동작했다(`ScanWorker::run`의 `loadMatches`).
- `ThumbnailStore` 조회(`requestThumb`)는 `worker_`가 없으면 miss를 반환 → 스캔 없는 상태에서는 썸네일 불가.
- 대기 팝업(`showReportWaitPopup`)은 제목이 `repWaitTitle`("검색 리포트 작성중")로 고정.

## 3. 변경 구조

- **IPC**: `LOAD_INDEX` 명령 추가(`backend_ipc.h`). payload `{root, appDir}`.
- **엔진**: `MediaSearchEngine::storedFiles()` = `db_.all()` (저장 파일 조회).
- **세션**: `BackendSession::loadIndex(root, appDir)` — 인덱스를 열어 `storedFiles()`+`loadMatches()`를 읽고,
  기존 `results()`/`quickLoaded()` 신호로 보고(스캔과 동일한 GUI 채움 경로 재사용). 워크/분석 없음.
- **백엔드 서버**: `LOAD_INDEX` → `session_->loadIndex(...)`.
- **GUI 클라이언트**: `BackendClient::loadIndex(root, appDir)` (loopback/supervisor 구현).
- **GUI**: 새로고침 버튼 → `📂 불러오기`(`load` 키), 클릭 → `MainWindow::loadIndex()`. 뷰 상태 초기화 후
  정렬을 `없음`으로 고정(`loadLockSort_`, 다음 스캔에서 해제)하고 `LOAD_INDEX` 전송. `loading_` 가드로 1회 제한 +
  버튼 비활성 + 비모달 "인덱스 목록 로딩중…" 팝업.
- **팝업 분리**: `showReportWaitPopup(..., textKey, titleKey)`로 제목 분리.
  - 불러오기: 제목 `loadWaitTitle`("인덱스 불러오기") · 본문 `loadWait`("인덱스 목록 로딩중…").
  - 검색 완료: 제목 `repWaitTitle`("검색 리포트 작성중") · 본문 `repWait`(원래 값).
  - 검색 중단: 제목 `repWaitTitle` · 본문 `stopWait`(원래 값).
  - `onResults()`가 `loading_`으로 분기 → 불러오기는 로드 팝업만 닫고 리포트 팝업을 **띄우지 않는다**.
- **썸네일**: `BackendSession::requestThumb`의 `worker_` 필수 조건 제거 → 로드 전용 뷰에서도 영속 디스크
  썸네일(`thumbs` 테이블) 또는 WIC/FFmpeg 디코드로 표시(engineFetch는 선택).

## 4. 해결된 상황

- 검색과 인덱스 조회 분리. 불러오기로 스캔 없이 저장된 유사그룹/미리보기 확인.
- 불러오기 중 리포트 팝업 미표시, 두 팝업의 제목·본문·트리거 분리.
- 중복 클릭 방지(1회) + 로딩 안내(비모달, 창 이동 가능).
