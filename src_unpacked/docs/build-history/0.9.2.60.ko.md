# MediaSimilarityFinder v0.9.2.60 — 아이콘/리스트 보기 복구 + fav 중복 제거 + 컬러 미리보기

## 변경 필요성
3건 보고: (1) 타일·자세히에서만 목록이 보이고 아이콘 4종+리스트에서는 백지, (2) 최근 검색폴더가 즐겨찾기에 중복 표시, (3) 미리보기가 흑백으로만 표시.

## 기존 구조
- (1) 타일 도입(v0.9.2.53) 시 타일용 커스텀 delegate를 쓰고 복귀 시 `setItemDelegate(nullptr)`. headless 프로브로 확정: `nullptr`은 기본 delegate로 복귀하지 않고 null 비주얼(-1x-1) → 해당 모드 전체가 백지. 타일(명시 delegate)과 트리(영향 없음)만 정상이었던 것과 일치
- (2) 최근폴더가 고정 즐겨찾기(다운로드 등)와 경로 비교 없이 추가 → 같은 폴더 이중 표시
- (3) 표시 경로가 지문용 그레이스케일에 의존: QImageReader 실패분(PNG 등, 포터블에 qpng 없음)은 WIC Gray 폴백, 비디오는 셸 미스 시 FFmpeg Gray 프레임 → 흑백

## 변경 구조
- **delegate 명시 복원**: `defaultDelegate_(QStyledItemDelegate)`를 두고 아이콘/리스트/자세히 모드에서 설정. `nullptr` 사용처 제거. 프로브(`view_mode_probe`)가 패턴을 영구 보장
- **fav 중복 제거**: 6개 표준 경로 집합과 대소문자 무시 정규화 비교 후 겹치면 생략. 없는 폴더도 생략(이미 있음)
- **컬러 표시 레인**: `ImageDecoder::decodeColorAspect`(WIC 32bppBGRA → ARGB32) 신설, `VideoDecoder::frameAtColor`(FFmpeg RGB24 단일프레임) 신설. `fileThumb` 이미지 레인은 QImageReader(컬러)→WIC 컬러→파일아이콘, 비디오 레인은 셸(컬러)→RGB24→파일아이콘. 그레이 디코더는 지문 전용으로 유지, 표시에서 제거
- `color_thumb_test` 신설(빨강 BMP→적색 픽셀 확인, testsrc 컬러바→유채색 픽셀 확인). 버전 표기 통일 → 0.9.2.60

## 향후 영향
- delegate는 절대 `nullptr`로 되돌리지 말 것(프로브가 감시). 모드 추가 시 명시 delegate 유지
