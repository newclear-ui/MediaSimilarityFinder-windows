# MediaSimilarityFinder v0.9.2.62 — Similarity-Inspired Additions (Pairs, ETR, Thumbnail Skip-List)

## Why the change was needed
The external reference analysis (`docs/architecture/reference-similarity.en.md`) identified three practical Similarity patterns worth adopting. Per-group file counts alone do not convey comparison scale for large groups (no Pairs column), elapsed-only status gives no finish estimate (no remaining time), and corrupt/undecodable files repeatedly consume the thumbnail budget (no skip list). All are solvable in the GUI common layer, independent of the CUDA algorithms.

## Previous structure
- Group tree with 4 columns: group / files / similarity / size. `fillPair` computed no pair counts
- Status message fixed as `done / total (pct%) — filename — elapsed` (`scanProgress`, 600ms `uiTimer` tick). No ETR
- `fileThumb`: cached the placeholder on failure, but after cache eviction (cap 3000) corrupt files re-spent heavy decodes. No separate failure memory

## New structure
- **Pairs column** (`gui/mainwindow.cpp` `fillPair`): `pairs = n*(n-1)/2`, tree grows to 5 columns (group/files/pairs/similarity/size) + grid labels show `N Pairs`. New KO/EN string `pairs`
- **ETR display** (new `scanStatusText`): linear extrapolation `remaining = elapsed*(total-done)/done`. Falls back to the old message when `elapsed<1s`, `done==0`, or `total<=done`. `scanProgress` and the tick display share the helper. New KO/EN string `remain`
- **Thumbnail skip list** (`thumbFail_`, cap 2000, evicted 500 at a time): remembers heavy-decode failures and returns the file-type icon immediately without spending budget on later ticks. Cleared on scan start, pruned on file deletion
- Version strings unified → 0.9.2.62

## Resolved state
- Real pair counts visible in tree and grid for every group (cf. Similarity v1.8.1 Pairs column)
- `… — Left HH:MM:SS` shown during scans for finish estimates (cf. Similarity Estimated Time Remaining)
- Corrupt files no longer drain shell/heavy decode budgets (cf. Similarity skip list, thumbnail scope)
