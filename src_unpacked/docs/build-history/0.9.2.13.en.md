# MediaSimilarityFinder 0.9.2.13 — Build History

## 중요 변경
0.9.2.13은 introduces a **load-state analysis gate that prioritizes protection of the user workload** in the resident real-time monitor.

### Changes
- CPU/메모리/GPU 상태를 Idle / Light / Busy / Heavy / Critical로 분류한다.
- Gaming 모드에서는 더 큰 여유 자원을 확보하며 Light 상태에서도 실시간 분석을 시작하지 않는다.
- Balanced 이상에서도 현재 사용량에 안전 여유폭을 더해 분석 허용 여부를 판단한다.
- GPU가 비활성화된 경우 GPU 사용률을 분석 차단 조건으로 사용하지 않는다.
- Windows CPU/GPU 샘플 상태는 `SystemLoadMonitor` 인스턴스별로 유지한다.
- 부하 상태 판정과 정책 게이트 회귀 테스트를 추가한다.

### Design principle
Non-interference with games, foreground work, and existing system load takes priority over real-time analysis speed. Delayed analysis is an expected protection behavior and is retried from the pending queue.
