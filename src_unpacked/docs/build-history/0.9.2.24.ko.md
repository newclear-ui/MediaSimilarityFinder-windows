# MediaSimilarityFinder 0.9.2.24

## 중요 변경

### Monitor 안정성 및 예외 복구 강화
- 동일 경로에 대한 연속 파일시스템 이벤트를 하나의 pending 작업으로 병합한다.
- 제거 이벤트와 이후 생성/수정 이벤트의 충돌을 정리하여 오래된 제거 작업이 새 파일 상태를 삭제하지 않도록 했다.
- Pause/Resume 및 재지연 과정에서도 pending 상태를 보존한다.
- 안정화 대기 및 시스템 부하 보호 지연에 최대 재시도 횟수(`maxRetries`, 기본 8회)를 적용한다.
- 재시도 한계 초과 시 해당 파일만 오류 상태로 종료하며 Monitor 전체는 계속 실행한다.
- 마지막 오류 경로와 오류 메시지를 `MonitorStatus`에 기록한다.

## 부하 보호
기존 foreground workload protection과 LoadState 정책은 변경하지 않았다. Monitor 자체 분석 스레드는 Windows에서 낮은 우선순위를 유지한다.

## 참고
현재 소스 트리에는 Qt GUI 실행 파일이 포함되어 있지 않으므로 Telemetry의 실제 Qt 화면 연결은 후속 GUI 단계에서 진행한다. 이번 버전에서는 Core `MonitorStatus` telemetry를 안정화했다.
