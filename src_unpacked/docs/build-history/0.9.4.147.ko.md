# MediaSimilarityFinder v0.9.4.147 — "없음" 정렬이 불러오기/검색 시의 순서를 기억

기준선 `0.9.4.146` → 본 빌드 `0.9.4.147`.
CPU CTest **125/125**, GPU CTest **126/126**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` 불변 (표시 전용).

## 1. 변경 필요성

- 실기: 불러오기/검색 직후의 "없음" 목록 순서를 기억하지 못하고, 이름·유사도 등으로 바꿨다가 다시 "없음"으로 돌아오면 **마지막 정렬 순서**가 표시됐다.
- 요청: "없음"은 항상 **초기 불러오기/검색 시의 목록 순서**를 복원해야 한다.

## 2. 기존 구조

- `rebuildGroups()`가 정렬 결과와 무관하게 `noneOrder_`(None 기준선)를 매번 현재 `groups_` 순서로 덮어썼다.
  - 주석에도 "정렬된 채우기 후에도 None 전환 시 보이던 순서를 보존"이라고 되어 있어, 이름/유사도 정렬 후 None이 그 순서를 따랐다.

## 3. 변경 구조

- `noneOrder_` 갱신을 **정렬 모드가 None일 때만** 수행한다.
  - 이름/유사도/그룹 크기 정렬은 기준선을 건드리지 않는다.
  - None으로 전환하면 저장된 불러오기/검색 순서를 복원하고, 새 그룹(root)은 기존 규칙대로 뒤에 추가한다.
- Load/재검증은 기존처럼 기준선을 새로 만들고, 스캔 중 None 구간(0.9.4.146의 시작/종료 재정렬 포함)도 새 결과의 순서를 기준선으로 기록한다.

## 4. 해결된 상황

- 이름/유사도 정렬 → "없음"으로 돌아오면 처음 불러왔을 때의 목록 순서가 그대로 표시된다.
- 검색 후에도 그 검색 결과의 None 순서가 기준선이 된다.

## 6. 향후 영향 및 한계
