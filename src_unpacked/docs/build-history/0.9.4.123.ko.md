## 1. 변경 필요성 (복수)

1. **`view_mode_probe` 부하 플레이크**(0.9.4.118 2회·0.9.4.121 2회 관측, 모두 빌드 직후 실행·재실행 PASS). 기준선 형상 확정 단언(`baseline geometry converged`)이 두 스냅샷 사이 단일 강제 레이아웃+펌프 비교라, Batched 증분 레이아웃이나 병합 singleShot 패스가 그 사이에 떨어지면 실패한다.
2. **PDB 미동봉**: Release PDB(`MediaSimilarityFinder.pdb` 39.8 MB·Backend 27.4 MB)는 생성되지만(`CMakeLists` /Zi+/DEBUG) portable zip에 포함되지 않아, 실기 덤프를 해당 빌드에 심볼 해석할 방법이 없었다. 런북은 "일치 PDB 함께 보관"을 요구한다.
3. **덤프 수집 원클릭 부재**: LocalDumps 설정이 런북 수동 절차로만 존재했다.
4. **제품 acceptance 재확인**: 런북 기준으로 Search/Index/Comparison를 코드·기존 증거·실기 보고에 대조할 시점이다(여전히 최종 NOT ACCEPTED).

## 2. 기존 구조

1. 프로브 기준선 블록이 강제 `doItemsLayout()` + 펌프 1회 후 단일 재스냅샷 비교였다.
2. `package_portable.ps1`은 exe·백엔드·DLL·ffmpeg·플러그인만 복사하고 PDB를 제외했다(플러그인의 `*.pdb` 제외와 무관).
3. 덤프 수집은 문서 절차뿐이었다.

## 3. 변경 구조

- **① 플레이크 근본 수정(테스트 전용)**: 기준선 확정 비교를 **최대 10회 수렴 루프**로 교체 — 강제 레이아웃+펌프+스냅샷을 연속 2회가 일치할 때까지 반복. 진성 진동 레이아웃은 10회 후에도 실패하므로 결함 은폐가 아니다. `base` 스냅샷 자체는 손대지 않는다(후속 단언 의미 유지).
- **② PDB 동봉**: `package_portable.ps1`이 두 PDB를 실행파일 옆에 복사(누락 시 패키징 실패 — 심볼 없는 포터블의 침묵 출하 금지). portable 크기는 약 44→90 MB로 증가한다. Qt 플러그인 PDB 제외는 유지.
- **③ `scripts/enable_localdumps.ps1` 신설**: 양 이미지 LocalDumps 등록(DumpFolder=`D:\Temp\OpenCodeWork\dumps`, Count 3, Type 1=mini, 런북과 동일). 미승격 실행은 명확한 메시지와 함께 거부한다(거부 경로 실행 검증). 런북 한·영에 스크립트 연결을 추가했다.
- **④ acceptance 재확인(코드 변경 없음)**: 런북 18개 항목을 대조한 결과는 §4·worklog 참조. 최종 판정은 **NOT ACCEPTED 유지**(실기 항목 잔여).

## 4. 해결된 상황 · 수용 판정

- 플레이크: 단독 3연속 PASS + 빌드 직후 실행 포함. 이후 전체 스위트에서도 재발하면 바운드를 재검토한다(기록 유지).
- PDB: 포터블에 `MediaSimilarityFinder.pdb`·`MediaSimilarityFinderBackend.pdb` 포함 검증(오케스트레이터 Step 7 단언 추가).
- 덤프: 원클릭 스크립트 + 거부 경로 검증. (관리자 승격 경로는 코드 리뷰+런북 일치로 검증 — CI는 비승격이라 실행 불가.)
- 수용 판정표(근거: 코드/테스트/실기 보고, 상세는 worklog):
  - Index I-1 불러오기 점진 채우기·반응성 — **PASS(실기)** / I-2 스캔 churn 부재 — 구현+프로브, 실기 로그 직접 확인 잔여 / I-3 유령 그룹 부재 — **PASS(실기: 275 소멸+missing=14)** / I-4 증분 fingerprint — **PASS(실기 5/177776+테스트)** / I-5 백엔드 생존 — **PASS(실기 킬 0건)** / I-6 요약 가독성 — 구현+핀, 육안 잔여
  - Search S-1 진행 정확성 — **PASS(상세 로그 1:1 대조)** / S-2 중지/재개 — 테스트 PASS(실기 edge 잔여) / S-3 의미론 — **PASS(테스트)** / S-4 모드 — **PASS(테스트+실기 AB)** / S-5 크래시 내성 — **PASS(테스트)** / S-6 요약 패널 — **PASS(테스트)**
  - Comparison C-1 카운트 정합 — **PASS(테스트+대조)** / C-2 배지 의미 — **PASS(테스트+감사)**, 문구 육안 잔여 / C-3 파생본 — 픽스처 PASS, 실데이터 잔여 / C-4 reduction — **PASS(대조)** / C-5 정렬/필터 — 구현(전용 테스트 없음), 실기 잔여 / C-6 파일 액션 — **PASS(테스트)**, 대량 실기 잔여(.105)
  - 최종: **NOT ACCEPTED 유지** — 실기 항목(.105/.106 대량 작업·배지 문구·churn 로그·휠/종료 체감)이 남았기 때문.
