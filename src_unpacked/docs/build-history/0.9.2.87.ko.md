# MediaSimilarityFinder v0.9.2.87 — CUDA 커널 1e-7 스냅(CPU·GPU 단색 일치)

## 변경 필요성
- 0.9.2.86의 고속 CPU pHash는 절댓값 1e-7 미만 계수를 0으로 스냅해 단색 이미지를 결정적 해시로 만들었으나, CUDA 커널에는 같은 스냅이 없었다.
- 단색 이미지에서 CPU(결정적)와 GPU(반올림 노이즈) 해시가 달라질 수 있었다. 합성 격자 패턴에서는 19비트 divergence가 실측됐다.

## 기존 구조
- 커널이 계수를 `coeff[tid]=sum*c_norm[v]`로 그대로 저장했다.

## 변경 구조
- `msf_phash_kernel`의 계수 저장 1줄을 스냅으로 교체했다: `|c|<1e-7`이면 0. CPU `bits_from()`과 동일한 기준이다. DCT 연산 자체·테이블·정렬은 불변이다(“CUDA 불변” 규칙의 예외로 승인됨).
- `cuda_backend_test`의 구조화 허용치를 제품 허용(D≤8)으로 복귀하고 주석을 실측(격자 패턴 ham=0)으로 갱신했다.
- 버전 표기 통일 → 0.9.2.87.

## 해결된 상황
- 자연 이미지 56장·합성 패턴 8종 모두 CPU·GPU 비트 완전 일치(격자 패턴 #5 포함).
- 단색 이미지는 CPU·GPU 모두 결정적 동일 해시(0x7fff…)가 된다.

## 향후 영향
- GPU 해시 의미가 CPU와 완전히 일치하므로, 단색류 파일의 CPU/GPU 경로 선택에 따른 결과 차이가 사라진다.
- FMA 합성 차이는 이론상 가능하나 본 환경(sm_86·CUDA 13.4·VS18)에서는 전 입력 0 divergence를 실측했다.
