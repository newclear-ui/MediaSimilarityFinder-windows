# MediaSimilarityFinder v0.9.2.81 — 단일 트리 재검증 + GUI 테스트 플러그인 경로

## 변경 필요성
- `C:\project`와 `C:\project-b64` worktree 병합 후, 표준 폴더의 구 빌드 산출물(`build-windows-cpu/cuda`)은 구소스 기준이라 그대로 둘 수 없었다.
- 병합 과정에서 보존 브랜치(`archive/project-wip-ql-revert`)의 CI·패키징·문서·ffmpeg 변경을 대조했으나, 모두 최신 라인에 이미 수렴(또는 검증됨)이라 이식할 내용이 없었다.
- 새로 구성한 트리에서 전체 빌드는 성공했으나 GUI 테스트 4개가 플랫폼 플러그인을 찾지 못해 크래시했다.

## 기존 구조
- Qt 플랫폼 플러그인(`qoffscreen` 등)은 `vcpkg_installed/x64-windows/Qt6/plugins`에만 있고, 빌드 출력 디렉터리나 `QT_PLUGIN_PATH`로는 전달되지 않았다.
- GUI 테스트는 CTest 환경에서 플러그인 경로를 보장받지 못했다.

## 변경 구조
- `CMakeLists.txt`에서 `Qt6::Core` 위치로부터 플러그인 디렉터리를 계산해 GUI 테스트 8종에 `QT_PLUGIN_PATH`를 부여한다.
- 판정 로직·CUDA 알고리즘 변경 없음. 버전 표기 통일 → 0.9.2.81.
