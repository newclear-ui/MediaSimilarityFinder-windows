## 1. Why it was needed (multiple)

1. **`view_mode_probe` load flake** (observed 4x: twice in 0.9.4.118, twice in 0.9.4.121 - always runs launched right after a build, always passing on rerun). The baseline-geometry assertion compared two snapshots around a single forced layout + pump, so a Batched incremental layout or a coalesced singleShot pass landing between them failed the check.
2. **No shipped PDBs**: Release PDBs (`MediaSimilarityFinder.pdb` 39.8 MB, Backend 27.4 MB) are emitted (CMakeLists /Zi+/DEBUG) but never copied into the portable zip, so a field dump could not be symbolized against its build. The runbook requires keeping the matching PDBs.
3. **No one-click dump setup**: LocalDumps existed only as a manual runbook procedure.
4. **Product acceptance recheck due**: time to judge Search/Index/Comparison against code, existing evidence, and field reports (final verdict still NOT ACCEPTED).

## 2. Previous structure

1. The probe's baseline block did one forced `doItemsLayout()` + pump and a single re-snapshot comparison.
2. `package_portable.ps1` copied exe/backend/DLLs/ffmpeg/plugins but excluded PDBs (unrelated to the Qt-plugin `*.pdb` exclusion).
3. Dump setup was documentation only.

## 3. New structure

- **(1) Flake root fix (test-only)**: the baseline convergence check is now a **bounded settle loop (10 attempts)** - repeat forced layout + pump + snapshot until two consecutive snapshots agree. A genuinely oscillating layout still fails after 10 attempts, so real defects are not masked. The `base` snapshot itself is untouched (later assertions keep their meaning).
- **(2) PDBs shipped**: `package_portable.ps1` copies both PDBs beside the executables (missing PDBs fail the package - an un-symbolizable portable must never ship silently). The portable grows ~44 MB to ~90 MB. The Qt-plugin PDB exclusion stays.
- **(3) New `scripts/enable_localdumps.ps1`**: registers LocalDumps for both images (DumpFolder=`D:\Temp\OpenCodeWork\dumps`, Count 3, Type 1=mini, same as the runbook). Unelevated runs are refused with a clear message (refusal path executed and verified). Both runbook languages link the script.
- **(4) Acceptance recheck (no code change)**: all 18 runbook items judged; see §4 and the work log. Final verdict stays **NOT ACCEPTED** (field items remain).
