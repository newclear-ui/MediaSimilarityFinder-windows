# MediaSimilarityFinder v0.9.2.46 — Scan Pipelining (Walk ‖ Analyze)

## Need for change
Scans were strictly sequential: analysis started only after the directory walk finished, idling CPU/GPU for 23 minutes on a 272k-file folder. Cancel was likewise ignored during the walk. Per request, rebuilt as two-stage overlap (walk ‖ analyze, matching untouched).

## Previous structure
`Scanner::scan` returned the full `vector<FileState>` before classify → analyze → match began. `MediaSearchEngine::scan` ran single-threaded collection, image batches, video batches, commit, match.

## New structure
- `Scanner::ScanCallbacks{onProgress, onFile, cancel, pause}` + `scan_stream()`. With `onFile` set, files move to the consumer (no vector retention); cancel/pause checked per entry. Plain `scan()` delegates with no callback, so behavior and signature are compatible
- `MediaSearchEngine::scan()`: a walker thread streams walked files through a queue while the main thread classifies → image batches/GPU → video async → upserts inline. Single-DB-connection rule kept (walker never touches the DB). Unbounded queue, no deadlock (~tens of MB at 272k files)
- Classify counters (added/modified/unchanged/scanned) and deleted detection (seen set) reworked for streaming. Single transaction, commit placement, match phase, and ignore filtering keep identical semantics
- Renamed to `msf::IndexedFile` (`incremental_index.h` defined a second, conflicting `FileState` alongside `database.h`. It built only by accident — no TU included both)
- Version strings unified → 0.9.2.46

## Resolved situation
- Analysis starts without waiting for the walk. Cancel during the walk takes effect immediately (previously ignored up to 23 minutes)
- Pause observed on both walker and analyzer. Match results and report semantics unchanged

## Validation
- Core Release build: PASS, **CTest 39/39 PASS** (all scan-path suites green = semantics preserved)
- Worker replica probe, 3,000 files: **identical** to sequential (scanned/analyzed/groups/candidates 641,358) + faster (46.6 s → 37.9 s)
- Pause/cancel probes: stall, resume, early stop all correct. Cancel now stops inside the walk phase
- Compile lesson recorded: `ScanCallbacks` was first placed at namespace scope, so `Scanner::` qualification failed (MSVC C2039+C3409 cascade) — moved inside the class

## Future impact
- Full pipelining (incremental matching) deliberately excluded. It would replace `pipe.analyze` with incremental index queries (separate version with accuracy regression)
- Legacy `Scanner::scan()` signature kept. New code uses `scan_stream`
- The `IndexedFile` rename removes the ODR hazard at its root
