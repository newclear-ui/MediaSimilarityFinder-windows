# MediaSimilarityFinder v0.9.2.76 — 콘솔 플래시 제거 + 해상도 무스폰화

## 변경 필요성
유사그룹 선택 시 터미널 창이 번쩍이고 순간 랙 발생. 원인 확정: `fileResolution()`이 Qt 플러그인 없는 포맷(PNG 등)마다 `ffprobe`를 `_popen`으로 실행. 콘솔 서브시스템 자식은 GUI 앱에서 보이는 콘솔을 띄우고, 스폰 ~100ms가 UI 스레드에서 직렬 발생. 그룹 선택 = 파일 수만큼 반복.

## 기존 구조
- 해상도: QImageReader → 실패 시 ffprobe `_popen` (콘솔 플래시 + 스폰). 캐시는 있으나 첫 표시마다 전량 스폰
- `video_decoder` CLI 폴백 2곳도 동일 `_popen` (미연결 FFmpeg 분기, 현재 빌드 미사용이나 동일 결함)

## 변경 구조
- **`captureSilent` 신설** (`src/proc_capture.h`, 헤더 온리): `CREATE_NO_WINDOW` + 파이프 캡처. 바이너리 안전. 비Windows는 popen 유지. 종료코드·빈 출력 실패 처리
- **PNG/JPEG 헤더 파서** (`ImageDecoder::dimensionsFast`): IHDR 직접 판독 + SOF 마커 워크 (baseline·progressive·extended, SOS 중단, 전구간 bounds 검사). 256KB 캡. 디코드·스폰 없음
- **fileResolution 순서**: QImageReader → 헤더 파서 → ffprobe(무창). 사진 라이브러리의 스폰 99% 제거. 비ASCII 경로는 기존과 동일하게 로컬 8비트 유지
- **video_decoder 폴백** 2곳도 동일 헬퍼로 교체 (결함 클래스 제거)
- `image_dim_test` 신설(JPEG/PNG 160x90 + 쓰레기·잘린 입력 거부). 버전 표기 통일 → 0.9.2.76

## 해결된 상황
- 그룹 선택 시 콘솔 플래시 원천 제거. 해상도 표시는 캐시 적중 또는 수십 μs 헤더 파싱
- ffprobe는 최후 수단으로만 1회성 실행 (무창)
