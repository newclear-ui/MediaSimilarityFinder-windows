# MediaSimilarityFinder v0.9.2.89 — Right-Click Selection (Reveal Misfire Fix)

## Need for change
- "Reveal in Explorer" opened a new window on the wrong folder. `revealPath()` itself is verified (`reveal_window_test` PASS), so the wrong path came from upstream.
- The cause was the context menu. Qt does not auto-select on right-click, but the file/group menus acted on the stale selection. A different file's folder opened as if that were normal.

## Previous structure
- The `customContextMenuRequested` handlers for the file grid/list and group tree/grid opened menus without selecting the item under the cursor.

## New structure
- All four handlers select the item under the cursor before showing the menu. Right-clicking an already-selected item preserves multi-selection; otherwise only that item is selected. Group panes point `currentGroup_` at the right-clicked row.
- No matching-logic or CUDA algorithm changes. Version strings unified → 0.9.2.89.

## Resolved situation
- Open, reveal, delete, rename, and all other menu actions now consistently target the right-clicked file/group.

## Validation
- Core+GUI Release build: PASS, **CTest 58/58 PASS**
- Portable `--smoke` exit 0, `MediaSimilarityFinder-v0.9.2.89-Portable-Windows-x64.zip` produced

## Future impact
- None. This is the standard Explorer selection rule.
