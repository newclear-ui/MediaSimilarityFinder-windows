# MediaSimilarityFinder v0.9.4.97 — Settings GPU rename + Load-thumbnail fix

Baseline `0.9.4.96` -> this build `0.9.4.97`.
CPU CTest **122/122**, GPU CTest **123/123**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` unchanged.

## 1. Why

Two user requests:

1. Rename the Settings > General `GPU 가속` checkbox to `모니터링 GPU가속` (label only, function unchanged).
2. Load fetches the index list but no thumbnails show up.

## 2. Previous structure

- `onThumbReady()` painted arrivals only onto the middle group grids (`imgGrid_/vidGrid_`) and the preview (220x190). The right file grid (`grid_`) was left to "heal through the memory cache on next refresh" (selection change) per its comment — never painted on arrival. After a Load with no clicks following, it kept placeholders forever.
- `fileThumb()` requested the backend at any size. In details/tree view the middle grid's `iconSize` is never set (-1x-1), so backend WIC decodes burned for art that can never paint.

## 3. New structure

- **Paint the right grid on arrival** (`gui/mainwindow.cpp::onThumbReady`): rows matching the stored path + current icon size are painted. A group switch recreates the rows, so a late arrival can never paint the wrong files. One `doItemsLayout()` when painted. Preview/middle paths unchanged.
- **Suppress invalid-size requests** (`fileThumb`): an invalid size returns the placeholder with no backend request. The visible grid re-requests at a valid size through fill/catch-up.
- **Rename**: `monitorGpu` key text only ("GPU 가속"→"모니터링 GPU가속" / "GPU"→"Monitoring GPU acceleration"). Function, key, and storage unchanged. Unrelated to the monitor tab's separate `allowGpu`.
- Regression: `ui_scroll_regression_test` phase 11 (second window + scan-free Load → 120 middle paints + real right-pane art after selection).

## 4. Result

- Right after a Load, both the middle list and the right file list show thumbnails. The right pane fills with no clicks needed.
- Undisplayable thumbnail requests no longer reach the backend in details/tree view.
- The Settings > General checkbox reads `모니터링 GPU가속`.
