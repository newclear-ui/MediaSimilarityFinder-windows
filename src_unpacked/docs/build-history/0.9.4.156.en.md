## 1. Why the change was needed

- The directive `지시/GUI 동영상 설정 탭 및 비교 프로파일 구현.md` requires a settings-dialog Video tab with short/mid/long comparison profiles. The authority docs (`architecture/video-similarity-search`, `implementation-briefs/V-video-content-matching`) assume V5 after the V0–V4 accuracy gates, but directive §5 explicitly requires wiring what the current engine supports and scoping the rest as pending gates instead of faking it.

## 2. Previous structure

- Fixed-tier sampling (`make_sample_plan`: 1/2/4/8/16/32 s), keep-all-that-passes-variance selection, and no video items anywhere in the settings propagation chain.
- `VideoBuildStats.decodedFrames` had already been corrected to the true decoded count in 0.9.4.155, securing the Probe/Kept/Decoded measurement denominator.

## 3. New structure

- **Settings UI**: Video tab added (mode combo + short/mid/long groups + uncertain-boost + partial-clip). Fifteen QSettings `video/*` keys, INI round-trip, out-of-range clamping.
- **Propagation**: `BackendScanConfig.videoPolicy` → IPC `video` object → `BackendSession::startScan` → `ScanWorker::setVideoPolicy` → engine-stored run snapshot. Unset means Auto recommended values.
- **Sampling**: short-form (≤60 s) interval rides the uniform sweep (default 5 s). Mid/long keep the legacy tiers — no local-window refinement exists yet, so long-form intervals are stored and propagated but not applied (explicitly pending).
- **Kept soft targets**: G1–G8 (5/8/9/12/11/10/12/14). Variance-ranked top-N keep with chronological restore; the 30% floor wins ties (degenerate inputs keep everything). Measured on the 8 s fixture: kept=2/decoded=80/sampled=3.
- **Cache split**: `policy` column added to `video_fingerprint_cache` + included in lookup/store (migration, no version bump). `sampling_generation` carries a policy suffix (`3:v1`) → one full re-analysis per policy change. Memory cache keyed by policy too.
- **Pending made explicit**: uncertain-boost (default ON) and partial-clip (default OFF) are engine no-ops with one backend-log line each. Nothing pretends to work.

## 4. Resolved state

- Shorts (≤60 s) run the new recommended policy. Long-form keeps the uniform sweep with kept budgets applied.
- Fingerprints from different policies can never mix (cache key + generation suffix + memory key).

- Long-form local refinement (V2/V3), selective re-extraction (V4), and the partial-clip route (V6) stay unimplemented; real-dataset accuracy measurement (V-gates) awaits user datasets.
