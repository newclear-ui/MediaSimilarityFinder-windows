# 0.9.2.10 — 빌드 로그

## 0.9.2.9 → 0.9.2.10

### 중요 변경
이번 빌드는 실시간 모니터의 **비교 인덱스 실시간 동기화**를 강화했습니다.

- 감시 루트와 비교 루트를 역할별로 구분했습니다.
- 비교 루트의 신규/변경 미디어는 중복 알림을 발생시키지 않고 해당 SQLite 인덱스를 갱신합니다.
- 삭제/이름 변경으로 사라진 비교 파일은 인덱스에서 제거합니다.
- 비교 인덱스 갱신을 위한 `MediaSearchEngine::upsertFingerprint()` / `removePath()` API를 추가했습니다.
- 감시 루트가 비교 루트와 겹치는 경우 비교 대상 파일을 알림 대상으로 잘못 처리하지 않도록 보강했습니다.
- 안정 파일 판정과 시스템 부하 보호 정책은 기존 원칙을 유지합니다.

### 테스트
- 전체 회귀 테스트: **27/27 PASS**
- CUDA Toolkit 미검출 환경에서는 CPU fallback으로 테스트했습니다.
- 실제 Windows `ReadDirectoryChangesW` 및 NVIDIA CUDA 런타임 검증은 Windows/NVIDIA 환경에서 별도 확인이 필요합니다.

### 로그 구조
빌드 히스토리는 `docs/build-history/` 아래 한글/영문 파일로 분리합니다. 최상위에는 현재 상태 문서만 유지합니다.
