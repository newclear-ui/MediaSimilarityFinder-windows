# MediaSimilarityFinder v0.9.2.69 — 툴바 정리 + 중간결과 실시간 + 요약/카운트 수정

## 변경 필요성
현장 스크린샷 12건: (1) 툴바 우측 "···"는 Qt 오버플로 버튼(공간 부족 시 자동 생성, 삭제 불가) — 붐비는 툴바가 원인, (2) 중간 검색 결과가 스캔 중·일시정지에도 표시 안 됨(중요), (3) 하단 "n/m (100%)"의 분모가 워크 중 계속 증가, (4) 검색 요약이 시간·GPU 외 "-" , (5) 삭제 버튼 명칭, (6) 상세 경로 늘어남, (7) 빈 선택 시 라벨 없음, (8) 장단 파일명 행 어긋남.

## 기존 구조
- 중간결과: `refreshStreaming()`이 매 틱 `rebuildGroups()` 전체 수행(게이트 밖) + 11k 그룹당 SQLite 디스크 읽기 + 위젯 재생성 → 페인트 기아. 일시정지는 dirty 플래그만 세워 게이트에 최대 3초 지연
- 카운트: 엔진 스트리밍 total을 분모로 사용 → 워크 중 증가하며 100% 오표시
- 요약: `updateStatusCounts`가 그룹/파일/mark만 갱신, 나머지는 종료 시에만

## 변경 구조
- **스트리밍 복구**: `rebuildGroups()` 게이트 안으로 이동. 스캔 중 fill은 행 60개까지만 실썸네일, 나머지는 DB 조회 없는 파일 아이콘 (목록 자체는 항상 표시). 일시정지는 `refreshStreaming(true)` 즉시 강제 갱신
- **고정 분모**: 워커 사전 워크(종류·무시 필터 동일, kind 판정은 엔진과 같은 `isVideoExt`)로 target emit → `targetCount` 시그널. 헤드라인은 scanned/target, 미수신 시 기존 폴백. `scan_streaming_test`에 target==4 단언 추가
- **요약 실시간**: 스캔 중 total/done/그룹/중복 실시간 기입. CPU/RAM은 모니터 타이머 영역으로 유지
- **툴바**: ⚙+☰ → ☰ 단일 메뉴(모니터 상세 설정/도움말). 검색 대상 사진/영상 개명 + 버튼 라벨에 선택 표시·단일 선택 시 굵게. GPU 허용 → "모니터 GPU"(툴팁 전체). CPU/GPU 스핀은 prefix+suffix "%"로 축소. preset에 % 병기(Maximum 90% 등). 폴더 입력 240→200
- **중간 바**: 보기 버튼 최소 110×30, 그룹 검색 최대 280·스트레치 제거
- **삭제**: "휴지통으로" 개명 + 휴지통 아이콘(fileBar). 동작은 기존 SHFileOperation(FOF_ALLOWUNDO) 그대로 휴지통 이동
- **상세**: 전체 경로를 2줄 고정 read-only 필드로(줄바꿈·드래그 선택·늘어남 없음). 빈 선택 시 9개 라벨 전부 "-" 표시
- **우측 행**: 파일명 elide 폭을 아이콘 너비로 (셀 균일)
- 버전 표기 통일 → 0.9.2.69

## 해결된 상황
