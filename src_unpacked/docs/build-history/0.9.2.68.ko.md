# MediaSimilarityFinder v0.9.2.68 — QuickLook 연동 재개

## 변경 필요성
파일 우클릭 메뉴에 QuickLook 설치 시 미리보기 항목 요구. `quicklook-paused` 브랜치(0.9.2.64 개발분)에 구현·검증됐던 작업을 현 기준선(0.9.2.67) 위로 재적용했다. 재개 과정에서 감사 지적분(_wgetenv null 가드)도 함께 반영.

## 기존 구조
- 파일 메뉴 최상단은 "열기" (전체 앱 실행). QuickLook 항목 없음

## 변경 구조
- **감지**: ProgramFiles/ProgramFiles(x86)/LocalAppData/Scoop + 제거 레지스트리(machine+user). 실행 중 파이프 존재도 감지로 겸함 (Store판은 exe 실행 불가라 실행 중에만 연동)
- **트리거**: QuickLook 네이티브 파이프 프로토콜 그대로 (`Toggle|<경로>|\n`, UTF-8). 미실행 시 exe 실행 후 최대 2.5초 대기. 메뉴는 감지·파이프 중 하나라도 있으면 최상단 표시, 없으면 숨김
- **가드**: `_wgetenv` null → 빈 문자열 (감사 지적 반영)
- `quicklook_pipe_test`: 가짜 파이프 서버 상대 정확 바이트 검증 (한글·공백 포함 60B)
- 버전 표기 통일 → 0.9.2.68

## 해결된 상황
- QuickLook 설치 PC에서 파일 우클릭 → 최상단 미리보기로 미디어 즉시 확인. 미설치 PC는 메뉴 자체가 없어 혼선 없음

- 파이프 프로토콜은 QuickLook 버전에 종속. 프로토콜 변경 시 테스트가 먼저 깨져 감지됨
