# MediaSimilarityFinder v0.9.2.43 — 중지 후 상태 복원 + 일시정지 스코프

## 변경 필요성
실머신에서 중지 버튼을 눌러도 시작 버튼으로 하이라이트가 돌아오지 않았고, 스캔이 끝나거나 끝난 뒤에도 일시정지 토글을 누르면 버튼 문구만 바뀌는(아무 동작 없음) 상태가 됐다. 일시정지는 실행 중인 자신의 스캔에만 반응해야 한다.

## 기존 구조
- `setRunning(false)`가 버튼 활성/비활성은 복원했지만 시작 버튼 포커스를 돌려주지 않았고, `scanPaused_`는 시작 시에만 초기화됐다
- `togglePauseScan`/`cancelScan`은 `worker_` 존재만 확인해서, 종료 후 잔류 워커에 대해 호출돼 UI만 바뀌는 문제가 있었다

## 변경 구조
- `setRunning(false)`에서 `scanPaused_=false` 초기화 + 일시정지 버튼 문구/체크 복원 + `scan_->setFocus()`로 시작 버튼 하이라이트 복귀. `scan_`은 `setDefault(true)`
- `togglePauseScan`/`cancelScan`에 `scanning_` 가드 추가. 일시정지는 실행 중인 스캔에만 동작
- 버전 표기 통일 → 0.9.2.43

## 해결된 상황
- 중지/완료 후 시작 버튼 하이라이트 + 누를 수 있는 초기 상태로 복귀. 일시정지 버튼은 유휴 상태에서 눌러도 무반응(비활성 유지)
