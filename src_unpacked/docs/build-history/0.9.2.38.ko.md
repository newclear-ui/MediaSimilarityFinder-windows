# MediaSimilarityFinder v0.9.2.38 — 3단 통일 UI + 비디오/무시 목록/처리량

## 변경 필요성
UI 리뷰에서 3단 통일(B안 기준), A·C 폐기, CSV 제거, 탐색기식 보기 버튼, 가운데 화면 키보드 mark가 요구됐고, 추가로 비디오 재생시간·썸네일, 처리량 표시, 별도 탭의 무시 목록이 선택됐다. 무시된 파일이 재검색에서 제외되려면 엔진 지원이 필요했다.

## 기존 구조
가운데 화면 단일 그룹 리스트(콤보 보기 전환), 상세에 재생시간 없음, 비디오 썸네일 없음, 상태바에 처리량 없음, 무시 기능 없음. `MediaFile`에 duration 없음, `ScanControl`에 제외 경로 없음.

## 변경 구조
- 엔진: `MediaFile`에 `duration` 추가(메모리 전용, 스키마 불변). `ScanControl::ignoredPaths` 추가 — 스캔 시 분석·결과에서 제외하되 DB 행은 유지하므로 무시 해제 후 재스캔하면 즉시 복원. 테스트 `scan_ignore_test` 추가 → 총 37종
- 가운데 화면: `QTabWidget` [폴더 | 결과: 이미지 (N) | 결과: 비디오 (M) | 무시 목록 (K)]. 이미지/비디오 탭이 각자 테이블+그리드 쌍 보유, 보기 모드·선택 공유 로직은 활성 쌍으로 동작
- 보기 콤보 → 탐색기식 **보기 ▾** 버튼+드롭다운(7종, 체크 동기화). 미리보기 창 항목은 우측 패널 토글
- 비디오 탭 테이블에 **재생시간** 컬럼. 필름스트립·그리드 썸네일은 첫 프레임 디코드(`VideoDecoder::frameAt`, 160px, 캐시). 상세 탭에 재생시간 행, 해상도는 `VideoDecoder::info` probe
- 상태바/상태 메시지: `NN% — 파일 — MM:SS` 경과 표시로 liveness 보장
- 무시: 파일/그룹 메뉴에 무시/무시 해제, 무시 탭(목록+해제/비우기), `QSettings(ui/ignored)` 저장, 워커에 전달. 무시 시 그룹에서 즉시 제거
- 폴더 탭: 현재 폴더+찾아보기+이 폴더로 검색+최근 폴더(최대 8)
- CSV 내보내기 삭제 (버튼·슬롯·메뉴)
- 목업B v3 갱신, A·C 삭제

## 해결된 상황
- 탭별 이미지/비디오 분리, 보기 버튼, 무시 탭, 처리량 표시 동작
- 버전 표기 통일 → 0.9.2.38

## 향후 영향
- `MediaFile.duration`은 메모리 전용. DB 영속화가 필요하면 스키마 마이그레이션(별도 버전)으로 진행
- 대용량 비디오 폴더에서 썸네일 첫 프레임 디코드는 lazy+캐시 구조 유지. 필요 시 백그라운드 프리페치로 확장
- `ScanControl::ignoredPaths`는 경로 정확 일치. 대소문자/정규화 변형은 스캐너 표준 경로 기준
