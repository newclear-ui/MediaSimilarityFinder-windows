# MediaSimilarityFinder v0.9.4.132 — Load populates the search summary

Baseline `0.9.4.131` -> this build `0.9.4.132`.
CPU CTest **125/125**, GPU CTest **126/126**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` unchanged (verdicts unchanged; CTest registration count unchanged).

## 1. Why the change was needed

- Field report: after **Load ("불러오기") the left-hand Search summary was all "-"** (the group list and status bar were fine: 9070 groups, 15135 stored matches).
- Root cause: Load answers through the `onResults(wasLoad)` path, which populates the list but never calls `refreshSummary()`. Load start resets `hasReport_=false`, no `lastStats_` exists, and a previous scan's `targetKnown_` lingers, so the panel stayed at its "-" placeholders.
- Two related problems: (1) the status bar kept the scan-path wording ("Loaded N stored matches — scanning only missing files…") even though a Load starts no scan; (2) the progress read 0%.

## 2. Previous structure

- Load completion = the wasLoad branch of `onResults`: `rebuildGroups`/list/views/`updateStatusCounts` (bottom bar) only. The left summary (`sumVal*`) was filled only by scan completion (`scanFinished`) or a `refreshSummary()` call.

## 3. Changed structure

- On Load completion the left summary is populated from the **loaded set** (`gui/mainwindow.cpp`):
  - Total files / read-complete / index-complete = loaded file count (e.g. 600), similar groups = `groups_.size()`, duplicate files = list-based sum (the 0.9.4.131 rule),
  - Pair verify = `- / N` (N = stored pairs; states that nothing was verified this session), search time = load duration.
- Load start clears `targetKnown_` (no stale scan target) and records `loadStartMs_`; completion sets `loadedSummary_`, which is cleared by the next scan answer (`onResults` scan branch) and by `scanFinished`.
- Status bar: new key `loadDone` = "Index load complete — %1 files · %2 matches" / "인덱스 불러오기 완료 — 파일 %1 · 매치 %2". Progress goes to 100%.
- Summary value labels gained objectNames for automated verification (display-only).

## 4. What was resolved

- Right after Load the summary shows total/read/indexed/similar-groups/duplicate-files/pair-verify ("- / N")/search-time, and the status bar shows the Load completion message instead of the scan wording.
- Display-only change: list, storage, verdicts and engine paths are untouched.
