# MediaSimilarityFinder v0.9.4.30 — Automatic CPU-usage 10–90% normalization

## Why the change was needed

The CPU spin box accepted `1–100`, while the Custom policy normalized CPU to
`5–100`. Entering `1–4` therefore left the typed value on screen while storing
`5` internally. This change removes that mismatch and fixes the new user CPU
range to `10–90`.

## Previous structure

- The CPU input was a single `QSpinBox`; there was no CPU slider.
- Range: `1–100`.
- User input reached `ResourceMode::Custom` through `customResourceChanged()`.
- Custom CPU values were normalized by `make_policy()` to `5–100`, while the
  Custom GPU value retained its existing internal compatibility range.
- The CPU policy was not persisted in `QSettings`; startup used Balanced `55`.
- The scheduler’s internal `cpuFloor` is a separate stability floor, not the
  same value as the user CPU cap.

## Changed structure

- `msf::kUserCpuPercentMin = 10` and `msf::kUserCpuPercentMax = 90` are declared
  as the single source of truth in `resource_policy.h`.
- `msf::normalize_user_cpu_percent()` was added and is used only for the
  user-facing Custom CPU path.
- Custom CPU input follows this rule:

```text
input < 10        → 10
10 ≤ input ≤ 90   → input unchanged
input > 90        → 90
```

- The `QSpinBox` range is also `10–90`. Handlers display the normalized value
  before creating the policy, using the existing `blockSignals` pattern so the
  corrective write does not re-enter the slot.
- Preset values are unchanged:

```text
Maximum  → 90
High     → 75
Balanced → 55
Gaming   → 25
Manual   → user input normalized to 10–90
```

- GPU percentage, GPU ON/OFF, the Adaptive Scheduler, and worker/batch formulas
  are unchanged.

## Future impact

- The user CPU setting is always `10–90`, with display and policy equal.
- Future user-CPU policy code must reuse `normalize_user_cpu_percent()`.
- The internal scheduler floor remains separate from the user policy.
- This change is unrelated to the D3 follow-up optimization and claims no
  performance improvement.
