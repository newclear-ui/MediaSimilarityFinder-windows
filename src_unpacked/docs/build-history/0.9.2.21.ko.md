# MediaSimilarityFinder 0.9.2.21

## 중요 변경
영상에도 이미지와 같은 **선택적 2차 Crop-Aware 비교 기반**을 추가했다.

### 변경 내용
- 기존 영상의 빠른 1차 단계는 그대로 normal + mirror fingerprint를 사용한다.
- 1차 단계 이후 명시적으로 요청할 때만 영상의 기존 샘플 timestamp를 재사용해 crop fingerprint를 생성한다.
- 각 샘플 프레임에 대해 4:3, 1:1, 9:16 중앙 crop과 각 mirror 변형을 생성한다.
- temporal alignment를 유지하면서 crop↔full, full↔crop, 동일 crop 비율끼리의 crop↔crop을 비교한다.
- 서로 다른 crop 비율 사이의 crop↔crop 직접 비교는 허용하지 않는다.
- 기존 video fingerprint persistent cache의 빠른 경로는 변경하지 않는다.
- 실시간 Monitor의 load gate를 우회하지 않으며, 무거운 crop 분석을 자동으로 상시 수행하지 않는다.

### 설계 효과
영상 전체를 모든 종횡비로 매번 재분석하지 않고, **normal/mirror 1차 후보 → 필요할 때만 temporal crop 2차 분석** 구조를 유지한다. 따라서 사용자가 가장 중요하게 요구한 백그라운드 작업 보호 원칙과 충돌하지 않는다.

### 테스트
- 전체 CTest: **34/34 PASS**
- 신규 `video_crop_similarity_test` 통과
- 기존 video similarity / real video decode / mirror / crop / monitor / GPU policy 회귀 테스트 모두 통과

## 유지 사항
- 실제 Windows Qt6 GUI 및 NVIDIA CUDA 런타임은 현재 Linux 테스트 환경에서 검증하지 않음.
- 영상 crop fingerprint는 이번 버전에서 선택적 2차 분석 API까지 구현했으며, 실제 SearchPipeline/Monitor의 후보 확정 후 자동 호출 통합은 다음 단계에서 진행한다.
