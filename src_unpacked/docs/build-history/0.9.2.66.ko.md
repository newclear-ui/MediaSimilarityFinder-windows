# MediaSimilarityFinder v0.9.2.66 — e2e 비디오 회귀 + EXIF 회전 + 자잘 정리

## 변경 필요성
Phase 2 항목: (1) reencode 직접호출 테스트만 있어 후보단계 탈락을 검증 불가, (2) Meta 지적 중 실재 1건 — WIC 지문경로에 EXIF orientation 미반영(표시 `setAutoTransform`과 divergence), (3) 감사 자잘(ScanCancelled 잔재·saveMatches 주석·데드 멤버·ETR pause·updateLastScan-on-cancel·Pairs 가정).

## 기존 구조
- `video_reencode_test`: `eng.build`+`video_similarity` 직접 호출. XOR→후보→temporal 전체 경로 미경유
- `decodeWicFile*` 3종(기본/aspect/컬러): 원시 프레임 디코드. 회전 휴대폰 사진이 지문과 표시가 다름
- `scanStatusText`·타이머·heartbeat가 벽시계 기준. ETR이 일시정지 중 증가
- 취소 스캔도 `updateLastScan` 기록

## 변경 구조
- **e2e 테스트**(`video_scan_e2e_test`): 원본+exact copy+libx264 reencode+3s trim+이색 control을 `MediaSearchEngine::scan()` 경유 검증. copy·reencode 필수 매치, stranger 금지, trim은 관찰 보고(게이트 정당 제외 가능). 저장 쌍도 quick-load 확인. 결과: `streamed=3 stored=3`, `trim_surfaced=0` (8s→3s trim이 게이트/DTW 기준 미달 — 정당 제외로 판정, 기준 엄격화 아님)
- **EXIF orientation**: WIC 메타데이터(274) → `FlipRotator` 8방향 매핑, 3개 레인(기본/aspect/컬러) 동일 적용. aspect 계열은 회전 후 크기로 종횡 계산. 색상 변환기 `enum` OR은 C++ 캐스트로 수정(빌드 에러 해결)
- **ETR pause 동결**: `elapsedActiveMs()`(pause 구간 제외). 진행줄·틱·heartbeat·리포트 시간 전부 통일
- **updateLastScan**: 완료 스캔만 기록
- **정리**: `ScanCancelled` 헤더 제거+주석 정정, `saveMatches` union 주석, 데드 멤버 3개 제거, Pairs complete-graph 가정 주석
- 버전 표기 통일 → 0.9.2.66
