# MediaSimilarityFinder v0.9.2.77 — 버튼 양식 통일 + 상세/그리드 침범 수정

## 변경 필요성
스크린샷 피드백: (1) ☰·사진+영상 버튼의 하단 화살표가 콤보와 달라 따로 놈, (2) 상세창 430 고정이 스플리터 이동을 막음 — 요구는 고정이 아니라 텍스트 길이에 따른 덜컹거림 방지, (3) 우측 파일 텍스트가 옆 사진칸 침범, (4) 상세 파일명·경로 표시 깨짐, (5) 하단 "619: 116"의 116이 무엇인지 불명.

## 기존 구조
- QToolButton InstantPopup: 텍스트 "▾" + 자체 화살표 이중 표시
- 우측 상세창 최대 430 고정. 파일명·경로 라벨이 폭 제한 없이 늘어남
- 우측 그리드 spacing 10, 셀 크기 제각각. groupFoot_ "N: M" 약식 표기

## 변경 구조
- **화살표 통일**: kindBtn_·utilBtn_ → MenuButtonPopup (콤보식 측면 화살표) + 클릭 시 메뉴 표시 연결
- **스플리터 이동 복원**: 430 고정 삭제. 대신 파일명·경로 라벨에 wordWrap + 수평 Ignored 정책을 걸어 할당 폭 안에서 줄바꿈 (덜컹거림 원천 제거)
- **우측 그리드**: spacing 10→2, uniform item size (한 번 레이아웃, 장단 파일명 정렬). elide는 아이콘 너비 기준 유지
- **상세 표시**: 파일명 줄바꿈+툴팁, 경로는 폴더 전용 (파일명 중복 제거)
- **groupFoot_**: `updateGroupFoot()` 신설 — "전체 619 · 선택 116" 명시 (3개 호출점 통합)
- 버전 표기 통일 → 0.9.2.77
