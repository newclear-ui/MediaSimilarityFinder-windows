# MediaSimilarityFinder v0.9.4.100 — 상세정보 원격 진단 + 파일명 견고화

기준선 `0.9.4.99` → 본 빌드 `0.9.4.100`.
CPU CTest **122/122**, GPU CTest **123/123**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` 불변.

## 1. 변경 필요성

사용자 보고: 파일 선택+체크 액션 후 상세정보 텍스트 전체가 표시되지 않는다. 0.9.4.99까지의 로컬 재현(그리드/트리/불러오기/다회 반복)은 전부 정상이어서, 실기에서만 확정 가능한 관측이 필요했다. 덤으로 백업 회전 정렬이 세 자리수 버전에서 신품을 버리는 결함을 발견했다.

## 2. 기존 구조

- `refreshDetail()` 이상 시 `msf_scan.log`에 남는 단서가 없었다.
- 상세 파일명/경로 라벨은 리치텍스트 자동 판정이라 `<>&` 포함 파일명에서 깨지거나 비어 보일 수 있었다.
- 백업 회전은 파일명 사전순에 의존했고, 주석은 0-패딩을 가정했지만 버전은 패딩이 없었다.

## 3. 변경 구조

- **원격 진단 트립와이어** (`gui/mainwindow.cpp::refreshDetail` 말미): 행 수 발산(>24), 폼 박스 붕괴/비가시/미장착, 비정상 탭일 때만 `detailAnomaly file=… rows=… box=WxH vis=… tab=…` 1줄을 `msf_scan.log`에 남긴다. 정상 run은 무음.
- **파일명 견고화**: 이름·경로 값 라벨에 `Qt::PlainText` 고정 (표시 동일, HTML 오인 제거).
- **백업 회전 수정** (`scripts/backup_src.ps1`): 버전 튜플 수치 정렬. `v0.9.4.100`이 사전순으로 `v0.9.4.99`보다 앞에 와서 신품을 휴지통에 버리는 결함 제거 (실측 확인).
- 테스트 후크 `testDetailRowCount()` (행 상한 영구 pin).

## 4. 해결된 상황

- 상세정보 이상이 재현되면 로그 1줄로 행 수·지오메트리·가시성·탭이 확정된다.
- 파일명 HTML 오인 표시가 원천 제거된다.
- 세 자리수 버전에서도 회전이 오래된 것부터 버린다.
