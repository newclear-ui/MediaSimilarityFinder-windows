# MediaSimilarityFinder v0.9.2.78 — Fixed Pre-count and Selection-Filter Alignment

## Need for change
The pre-count counted every file while the engine only sees media extensions. Result: totals and completed counts lived in different universes, so the denominator wobbled again. The earlier “fixed denominator” report moved the count earlier but did not share the actual selection rules, so image-only scans, ignored paths, and Index exclusion still diverged.

## Previous structure
- Pre-walk: no extension filter, no Index exclusion, loose ignore matching

## New structure
- **Single selection rule**: added `Scanner::isMediaPath/isVideoPath` and `Scanner::count`; listing and scan now share extension and case rules
- **Fixed denominator**: pre-counts the complete selected-media universe, including kind filters and ignored paths, once before scanning. Zero is tracked as a valid value
- **Separate progress counters**: added a `walked` callback to distinguish selected files passed by the directory walker from analyzed files. Summary, status bar, and progress percentage use the fixed denominator
- **Consistent restored results**: quick-loaded pairs and final file lists apply the same kind and ignore filters
- `scan_streaming_test` now includes non-media, video, and ignored BMP files and verifies image-only target==4
- Version strings unified → 0.9.2.78

## Resolved situation
- Image scans pre-count images, video scans videos, combined counts all media — fixed up front. "N of M" stays steady
- Analysis completion is separated from files passed by the walker, so decode latency, changed files, and incremental rescans do not make the displayed count drift

## Validation
- Core+GUI Release build: PASS, **CTest 55/55 PASS**
- `--version` 0.9.2.78, `--smoke` exit 0 (offscreen)
- CUDA algorithms unchanged (common layers only)

## Future impact
- Symlinks/permission-denied edges may differ by 1-2 files. Documented tolerance
- Pre-walk costs seconds on huge folders (unchanged behavior)
- `walked` counts files that passed the selection filters; decode failures are included. This is the intended definition of the "Scanned" counter
