# MediaSimilarityFinder v0.9.2.55 — 창 크기·배열 미복원 원인 수정(QSettings 무효)

## 변경 필요성
조절한 창 크기와 창간 배열이 재시작 후 복원되지 않았다. 조사 결과 레지스트리에 앱 설정 키가 하나도 없었고, 원인은 `main.cpp`에서 조직명/앱명을 설정하지 않아 모든 기본 `QSettings`가 조용히 실패(AccessError)했기 때문이다. Qt 문서 명시 사항이다. 창 geometry뿐 아니라 보기 모드·언어·폴더·무시목록 등 모든 설정이 매 실행 초기화되고 있었다.

## 기존 구조
- `main()`: `QApplication` 생성 후 조직명/앱명 설정 없음. NativeFormat(레지스트리) 기본값
- `saveUiState()`/`restoreUiState()` 코드는 정상이었으나 읽고 쓰는 저장소 자체가 무효라 동작 불가

## 변경 구조
- **`initAppSettings()` 신설**(`gui/mainwindow.h/.cpp`): 조직명 `newclear-ui` + 앱명 `MediaSimilarityFinder` 설정, 기본 포맷을 INI로, 저장 경로를 실행 파일 폴더로. `main()` 시작 시 1회 호출. 포터블 빌드가 레지스트리 없이 폴더와 함께 설정을 들고다니게 됨
- **크로스프로세스 프로브 테스트**(`tests/ui_settings_test.cpp`, CTest 2종): `--probe-write`(창 생성→리사이즈→파괴→INI 파일 디스크 확인)와 `--probe-verify`(별도 프로세스에서 복원 크기 확인)를 DEPENDS로 연결. 동일 프로세스 재확인은 QSettings 메모리 캐시에 속을 수 있어 프로세스를 분리한 것이 핵심
- 버전 표기 통일 → 0.9.2.55

## 해결된 상황
- 실앱 `--smoke` 실행 후 실행폴더에 `newclear-ui/MediaSimilarityFinder.ini` 생성 확인(mainGeom/splitter/헤더/kindMask/groupView 전부 기록)
- 재시작 시 창 크기·스플리터·컬럼 너비 복원. 포터블 폴더 이동해도 설정 유지
- 계측 과정에서 확인: 복원된 크기가 화면·레이아웃 최소값에 의해 조정되는 것은 정상 Qt 동작(테스트 화면 800x800 한계는 offscreen 환경 한계로 프로브는 높이로 검증)

## 향후 영향
- 기존 사용자에게는 레지스트리 잔재가 없으므로(한 번도 저장된 적 없음) 마이그레이션 불필요
- 새 UI 기본값 추가 시 QSettings 키만 쓰면 자동 영속. 단위 테스트는 같은 프로브 패턴 재사용
- 설정 파일 위치를 바꾸려면 `initAppSettings` 1곳만 수정
