# MediaSimilarityFinder 0.9.2.15

## Important Changes
- Added explicit Pause/Resume control to the resident real-time monitor.
- Added `MediaMonitor::setPaused()`, `paused()`, and `MonitorStatus.paused`.
- While paused, pending files remain queued and no analysis is performed.
- Added `Pause/Resume analysis` to the system-tray menu.
- Status display distinguishes `RUNNING / PAUSED / STOPPED`.
- Added a pause API regression test.

## Safety Principle
Protecting the user's foreground workload remains more important than real-time analysis speed. Automatic load protection and manual pause operate independently.
