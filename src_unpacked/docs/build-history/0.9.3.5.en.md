# MediaSimilarityFinder v0.9.3.5 — Engine Thumbnail Reuse + Scroll Jump Fix

## Need for change
1. The root preview cost was duplicate decoding. Scan workers already decode every
   image twice and every video frame twice, yet the GUI decoded the same files
   again for display.
2. After stopping a scan, scrolling froze and the list kept jumping to the top
   until the log popup appeared. Idle catch-up fills reset the scroll via
   `clear()` plus full rebuild.

## Previous structure
- `fileThumb`: memory → disk → failure skip → budget → shell → QImageReader/WIC/FFmpeg.
- `fillPair`: cleared and rebuilt everything without preserving scroll.

## New structure
- Scan workers also hand over display pixels.
  Images: one extra 128px color decode in the crop pass, attached to results
  (the gray fingerprint path is untouched). The engine keeps a 512-entry LRU
  (~25MB max, mutex-guarded).
- Videos reuse the existing 48px `thumb48` (memory + persistent cache, no decode).
- GUI `fileThumb` consults the engine after the disk cache and before shell/heavy
  decodes. Hits flow through the existing JPEG persistence, so they survive rescans.
- `fillPair` saves and restores tree/grid scrollbar positions around rebuilds
  (out-of-range values clamp automatically).
- Version strings unified → 0.9.3.5.

## Resolved situation
- Scanned files preview instantly via memory/DB lookup with no GUI-thread decode.
- Unscanned files keep the existing fallback chain.
- Catch-up fills no longer throw scrolling back to the top.

## Validation
- Core+GUI Release build: PASS, **CTest 59/59 PASS**
  (`image_pipeline_test` extended with a BMP fixture asserting `hasColorThumb` and
  BGRA consistency. PGM can't take the color path, hence BMP).
- Portable `--smoke` exit 0, `MediaSimilarityFinder-v0.9.3.5-Portable-Windows-x64.zip` produced.

## Future impact
- One extra color decode per image on workers slightly raises worker CPU, but total
  work drops as repeated GUI decodes disappear.
- The engine LRU is rebuilt per scan (worker-owned) and lives while the worker lives.
