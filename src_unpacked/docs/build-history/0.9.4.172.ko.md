`kEngineVersion 1.5.2` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 11` / `kProtocol 1` (모두 불변).

## 1. 변경 필요성

- 사용자 지시(`지시/동영상 Temporal Anchor 판독 방식 신규 구현 — 기존 V3 보존 및 병렬 비교.md`): 현행 V3(DTW)를 LegacyV3로 보존하고, 선행 삽입(광고·인트로·블랙 리더)을 허용하는 독립 판독 방식 `TemporalAnchorV1`을 추가한다. 단순 점수 보정·임계 조정이 아니라 본편 시작점 탐색부터 장기 앵커 검증까지의 독립 경로다.
- 근거: `lead-prefix-discrimination` 현장 보고서 §11 — V3는 시작 오프셋 미흡수(Miss C1)와 평탄 공유 지문 오탐(False Alarm C1)으로 리더 쌍을 판정하지 못한다.

## 2. 기존 구조

- `video_similarity()` 현행 DTW 비교, V3 segmented kept가 production 기본값.
- V2 구조 프로브·V4 커버리지는 진단·검증 계보 유지.
- `video_sampling.*`, `video_decoder.*`, `video_policy.h`가 샘플링·정책 진입점.

## 3. 변경 구조

- 신규 모듈 `src/temporal_anchor.{h,cpp}` (msf_core): `TemporalAnchorIndex` (compact 시간 지문), `buildTemporalAnchorPlan()` (조밀 1fps, 단일 sequential sweep — 성긴 윈도우로는 45초 리더 같은 중간 오프셋을 커버할 수 없음이 실측으로 확정되어 탐색 기질을 조밀화; 디코드 자체는 어차피 전체 파일을 읽으므로 추가 디코드 없음), `makeTemporalAnchorIndex()` (32x32 pHash+미러+평균/분산/변화량), `findLeadingOffset()` (순서 보존·미러 허용·단일 프레임 거부·평탄 과다사용 금지, 첫 질감 구간부터 탐색, 양방향, 복수 후보+기본 (0,0) 가설 병행), `temporalAnchorSimilarity()` (§3.2~§3.6 + §5 판정: DUP는 복수 본편 앵커+오프셋 일관, ending/크레디트만으로 확정 금지, 부족하면 UNCERTAIN).
- 판독 전략 식별자: `LegacyV3` (기본값) / `TemporalAnchorV1` (실험 opt-in). `VideoPolicy.readStrategy` + GUI 동영상 탭 콤보 + QSettings `video/readStrategy` + IPC JSON + backend 파싱 + 스캔 snapshot. 신규 trStr 키 4종 (ko/en).
- 엔진: `VideoFingerprintEngine::buildAnchorIndex()` (독립 sweep, 영속 캐시 없음). `build()`는 `readStrategy==TemporalAnchorV1 && MSF_VIDEO_ANCHOR==1`일 때만 앵커 sweep을 추가 측정하고, 그 외에는 바이트 동일 (V3 지문·캐시 불변).
- 텔레메트리(가산·보고 전용): `VideoBuildStats.anchorBuilt/anchorFrames/anchorMs` + `TemporalAnchorResult` 전 항목 (§6 목록: strategyId, probe, start, offset, anchors, drift, ending, verdict, decode/compare 시간 등).
- 테스트: `tests/video_temporal_anchor_test.cpp` (합성 전용 13핀: 플랜, 리더 탐색·양방향·단일/역순 거부·미러, DUP 게이트, 상이 DIFF, 평탄 UNCERTAIN, ending-only 비확정, 공유 리더 비확정, 드리프트 검출·비강제, 숏폼 UNCERTAIN, 실 index 빌드).

## 6. 향후 영향 및 한계

- 판정 불변 (기본 경로 바이트 동일, 엔진/DB/schema/cache 불변 — 저장 쌍 재검증 없음).
- **Gate PASS 선언 안 함**: 선행 광고 삽입본 검출률은 장편 2/5 DUP + 2 UNCERTAIN으로 개선됐으나, 숏폼은 UNCERTAIN 위주(0 DUP)이고 HDR 동일-콘텐츠 쌍·드리프트/트림/배속 매트릭스·중간 삽입 branch·크레디트 판별이 미측정/미구현이다. 기본값 승격 없음.
- 알려진 한계: 어두운 오프닝/본편의 pHash 불안정 (L02), 단일 프레임 87.5 strictness, ending은 NoCredits/Uncertain만 판별 (PreCredits 예약), anchor JSON 집계는 후속 (결과 구조체+작업로그 기록).
- 롤백: GUI에서 LegacyV3 선택 (기본값) + `MSF_VIDEO_ANCHOR` 미설정. V3 행과 anchor 산출물은 식별자가 달라 혼합 불가.
