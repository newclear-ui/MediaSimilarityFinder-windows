# 0.9.2.19 — Center-Crop Second-Stage Candidate Foundation

## IMPORTANT CHANGE

Added 4:3, 1:1, and 9:16 centered-crop fingerprints for images and dedicated crop CandidateIndexes. This allows cropped versions that may not survive the normal global-hash candidate filter to enter a second-stage comparison path.

### Changes
- Added an aspect-preserving low-resolution image decode path.
- Generate 4:3 / 1:1 / 9:16 centered crops and normalize each to 32×32 before pHashing.
- Generate mirrored fingerprints for each crop.
- Added six crop fingerprint columns to SQLite with automatic migration for existing databases.
- Added three image crop CandidateIndexes to reduce candidate pairs before final comparison.
- Real-time Monitor now generates and persists the same crop fingerprints for image events.
- Final image comparison emphasizes full↔full, crop↔full, and same-ratio crop comparisons to avoid unnecessary cross-ratio comparisons.
- Videos retain the existing fast normal/mirror path in this build; centered video crops will be implemented with the later temporal second-stage design.

## Rationale

The system does not perform expensive arbitrary crop searches on every media item. Image crop signatures are generated at scan time and indexed cheaply; detailed similarity is evaluated only for candidates. The first supported aspect ratios are 4:3, 1:1, and 9:16. Off-center crops can be added later only when needed.
