# MediaSimilarityFinder v0.9.2.70 — 이미지 오탐 2차 검증 게이트

## 변경 필요성
전혀 다른 두 사진이 유사도 85%로 매칭되는 오탐 보고. 원인 확정: pHash는 32×32 DCT 저주파 8×8만 사용하고, `bestMatch()`는 full·미러·크롭 변형 수십 쌍 중 최대값을 취하는 단일 게이트다. 어둡고 평탄하며 색감이 비슷한 두 사진은 저주파 우연 일치로 Hamming D≤8(87.5%)에 쉽게 들어간다. 이미지는 비디오와 달리 검증 단계(L2/L3)가 없어 그대로 확정됐다.

## 기존 구조
- 후보 → `bestMatch()` 최대값 → 임계 통과 시 즉시 확정. 구조 검증 없음

## 변경 구조
- **`verifyImagePair` 신설** (`src/image_verify.h/.cpp`): 97 이상은 디코드 없이 즉시 확정(완전중복 UX·기존 테스트 보호). 그레이존은 64×64 디코드 후 full + 중앙 4:3/1:1/9:16 영역 SSIM(뒤집기 포함 최대값)으로 0.5·Hamming + 0.5·SSIM 재채점, 임계 미달이면 탈락. 디코드 실패는 Hamming 유지(레거시), 비디오는 그대로 통과(temporal L2/L3 소유)
- **3개 emit점 적용**: `addAndMatch`, `analyze`, `compareFingerprint`(monitor 경로, query 경로 있을 때만)
- `frame_ssim`을 끝단 버림(floor windows)으로 완화 (36px 9:16 영역 대응). 기존 테스트의 w=0/null 거부는 유지
- `image_verify_test` 신설(결정적 7케이스: 고속경로·블렌드 승인·오탐 절삭·폴백 2종·비디오 통과·빈경로). 버전 표기 통일 → 0.9.2.70

## 해결된 상황
- 스캔 임계 87.5 기준: H=90·이종 사진(SSIM≈0.2)은 약 55로 탈락, H=90·동일 사진(SSIM≈1)은 95로 유지. 보고된 형태의 오탐이 게이트에서 걸러짐
- 완전중복·미러·중앙크롭 진검출은 고속경로/영역 SSIM으로 보존
