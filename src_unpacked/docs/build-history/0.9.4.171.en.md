## 1. Why the change

- User directive (Korean-only file `지시/동영상 길이·구조 기반 샘플링 설계 재검토 및 미구현 기능 구현.md`): implement the length/structure-based sampling designed in Architecture §§4–7, 10–13 and V Brief §§4–7, 10 but missing from the production engine. End goal: GUI settings actually drive timeline selection, structure detection, and representative-frame generation.
- §3 checklist (pre-implementation code review, recorded in worklog): (1) `make_sample_plan()` uniform intervals only, (2) `selectKeptSegmented()` uniform 4 segments, (3) `probeVideoStructure()` diagnostic-only, (4) V2 output consumed nowhere, (5) `longStruct/longPrecise` never read by the engine, (6) `uncertainBoost/boostFrames` explicit no-ops, (7) no production credits/last-scene path.
- Constraint: long-form accuracy gates are unpassed, so unvalidated accuracy parts stay diagnostic/opt-in and the production path is preserved (directive §8). No baseless engine/DB/cache version bumps (directive §7).

## 2. Previous structure

- `build()`/`buildFull()`: `shortIv=(duration<=60)?shortIntervalSec:0` + uniform `make_sample_plan()` sweep. Long-form intervals were stored, propagated, and telemetered but never read by the engine.
- Kept selection: default `selectKeptSegmented()` (uniform 4 segments, no variance floor — known P1), rollback `MSF_VIDEO_KEPT=legacy`, cache identity `+seg/+var`.
- V2 probe: ran only under `MSF_VIDEO_STRUCTURE=1`, reporting to `VideoBuildStats` only.

## 3. New structure

- `make_cohort_plan(duration, policy, structured)` (video_sampling.*): default (`structured=false`) delegates byte-identically to the legacy sweep. The structured path (`structured=true`) merges opening detail (0–30 s at `longStructIntervalSec`), main-start candidates (30/60/90/120/180 s), reverse-from-T endpoints (`T-15 s/30 s/1/2/4/8/12/20 min`, computed from T then sorted ascending), and last-60 s refinement (`longPreciseIntervalSec`) into the base, sorts, dedups (1 ms), and decodes in ONE sequential sweep. No random seeks, no reverse playback (E-3B `ExactnessPolicy::RefuseAll` stands). With default intervals, G1/G2 extras collapse exactly onto the base.
- `videoStructuredSamplingEnabled(policy)`: true only under `MSF_VIDEO_STRUCTURE=full` or non-default long-form GUI intervals. Default Auto policy stays on the legacy path.
- `selectKeptStructured()` (video_structure.*): one best-variance frame per structure segment, then global-rank fill with a `kMinVariance=6.0` floor (low-information frames never forced; soft target — fewer than target is valid). The caller falls back to uniform segmented when `confidence < 0.30` or unprobed (`structWindows=0`).
- `processVideoFrames(..., structure)`: structured selection when a usable structure is supplied, otherwise the previous path byte-identically. `build()` runs the V2 probe on the already-decoded 96x96 frames (no extra decode) and consumes it with confidence fallback. `buildFull()` follows the same plan.
- Cache identity: `videoKeptPolicyId()` — default returns the legacy string byte-identically (`v1+seg`, `+var`); only the structured path appends `+struct:<hash>` (covers the long intervals). Default users never rebuild. Engine/format unchanged (same mechanism as 0.9.4.168: method changes isolated by cache suffix).
- `uncertainBoost`/`boostFrames`/`partialClip` stay explicit no-op logs (V4/V6 scope, unimplemented).
- Telemetry (additive, report-only): `VideoBuildStats.cohortId/cohortStructured/structWindows` (benchmark JSON aggregation deferred to V-gate validation).

## 4. Resolved state

- Short-form (≤60 s, defaults): structured on/off fingerprints identical (collapse, asserted). Long-form (130 min example): base 245 → structured 271 probes (+26 opening/reverse/refinement).

## 6. Future impact and limits

- Verdicts unchanged (default path byte-identical; engine/DB/schema/cache unchanged — no stored-pair re-verification).
- Accuracy gates unmeasured: the 50-file short-form field set is not claimed to validate long-form policy. Long-form evaluation awaits the user-supplied 30 min / 1 h / 1 h+ paths. Boundary detection rate, candidate recall, and precision/recall are unmeasured.
- `MSF_VIDEO_STRUCTURE=full` diagnostic opt-in; default production path preserved. Rollback: unset the env var (coexists with default `+seg` rows, no rebuild) + `MSF_VIDEO_KEPT=legacy`.
- Next: after receiving user long-form paths, validate with the §8 cohort set (opening/main/ending/credits boundary rates, kept mean/p95, time/cache accounting); promote to default in a separate build only after passing.
