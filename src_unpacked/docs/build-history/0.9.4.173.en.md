## 1. Why the change

- User directive (`지시/TemporalAnchorV2` …, Korean-only): keep the V1 forward search and add a **reverse ending search**. Anchors counted back from the main-content end are cross-checked against forward anchors, and when a mid-roll insertion shifts the offset the timeline splits into per-segment relations. Same-content judgement from temporal structure, not a score tweak.
- Defects deliberately NOT inherited from V1 (directive §2): ScanPipeline not connected, duplicate full-decode sweep, single-valid-frame confirmation, low-info frames counted as evidence, long-form fixed anchor spacing, unused estimatedContent, never-assigned PreCredits, score/verdict mismatch, hasty DIFF on dark scenes.
- V3 stays the production default. V2 remains experimental until validated.

## 2. Previous structure

- V1 (`src/temporal_anchor.{h,cpp}`, 0.9.4.172): forward start search, mid anchors, consecutive-frame verification, low-info filtering. V1 functions are behavior-frozen in this build.
- V3 (DTW) segmented kept is the production default. Engine/DB/schema/cache unchanged.

## 3. New structure

- V2 API (`temporalAnchorSimilarityV2`, `TemporalAnchorV2Result`, `findLeadingOffsetV2`, `findEndingProbe`, `anchorCentersForDuration`, `anchorVerdictScore/For`): shares the index type with V1 but a separate orchestration, so V1 results stay comparable.
- Bidirectional search: forward opening probe + reverse ending search (never judges credits by blackness alone; never mistakes dark HDR/fade-out — PreCredits only with edge-elevated evidence), anchors counted back from the ending, forward/reverse offset agreement.
- Length policy: micro ≤13 s (start/middle/end), ≤60 s (scaled thirds), ≤25 min (start/center/late/end), long-form (forward 5/10/15 min + reverse 5/10/15 min pre-end).
- Segments: 1 by default, at most 2 on verified drift. A partial-segment match alone never confirms DUP.
- Unified verdict (single definition shared by code/tests/docs): score = 40·min(validMain,2) + 10·consistent + 10·endingSupport (capped at 100). DUP only with validMain≥2 + consistent offsets + no covered-failed mains + no drift + no content-ratio flag + score≥87.5. Low-info frames excluded from evidence (≥2 non-low frames required). Darkness without counter-evidence stays UNCERTAIN, never DIFF.
- Union single sweep (§7): the V3 plan merged with the anchor plan serves both the V3 print and the anchor index in one sequential sweep. V3 consumes only its own timestamps, so armed and unarmed builds yield byte-identical V3 prints (asserted by the file test). Persistent cache format untouched (anchors are memory-only).
- Real product-path wiring (§8): the ScanPipeline flush worker compares only when armed (strategy opt-in + `MSF_VIDEO_ANCHOR=1`) and both indexes are in memory, recording additive `videoAnchor*` telemetry only. V3 verdicts are untouched, so armed scans yield identical match sets (asserted by the scan test).
- GUI: TemporalAnchorV2 entry in the video-tab strategy combo (LegacyV3 default unchanged), QSettings/IPC/backend mapping, 1 new tr key.
- Tests: 13 synthetic pins (mapping table, single-frame non-evidence, low-info exclusion, length policy, credits detected/not-detected, bidirectional leader DUP, mid-roll UNCERTAIN + 2 segments, dark UNCERTAIN, shared-ending non-confirmation, ratio flag, no double-count), real-decode file test (union==separate, V2 DUP/offset, stranger non-DUP, disarmed no-index), scan-path test (LegacyV3 vs armed V2 identical match sets).

## 6. Future impact and limits

- Verdicts unchanged: default path byte-identical, engine/DB/schema/cache unchanged — no stored-pair re-verification. Armed scans keep identical match sets.
- **No gate PASS, no default promotion**: HDR same-content (L02-lead), the 180 s leader edge, flat openings, beyond-2-segment mid-rolls, real-file PreCredits, and threshold calibration remain unvalidated/follow-up. Unvalidated parts stay diagnostic/opt-in.
- Known limits: dark-opening/HDR pHash instability, single-frame 87.5 strictness, endings mostly NoCredits/Uncertain (PreCredits only with edge evidence), 180 s leaders missed by both strategies.
- Rollback: select LegacyV3 in the GUI (the default) + unset `MSF_VIDEO_ANCHOR`. Anchor artifacts are memory-only, so nothing persists.
