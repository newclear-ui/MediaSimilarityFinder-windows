# MediaSimilarityFinder v0.9.2.43 — Post-Stop State Restore + Pause Scope

## Need for change
On-machine: after Stop, the highlight never returned to Start, and the pause toggle could be pressed after a scan ended, changing only its own label with no effect. Pause must act solely on its own running scan.

## Previous structure
- `setRunning(false)` restored button enablement but not Start focus, and `scanPaused_` reset only on start
- `togglePauseScan`/`cancelScan` checked only `worker_`, so they acted on the leftover worker after finish, changing UI state with no effect

## New structure
- `setRunning(false)` resets `scanPaused_`, restores pause text/check, and returns focus to Start via `scan_->setFocus()`. `scan_` is `setDefault(true)`
- `scanning_` guard added to `togglePauseScan`/`cancelScan`. Pause only affects a running scan
- Version strings unified → 0.9.2.43

## Resolved situation
- After stop/finish, Start is highlighted and pressable as at launch. The pause button stays inert when idle

## Validation
- Core Release build: PASS, **CTest 39/39 PASS**, `--smoke` exit 0, `--version` 0.9.2.43
- On-machine click behavior needs user-side confirmation

## Future impact
- Button-state rule: `setRunning()` is the single entry point. New action buttons put their enable conditions there
