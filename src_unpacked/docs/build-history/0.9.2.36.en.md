# MediaSimilarityFinder v0.9.2.36 — Explorer-Style UI Rewrite (Grid+List, KO/EN)

## Need for change
The pre-0.9.2.36 GUI was a single-panel layout that could not host the requirements (Explorer-like 3 panes, live results during scan, mark/context menu, view switching, KO/EN). Re-scans showing `analyzed=0` looked like "search is broken" because the status text never explained it. Engine probes first proved scan/pause/cancel/incremental-skip all correct; the UI was then rewritten.

## Previous structure
Single `QSplitter` (folder input + result list + status). Results appeared only after scan end, strings hard-coded (mostly English), no mark, no detail tabs, pause/resume buttons always in the same state.

## New structure
`gui/mainwindow.h`/`.cpp` rewritten (no CMake change — same two files build):
- Top: folder select/path/refresh/scan·pause·resume·stop/preset/CPU·GPU/monitor toggle/language combo/settings/help
- Left: favorites + This PC (drives) + network folder tree (lazy expansion), scan summary panel (total/done/groups/duplicates/time/GPU/CPU/RAM/monitor)
- Middle: duplicate-group list (group/file count/similarity/size), sort, group search, CSV export
- Right: group detail — grid (`QListWidget` icon mode, checkbox marks, filename·size·resolution·similarity%) ↔ list (`QTreeWidget`, 7 columns), zoom slider, file action bar, detail tabs (details/EXIF/similarity/hash), preview + metadata
- Live streaming: worker batches `ScanControl::onMatch` → `matchesArrived` signal → GUI thread accumulates groups via union-find, views refresh on a 600 ms timer. The `SearchMatchRef` compact path stays for a future virtualized model
- KO/EN: `trStr()` string table + settings/toolbar combo, instant switch without restart, persisted in `QSettings(ui/language)`
- Context menu: open/reveal/copy/cut/paste/move/rename/delete (Recycle Bin)/mark family/analyze. Deleted/moved files are pruned from groups
- Explicit completion message: "Already up to date" when `analyzed==0 && unchanged>0`
- `main.cpp --smoke`: headless CI hook (offscreen window + 3 s event loop)
- Monitor (tray/status/settings/match popup) behavior kept; status moved to the summary panel instead of hijacking the status bar
