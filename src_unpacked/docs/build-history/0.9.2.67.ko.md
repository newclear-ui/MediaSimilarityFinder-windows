# MediaSimilarityFinder v0.9.2.67 — L3 SSIM 검증 셀 + thumb48 캐시 v5

## 변경 필요성
Phase 3 (Grok): L1을 통과한 쌍 중 같은 저주파·다른 장면의 오탐을 pHash Hamming만으로 가르기 어렵다. 정렬된 프레임 쌍에 96×96급 구조 유사도(SSIM)를 채점하는 검증 레이어가 필요했다. 단, SSIM은 키가 아니라 채점 함수이므로 후보 단계가 아닌 DP 셀에 둔다.

## 기존 구조
- `video_similarity()` DP 셀이 `hash_similarity` 단일 점수. 캐시 v4에는 픽셀이 없어 구조 비교 불가

## 변경 구조
- **`thumb48`**: kept 프레임당 48×48 그레이(2304B), `hashes[]`와 1:1. build 시 96×96 crop 패스를 2×2 box 다운샘플 (추가 디코드 없음). 96 패스 누락분은 0 채움으로 정렬 유지
- **캐시 v5**: v4 + thumbCount + thumbs. `kCacheFormatVersion=5`, 기존 v4 행 전량 폐기(1회 전체 재빌드). thumb 불일치 행은 reject, thumbCount 0은 Hamming-only 허용 (손으로 만든 지문·구행 호환)
- **SSIM 셀**: 균일 8×8 윈도우 MSSIM, [0,1] 클램프. B측은 1회 뒤집어 `max(SSIM, SSIM-flip)` (미러 대응). Hamming 미달 셀은 기존 거부 경로 그대로(SSIM 비용 0). 통과 셀만 0.4·Hamming + 0.6·SSIM 재채점. 전역 평탄(무thumbs) 셀은 Hamming-only로 레거시와 동일
- `crop_temporal_score`는 Hamming 유지 (crop 해시 셀 구조라 픽셀 없음). 최종 `max()`라 SSIM 게이트와 병립
- `frame_ssim()` 순수 함수로 분리 + `video_ssim_test` (identity≈1, 흑백≈0, 변형 중간값, 폴백 동등, 노이즈 삭감 증명). `video_cache_test` v5 갱신
- 버전 표기 통일 → 0.9.2.67
