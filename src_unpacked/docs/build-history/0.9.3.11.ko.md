# MediaSimilarityFinder v0.9.3.11 — cache quick identity 검증

## 변경 필요성
- size와 modification time이 보존된 파일 교체 시 Video fingerprint, image verification, thumbnail cache가 stale 결과를 재사용할 가능성이 남아 있었다.

## 기존 구조
- 검색 DB 변경 판정에는 quickHash가 반영됐지만, 개별 cache key는 path/size/mtime 중심이었다.

## 변경 구조
- Video memory/SQLite cache, image verification LRU, persistent thumbnail cache에 파일 앞부분 64KB FNV quick identity를 추가했다.
- Video cache schema에 `quick_hash`를 추가하고 cache format을 v8로 올렸다.
- Thumbnail DB schema version을 `1.0.3`으로 올렸다.

## 해결된 상황
- 동일 path·size·mtime 파일 교체 시 기존 fingerprint, SSIM buffer, thumbnail을 그대로 재사용하지 않는다.
- 기존 cache row는 quick identity 불일치로 miss 처리되고 새 결과로 갱신된다.
