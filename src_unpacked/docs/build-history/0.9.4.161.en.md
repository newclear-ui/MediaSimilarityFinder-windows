# MediaSimilarityFinder v0.9.4.161 — Decode-Stage Cost Split Measurement (P1)

Baseline `0.9.4.160` → this build `0.9.4.161`.
CPU CTest **134/134**, GPU CTest **134/135 + 1 unrelated timing flake green on retry** (no new CTest; assertions added to existing tests).
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 10` / `kProtocol 1` all unchanged.

## 1. Why the change was needed

- External review P1: per-file decoded/sampled/kept existed, but decode time, grayscale-convert time, pHash time, and MSSIM time were not measured separately, so cost attribution on decode-bound runs (e.g. the 55-minute scan) was impossible.

## 2. Previous structure

- `VideoBuildStats` held only decoded/sampled/kept + cacheHit + planner + gpuMs. Sweep wall time and CPU pHash time went nowhere.
- `TelemetryRecorder::addVideo` aggregated counts, bytes, frames, and build time only. Stage splits existed for images only (D4a per-boundary).

## 3. New structure

- `VideoBuildStats` gains `decodeMs` (sweep wall time: decode + grayscale convert, both planner paths) + `phashCpuMs` (CPU pHash compute only, 0 when the GPU batch covers everything). Cache hits record 0 for both (measured zero, same contract as `decodedFrames`).
- New `TelemetryRecorder::addVideoStages(decodeMs, phashCpuMs)` (existing `addVideo` signature untouched) + `videos.decodeMs`/`decodeMsState` and `phashCpuMs`/`phashCpuMsState` JSON keys (additive, schema unchanged). Reset in `start()`, so no cross-run inheritance.
- Called per file from the `media_search_engine` analyze path under `telemetryOn`.
- Regression pins: `analyze_telemetry_test` gains measured/not_measured contract assertions (recorded values → measured; no calls → null + not_measured). `video_complete_test` baseline gains `decodeMs>0`, `phashCpuMs>=0`, fresh-prime-miss assertions (real-engine end-to-end).
- Per-pair MSSIM match-path timing (CPU fallback / GPU) is excluded — that path has no `stats` plumbing, so both call sites would need changes; left as a separate task.

## 4. Resolved state

- Future field-scan logs decompose per-file `buildMs` into `decodeMs + phashCpuMs + remainder (GPU, DTW, overhead)`.
