# MediaSimilarityFinder v0.9.4.103 — 체크 우선 파일 액션 + 파일바 구분선

기준선 `0.9.4.102` → 본 빌드 `0.9.4.103`.
CPU CTest **122/122**, GPU CTest **123/123**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` 불변.

## 1. 변경 필요성

사용자 요청 2건 (상세정보 건은 다음 빌드로 유예):

1. 우측 창에서 복수 체크 후 하단 복사/잘라내기/붙여넣기/이동/휴지통 버튼을 누르면 체크된 전체가 아니라 하이라이트 1개에만 액션이 일어난다. 체크된 파일이 있을 때는 그것을 우선 대상으로 한다. 열기/탐색기에서 보기는 1개 파일 그대로 유지한다.
2. 상세 상단 메뉴에서 탐색기에서 보기 다음에 구분선을 넣는다 (상단 회색 세로막대 1픽셀형). 최종 순서: 열기, 탐색기에서 보기, 구분선, 복사, 잘라내기, 붙여넣기, 이동, 휴지통.

## 2. 기존 구조

- 복사/잘라내기/이동/휴지통은 `selectedFiles()`(하이라이트/선택)만 봤고 체크박스(`marked_`)를 무시했다. 붙여넣기는 클립보드 기반이라 체크와 무관했다.
- 파일바 액션은 구분선 없이 7개 연속이었다.

## 3. 변경 구조

- **`actionFiles()` 신설**: 체크가 하나라도 있으면 전체 체크 집합(결정적 순서로 정렬), 없으면 기존 하이라이트 선택. 복사/잘라내기(`cutPaths_` 포함)/이동/휴지통이 사용한다. 열기/탐색기에서 보기/붙여넣기/토글/무시/분석 경로는 손대지 않는다 (열기/탐색기는 1개 파일, 붙여넣기는 클립보드 그대로).
- **구분선**: 탐색기에서 보기 다음에 `addSeparator()`, 파일바 스타일 `1px #8c8c8c` (상단과 같은 회색). 최종 순서 지시대로.
- 테스트 후크 `testActionFiles()`.

## 4. 해결된 상황

- 체크된 파일이 있으면 복사/잘라내기/이동/휴지통이 체크 전체에 동작하고, 잘라내기→붙여넣기 흐름도 체크 집합을 잇는다. 체크가 없으면 기존과 동일하다.
- 파일바에 열기/탐색기에서 보기와 나머지 액션 사이 구분선이 보인다.
