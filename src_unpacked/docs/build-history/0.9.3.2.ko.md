# MediaSimilarityFinder v0.9.3.2 — 벤치마크 토글(1.0 제거 예정)

## 변경 필요성
- 매 검색마다 벤치마크를 돌려 자료를 수집하고, 코드 개선·잘못된 빌드를 확인하려면
  켜고 끌 수 있는 일시 옵션이 필요했다. 1.0 완성에서는 제거가 목표다.

## 기존 구조
- 벤치마크가 항상 동작했고 끌 방법이 없었다.

## 변경 구조
- 검색 버튼 옆에 벤치마크 체크박스를 추가했다(기본 켜짐, 한/영 `benchToggle`).
  체크 상태가 `ScanWorker::setBenchmark` → `ScanControl::benchmarkEnabled`로 전달된다.
- 엔진은 플래그가 꺼지면 레코더를 시작하지 않고 이전 데이터를 리셋한다.
  이미지 배치에는 레코더 대신 null을 넘겨 타이밍·통계 오버헤드가 남지 않는다.
  비디오·단계 시간 기록도 건너뛴다. 팝업은 데이터가 있을 때만 뜬다.
- 1.0 제거 시 삭제 대상: 체크박스·setter·플래그·게이팅 분기. 동작 자체는 기본 켜짐이라
  제거 후에도 현재 동작과 동일하다.
- 버전 표기 통일 → 0.9.3.2.

## 해결된 상황
- 체크 해제 시 벤치마크 스레드·타이머·팝업 없이 스캔이 동작하고, 결과는 동일하다.

## 검증
- Core+GUI Release 빌드: PASS, **CTest 59/59 PASS**
  (`search_engine_test`에 토글 OFF 커버리지 추가: 동일 결과 + `hasBenchmark()==false`).
- 포터블 `--smoke` exit 0, `MediaSimilarityFinder-v0.9.3.2-Portable-Windows-x64.zip` 생성.

## 향후 영향
- 1.0에서 제거 예정. 제거 후 기본 동작은 현재 체크 켜짐 상태와 동일하다.
