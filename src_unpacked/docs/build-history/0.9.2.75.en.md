# MediaSimilarityFinder v0.9.2.75 — Toolbar, Detail, and Summary UI Round

## Need for change
Ten screenshot-driven UI feedback items: unclear monitor-pause button, monitor button auto-opening settings, menu button placement/size, doubled arrows on view/kind buttons, detail path intrusion, trash labeling, monitor-GPU checkbox placement, summary monitor row/RAM meaning/GPU-CPU display.

## Previous structure
- Monitor pause button (analysis suspend, watcher alive) overlapped start/stop. Monitor button auto-opened settings when unconfigured. Small menu button left of monitor
- View/kind QToolButtons showed text "▾" plus their own drawn arrow
- Detail full path as a lone QTextEdit box, repeating the filename already shown above
- Summary monitor row always "-" without monitor. CPU/RAM rows only lived while monitoring. GPU row static "GPU"/"CPU" text

## New structure
- **Pause deleted**: button, slot, and members removed. Engine `setPaused` API and its test stay
- **Pure monitor toggle**: settings auto-open removed; unconfigured clicks show guidance. Checked state paints green bold highlight
- **Menu docked right**: after the spacer, font +4, bold, minimum 58×32
- **View as combo**: QToolButton+menu → QComboBox (same form as the preset combo, single arrow). Language/tab sync kept
- **Kind button**: label "▾" dropped (own arrow remains). Photos/Videos naming kept
- **Detail path**: folder-only QLabel (no filename repeat), wraps, drag-selectable, same look as other rows. Detail pane capped at 430
- **Trash**: fileBar icon dropped, "Move to Trash" text (behavior unchanged: FOF_ALLOWUNDO)
- **Monitor GPU**: moved next to the monitor button
- **Summary**: monitor row deleted. CPU row shows live process usage (GetProcessTimes, core-normalized), RAM row shows working set (GetProcessMemoryInfo) — both meaningful now. GPU row shows on/off, visible only while accelerating
- Version strings unified → 0.9.2.75

## Resolved situation
- One fewer toolbar button, state readable from highlight, menu more reachable
- Detail intrusion gone. Summary fully live during scans

## Validation
- Core+GUI Release build: PASS, **CTest 54/54 PASS**
- `--version` 0.9.2.75, `--smoke` exit 0 (offscreen)
- CUDA algorithms unchanged (common layers only)

## Future impact
- Unconfigured monitor button only guides to the menu. Settings live under ☰
- CPU% samples at 600ms so it jitters. Task Manager remains the precise reference
