## 1. 변경 필요성

사용자 요청 3건:

1. 상단바의 사진/영상 선택 하이라이트 토글 2개를 왼쪽 자원량 선택 메뉴 같은 드롭다운 1개로 통합한다 (1번째 사진, 2번째 영상, 3번째 모두).
2. 유사그룹 체크박스로 mark를 선택하면 기준파일(대표이미지)을 빼고 나머지 전부를 선택한다 (이동·휴지통 이동 대상).
3. 그룹 체크박스 선택→취소 후 목록에서 파일을 선택하면 하단 상세정보(경로·이름·크기)가 사라지는 버그를 수정한다.

## 2. 기존 구조

- 사진/영상 토글 버튼 2개 + 둘 다 OFF 금지 강제 로직. 스캔 범위(`scanImages/scanVideos`)는 버튼 상태에서 읽었다.
- 그룹 체크박스(`setGroupMarked`)는 그룹 전 파일을 mark했고, 행 상태도 전수 기준이었다.
- `refreshDetail()`은 `QFormLayout::takeAt()` 루프로 행을 지웠다. 빈 행이 레이아웃에 남아 `rowCount()`가 매 갱신마다 ~9씩 영구 증가했고, 실제 행이 아래로 밀려 보였다/안 보였다.

## 3. 변경 구조

- **종류 드롭다운** (`gui/mainwindow.cpp`, `gui/mainwindow.h`): `kindBox_` (사진/영상/모두, 기존 `kindImages`/`kindVideos` + 신규 `kindAll` 키). 단일 선택 구조라 OFF 금지가 사라진다. `ui/kindMask` 비트값(1/2/3) 그대로 저장·복원, 스캔 범위도 동일 매핑. 토글 버튼 멤버 삭제.
- **대표 제외 마크**: `setGroupMarked(..., true)`는 `paths[0]`을 건너뛰고 나머지만 mark, 해제는 전체 해제(취소 의미). 행 상태는 `groupMarkState()`로 통일(신규 helper): 기준 제외 전수 mark면 Checked. 생성(`addGroupItems`)·동기화·스페이스 토글 모두 같은 규칙을 탄다. "모두 Mark" 메뉴(`markAll`)는 손대지 않는다.
- **상세정보 소실 수정**: `refreshDetail()` 시작 시 폼 객체를 통째로 교체한다 (위젯 회수 후 레이아웃 삭제 → 재생성, 안정 `QLayout` 규약에만 의존). `takeAt`/`removeRow`의 소유권·빈 행 문제를 밟지 않는다.
- 테스트 후크 `testMarkedPaths()`, `testDetailFileName()`.

## 4. 해결된 상황

- 종류 선택이 드롭다운 1개(사진/영상/모두, 기본 모두)다. 스캔 범위는 기존과 동일.
- 그룹 체크 1회로 대표 제외 전부가 mark되어 이동·휴지통 메뉴 바로 가능. 해제는 전체 해제.
- 체크→취소→파일 선택 후에도 경로·이름·크기가 표시된다. 폼 행 수가 발산하지 않는다.
