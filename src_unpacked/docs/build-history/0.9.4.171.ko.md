## 1. 변경 필요성

- §3 확인표(구현 전 코드 대조, worklog 기록): (1) `make_sample_plan()` 균일 간격만 생성, (2) `selectKeptSegmented()` 균등 4구간, (3) `probeVideoStructure()` 진단 전용, (4) V2 결과 미연결, (5) `longStruct/longPrecise` 엔진 미사용, (6) `uncertainBoost/boostFrames` 명시적 no-op, (7) 크레디트/마지막-본편 구분 production 경로 없음.
- 제약: 장편 정확도 Gate 미통과 상태이므로 미검증 정확도 부분은 진단/opt-in으로 유지하고 기존 production 경로를 보존한다 (지시 §8). 근거 없는 engine/DB/cache version bump 금지 (지시 §7).

## 2. 기존 구조

- `build()`/`buildFull()`: `shortIv=(duration<=60)?shortIntervalSec:0` + `make_sample_plan()` 균일 sweep. long-form interval은 저장·전파·텔레메트리만 하고 엔진이 읽지 않았다.
- kept 선택: 기본 `selectKeptSegmented()` (균등 4구간, variance floor 없음 — P1 기지정), 롤백 `MSF_VIDEO_KEPT=legacy`, 캐시 식별 `+seg/+var`.
- V2 프로브: `MSF_VIDEO_STRUCTURE=1`에서만 실행, `VideoBuildStats` 보고만.

## 3. 변경 구조

- `make_cohort_plan(duration, policy, structured)` (video_sampling.*): 기본(`structured=false`)은 레거시 sweep에 바이트 동일 위임. 구조화 경로(`structured=true`)는 base에 오프닝 세밀(0~30초, `longStructIntervalSec`), 본편 시작 후보(30/60/90/120/180초), 역방향 엔드포인트(`T-15초/30초/1/2/4/8/12/20분`, T 기준 계산 후 오름차순 정렬), 마지막 60초 세밀(`longPreciseIntervalSec`)을 병합·정렬·중복제거(1ms) 후 단일 sequential sweep으로 디코드한다. random seek·역재생 없음 (E-3B `ExactnessPolicy::RefuseAll` 유지). G1/G2 기본값에서는 추가분이 base와 완전히 겹쳐 collapse한다.
- `videoStructuredSamplingEnabled(policy)`: `MSF_VIDEO_STRUCTURE=full` 또는 long-form interval 비기본값(GUI 명시 설정)일 때만 true. 기본 Auto 정책은 레거시 경로 그대로.
- `selectKeptStructured()` (video_structure.*): 구조 segment당 최고 분산 1장 + 전역 순위 충원, 충원에는 `kMinVariance=6.0` floor 적용(저정보 강제충원 금지, soft target — 목표 미달이 정상). `confidence < 0.30` 또는 미probe 시 호출자가 균등 segmented로 폴백 (`structWindows=0`).
- `processVideoFrames(..., structure)`: 구조 사용 가능 시 구조화 선택, 아니면 기존 경로 바이트 동일. `build()`는 디코드된 96x96 위에서 V2 프로브를 실행(추가 디코드 없음)하고 신뢰도 폴백으로 소비한다. `buildFull()`도 동일 평면.
- 캐시 식별: `videoKeptPolicyId()` — 기본은 기존 문자열 바이트 동일(`v1+seg`, `+var`), 구조화 활성 시에만 `+struct:<hash>` (long interval 포함). 기본 사용자는 재구축 없음. 엔진/포맷 불변 (0.9.4.168 선례와 동일: 선택방식 변경은 캐시 접미사로 격리).
- `uncertainBoost`/`boostFrames`/`partialClip`은 명시적 no-op 로그 유지 (V4/V6 범위, 미구현).
- 텔레메트리(가산·보고 전용): `VideoBuildStats.cohortId/cohortStructured/structWindows` (benchmark JSON 집계는 V-gate 검증 시).

## 4. 해결된 상황

- 지시 §3의 7개 항목 중 5·6·7번의 엔진 미연결이 해소됐다 (구조화 경로에서 long interval 소비 + 구조 윈도우 kept). 단 기본값에서는 의도적으로 레거시와 동일하게 동작한다.
- P1(segmented variance floor 없음): 구조화 경로에서 해소 (floor + soft target). 기본 segmented의 기지정은 검증 후 승격까지 유지한다.
- 숏폼(≤60초, 기본값): 구조화 on/off 지문 동일 (collapse, 단언). 장편(130분 예시): base 245 → 구조화 271 probe (+26, 오프닝/역방향/세밀 추가분).
