# MediaSimilarityFinder v0.9.2.54 — 폴더 가로스크롤·XL 기본보기·UI상태 복원·프로그레스 스로틀·High 모드·멀티코어 개선

## 변경 필요성
현장 보고 6건: (1) 좌측 폴더 탐색기에 가로 스크롤바가 없어 긴 경로 확인 불가, (2) 유사그룹 초기 보기가 큰 아이콘이어서 매번 아주 큰 아이콘으로 바꿔야 함, (3) 조절한 창 크기·창간 배열이 재시작 후 복원되지 않음, (4) 일부 코어만 작업에 할당됨, (5) Maximum에서 UI가 멈춤(응답 없음·창이동/일시정지/종료 불가), (6) Maximum과 Balanced 사이에 중간 단계 요구(CPU/GPU 75% 목표).

## 기존 구조
- 폴더 트리(`folders_`): 헤더 숨김 + 단일 컬럼이 뷰포트에 맞춰 늘어나 `stretchLastSection` 기본값 때문에 가로 스크롤이 영원히 안 나타남
- 그룹 보기 기본값 `QSettings("ui/groupView", 1)` = 큰 아이콘
- 저장되는 UI 상태: 창 geometry + 메인 스플리터뿐. 트리/리스트 컬럼 너비 미저장
- 이미지 CPU 폴백 해시 루프(`media_pipeline.cpp`)가 배치 스레드에서 직렬 실행. 디코드 워커 상한 16
- `control_.progress`가 분석 파일마다 emit → 큐 시그널 → `scanProgress`가 파일마다 setText/setValue/`updateStatusCounts`(전체 그룹 순회). Maximum 속도에서 GUI 이벤트루프가 매몰되어 멈춤
- 자원 모드 4종(Maximum 90 / Balanced 55·60 / Gaming 25 / Custom). 콤보 인덱스+1 = enum 매핑

## 변경 구조
- **폴더 가로스크롤**: `header()->setStretchLastSection(false)` + `ResizeToContents` → 컬럼이 내용 너비로, 넘치면 가로 스크롤 표시
- **초기 보기 XL**: `ui/groupView` 기본값 1→0, 무효값 클램프도 0으로
- **UI 상태 저장/복원 확대**: `saveUiState()`/`restoreUiState()` 신설. geometry+스플리터에 더해 imgTree/vidTree/list 헤더 상태 저장. 소멸자에서 저장, `buildUi+applyStaticTexts` 후 복원
- **프로그레스 스로틀**: worker 스레드에서 최신 done/total/path를 멤버에 보관하고 150ms 간격으로만 emit. 스캔 종료 시 최종값 flush. 일시정지/취소/닫기가 항상 반응
- **High 모드**: enum 재정렬(Maximum=1, High=2, Balanced=3, Gaming=4, Light=4, Custom=5) + `make_policy` High→75/75. 콤보에 "High" 추가(Maximum 다음), 기본 Balanced 인덱스 2, Custom 인덱스 4. 기존 i+1 매핑 유지. `resource_policy_test`에 High 단언 추가(75/75, 16스레드→12워커, batch 64→48)
- **멀티코어**: 디코드 워커 상한 16→32, CPU 폴백 pHash+미러 루프를 `parallelFor`로 병렬화
- 버전 표기 통일 → 0.9.2.54

## 해결된 상황
- 긴 폴더 경로 가로 스크롤로 확인 가능. 시작부터 아주 큰 아이콘. 창·스플리터·컬럼 너비 복원
- Maximum에서도 프로그레스 표시가 최대 ~7Hz라 UI 응답 유지. GPU 없는 환경의 CPU 해시와 32스레드급 머신의 디코드가 전 코어 활용
