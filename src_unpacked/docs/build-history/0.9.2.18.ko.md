# 0.9.2.18 — Mirror Candidate Index 최적화

## 중요 변경

좌우 반전 검색을 위한 별도 mirror-only BK-tree를 제거하고, 기존 이미지/동영상 CandidateIndex 하나에 일반 fingerprint와 mirror fingerprint를 함께 저장하도록 정리했다.

### 변경 사항
- 이미지/동영상별 CandidateIndex는 일반+반전 fingerprint를 함께 보유한다.
- 비교 시 일반 fingerprint와 mirror fingerprint의 최대 2회 후보 질의만 수행한다.
- 중복 후보는 index 기준으로 즉시 제거한다.
- 기존 4가지 normal/mirror 조합의 최종 유사도 계산 의미는 유지한다.
- SQLite 스키마 및 기존 mirror fingerprint 데이터와 호환된다.
- 검색 엔진 회귀 테스트에 실제 반전 후보 검색을 추가했다.

## 설계 의도
별도의 mirror-only 인덱스는 동일한 mirror fingerprint를 중복 저장하면서 후보 검색 횟수를 늘렸다. 하나의 transform-aware BK-tree에 두 표현을 함께 저장하면 normal→normal, normal→mirror, mirror→normal, mirror→mirror 네 조합을 두 번의 인덱스 질의로 모두 커버할 수 있다.

## 검증
Linux Release core build 및 전체 테스트를 수행한다. CUDA/Qt6 Windows 런타임은 이 환경에서 검증하지 않는다.

다음 단계는 계획대로 중앙 크롭 기반 2차 후보 검색 구조(4:3, 1:1, 9:16)다.
