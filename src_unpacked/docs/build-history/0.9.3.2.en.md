# MediaSimilarityFinder v0.9.3.2 — Benchmark Toggle (Temporary, Remove in 1.0)

## Need for change
- Collecting data on every test scan, and catching regressions or bad builds,
  needs a temporary on/off option. Removal is planned for the 1.0 release.

## Previous structure
- The benchmark always ran with no way to disable it.

## New structure
- A benchmark checkbox sits next to the Scan button (default on, KO/EN `benchToggle`).
  Its state flows `ScanWorker::setBenchmark` → `ScanControl::benchmarkEnabled`.
- With the flag off, the engine never starts the recorder and resets stale data.
  Image batches get a null recorder (no timing/stat overhead), and video and stage
  times are skipped. The popup only appears when data exists.
- Removal targets for 1.0: the checkbox, setter, flag, and gating branches. Default-on
  behavior is identical to post-removal behavior.
- Version strings unified → 0.9.3.2.

## Resolved situation
- Unchecked scans run with no benchmark thread, timers, or popup, with identical results.

## Validation
- Core+GUI Release build: PASS, **CTest 59/59 PASS**
  (`search_engine_test` gains toggle-OFF coverage: same results + `hasBenchmark()==false`).
- Portable `--smoke` exit 0, `MediaSimilarityFinder-v0.9.3.2-Portable-Windows-x64.zip` produced.

## Future impact
- Scheduled for removal in 1.0. Post-removal default behavior equals today's checked state.
