# MediaSimilarityFinder 0.9.2.16

## 주요 변경

- 실시간 모니터 설정 전용 GUI 추가
- 감시 폴더를 개별 추가/삭제
- 비교 폴더를 개별 추가/삭제
- 모니터 전용 유사도 임계값 설정
- 안정화 대기 시간 설정
- 비-Windows 폴백 폴링 간격 설정
- 모니터 분석의 GPU 사용 허용 여부 설정
- 모니터 시작 시 저장된 설정을 사용하도록 변경

## 설계 의도

기존의 세미콜론 입력 방식 대신 실제 폴더 목록을 관리하는 대화상자를 사용하여 여러 드라이브/폴더를 운영할 때 설정 오류를 줄인다. 일반 검색의 tolerance와 실시간 모니터의 유사도 임계값을 분리하여 모니터 정책을 독립적으로 관리한다.

## 검증

Core Release 빌드 및 테스트를 현재 개발 환경에서 수행한다. 실제 Windows + Qt6 + NVIDIA CUDA GUI/런타임 검증은 Windows 대상 환경에서 별도로 필요하다.
