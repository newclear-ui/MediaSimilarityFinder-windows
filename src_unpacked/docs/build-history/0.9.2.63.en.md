# MediaSimilarityFinder v0.9.2.63 — Disk Thumbnail Cache + Favorites/Dedup/Filename/Resolution/0B Fixes

## Need for change
Four screenshot reports: (1) same folder twice in favorites, (2) middle group pane shows file icons only (right pane shows real photos), (3) misaligned rows with mixed long/short filenames, (4) "-" resolution in details.

## Previous structure
- (2) Thumbnail memory cache resets every scan start. Quick-loaded groups restart as placeholders and re-decode 11k files through the budget (tens of minutes). The right pane's 3 files decode instantly within budget — the asymmetry
- (1) Recent-folder dedup compared exact strings, so separator/case variants stored separately
- (3) Full filenames in fixed 3-line cells; long names wrap and break row heights
- (4) Single `QImageReader::size()` path. Plugin-less formats (PNG etc.) guaranteed "-"

## New structure
- **Disk thumbnail cache** (`thumbs` table: path/PK, mtime, size, JPEG): successful decodes stored as 192px JPEG; rescans display instantly via indexed SQLite reads (no budget). mtime/size mismatch goes stale and re-decodes. Index orphans pruned at scan end (`pruneThumbs`). Second GUI-only connection (WAL-safe, failures ignored)
- **Favorites normalization**: `cleanPath` + case-insensitive compare on store; defensive render-side dedup
- **Filename elision**: one middle-truncated line in the right grid (full path stays in tooltip). Rebuilt immediately on zoom
- **Resolution fallback**: ffprobe header probe on QImageReader failure (no decode; verified `64,48` parsing). Cached permanently, one-time cost. WIC `GetSize` direct call AVs on valid frames (headless-confirmed, root cause open) so it was not adopted — recorded as an unsolved mystery
- **0 B fix**: `fileSizeCached()` live-stats unindexed files once, then caches. Loaded groups show real sizes
- Version strings unified → 0.9.2.63

## Resolved situation
- Previous thumbs show instantly on rescan. First scans still fill progressively (budget kept)
- One entry per folder. Long names one line + hover full path. Resolutions mostly shown. Loaded groups sized
