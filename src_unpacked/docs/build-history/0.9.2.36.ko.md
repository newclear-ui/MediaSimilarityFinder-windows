# MediaSimilarityFinder v0.9.2.36 — 탐색기형 UI 재작성 (그리드+리스트, 한영)

## 변경 필요성
0.9.2.35까지의 GUI는 단일 패널 구조라 요구사항(탐색기형 3분할, 검색 중 실시간 결과, mark/컨텍스트 메뉴, 보기 전환, 한영 전환)을 담을 수 없었다. 재스캔 시 `analyzed=0`인 이유가 상태 메시지에 드러나지 않아 "검색이 동작하지 않는다"는 오해를 샀다. 엔진 레벨 프로브로 스캔·pause·cancel·증분 건너뛰기가 모두 정상임을 먼저 입증한 뒤 UI를 재작성했다.

## 기존 구조
단일 `QSplitter` (폴더 입력 + 결과 리스트 + 상태). 결과는 스캔 종료 후 일괄 표시, 한영 하드코딩(영어 위주), mark 없음, 상세 탭 없음, 일시정지/계속 버튼이 항상 같은 상태로 표시됨.

## 변경 구조
`gui/mainwindow.h`·`cpp` 재작성 (CMake 변경 없음 — 동일 2파일 빌드):
- 상단: 폴더 선택/경로/새로고침/검색·일시정지·계속·중지/프리셋/CPU·GPU/모니터 토글/언어 콤보/설정/도움말
- 왼쪽: 즐겨찾기+내 PC(드라이브)+네트워크 폴더 트리(지연展开), 검색 요약 패널(총 파일/완료/그룹/중복/시간/GPU/CPU/RAM/모니터)
- 가운데: 유사 그룹 리스트(그룹/파일 수/유사도/크기), 정렬·그룹 검색·CSV 내보내기
- 오른쪽: 그룹 상세 — 그리드(`QListWidget` 아이콘 모드, 체크박스 mark, 파일명·크기·해상도·유사도%) ↔ 리스트(`QTreeWidget` 7컬럼) 전환, 줌 슬라이더, 파일 액션바, 상세 탭(상세/EXIF/유사도/해시), 미리보기+메타데이터
- 실시간 스트리밍: `ScanControl::onMatch`를 워커에서 배치 수집 → `matchesArrived` 시그널 → GUI 스레드에서 union-find로 그룹 누적, 600ms 타이머로 뷰 갱신. `SearchMatchRef` compact 경로는 향후 가상화 모델용으로 유지
- 한영: `trStr()` 문자열 테이블 + 설정/툴바 콤보, 재시작 없이 즉시 전환, `QSettings(ui/language)` 저장
- 컨텍스트 메뉴: 열기/탐색기에서 보기/복사/잘라내기/붙여넣기/이동/이름바꾸기/삭제(휴지통)/Mark 계열/분석. 파일 삭제·이동 후 그룹에서 제거(prune)
- 완료 메시지 명시화: `analyzed==0 && unchanged>0`이면 "이미 최신 상태입니다" 표시
- `main.cpp --smoke`: headless CI용 offscreen 기동 검증 훅 (3초 이벤트 루프)
- 모니터(트레이/상태/설정/매치 팝업) 동작 유지, 상태 표시줄 하이재킹 대신 요약 패널로 이동
