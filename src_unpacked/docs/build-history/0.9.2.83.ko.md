# MediaSimilarityFinder v0.9.2.83 — 시작 실패 자가진단(플랫폼 플러그인 사전 점검)

## 변경 필요성
- 포터블 배치는 0.9.2.82에서 수정했고 깨끗한 환경 검증도 통과했지만, 사용자 PC에서 여전히 `no Qt platform plugin` 오류가 보고됐다.
- 로컬 패키지가 정상이므로 실패는 실행 환경 쪽(구버전 실행·zip 내부 직접 실행·exe만 복사 등)일 가능성이 높았다. 그러나 기존에는 Qt가 `QApplication` 생성자에서 강제 종료돼 원인 안내가 불가능했다.

## 기존 구조
- `main()`이 인자 해석보다 먼저 `QApplication`을 생성했으므로, 플러그인이 없으면 어떤 안내도 없이 Qt 치명 오류 대화상자로 끝났다.
- `--version`조차 `QApplication` 생성자를 거치느라 플러그인 없이는 동작하지 않았다.

## 변경 구조
- `QApplication` 생성 전에 경량 사전 점검을 수행한다: `platforms/qwindows.dll`(신 배치) 또는 `Qt6/plugins/platforms/qwindows.dll`(구 배치) 중 하나라도 있으면 정상 진행한다.
- 없으면 콘솔이 있을 때 `missing-platform-plugin` 표식을 남기고, 원인+대처(끝까지 압축 해제·폴더째 복사·실행, zip 내부 직접 실행 금지)를 담은 한/영 대화상자를 표시한 뒤 exit 1로 종료한다.
- `--version`/`--help`는 Qt 없이 먼저 처리하므로 플러그인과 무관하게 항상 동작한다.
- 판정 로직·CUDA 알고리즘 변경 없음. 버전 표기 통일 → 0.9.2.83.

## 해결된 상황
- 플러그인 누락 시 기존의 모호한 Qt 오류 대신 구체적인 대처 안내가 표시된다.
- 완전 패키지 실행은 그대로 exit 0이다.

## 검증
- Core+GUI Release 빌드: PASS, **CTest 56/56 PASS**
- 양성 검증: 완전 패키지 `--smoke` exit 0 (최소 PATH·플러그인 경로 미설정)
- 음성 검증: exe+DLL만 있는 디렉터리에서 `--smoke` 실행 시 exit 1로 종료(Qt 강제 종료 코드가 아님). 비대화형 세션이라 대화상자는 표시되지 않았으나 종료 경로가 가드를 거쳤음을 확인했다.
- `MediaSimilarityFinder-v0.9.2.83-Portable-Windows-x64.zip` 생성

## 향후 영향
- 사용자 PC에서 오류가 재현되면 표시되는 안내대로 전체 압축 해제 여부를 먼저 확인하면 된다.
- 실행한 파일이 `MediaSimilarityFinder-v0.9.2.83-Portable-Windows-x64.zip`의 완전 해제본인지 확인이 필요하다(구버전 zip·빌드 산출물 직접 실행은 지원 대상이 아님).
