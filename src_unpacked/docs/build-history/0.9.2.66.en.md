# MediaSimilarityFinder v0.9.2.66 — E2E Video Regression + EXIF Rotation + Cleanups

## Need for change
Phase 2 items: (1) only direct-call reencode tests existed, blind to candidacy misses; (2) the one real Meta finding — EXIF orientation missing from the WIC fingerprint path (divergent from display `setAutoTransform`); (3) audit leftovers (ScanCancelled remnant, saveMatches comment, 3 dead members, ETR pause, updateLastScan-on-cancel, Pairs assumption).

## Previous structure
- `video_reencode_test`: direct `eng.build`+`video_similarity`. Never traversed XOR→candidacy→temporal
- `decodeWicFile*` trio (plain/aspect/color): raw frames. Rotated phone photos fingerprinted differently than displayed
- `scanStatusText`, tick, heartbeat, report times all wall-clock. ETR grew while paused
- Cancelled scans still recorded `updateLastScan`

## New structure
- **E2E test** (`video_scan_e2e_test`): original + exact copy + libx264 re-encode + 3s trim + stranger control, all via `MediaSearchEngine::scan()`. Copy and re-encode must match, stranger must not; trim reported observably (legitimately excludable). Stored pairs quick-load checked. Result: `streamed=3 stored=3`, `trim_surfaced=0` (8s→3s trim below gate/DTW bar — legit exclusion, not bar-raising)
- **EXIF orientation**: WIC metadata (274) → `FlipRotator` 8-way mapping, applied identically to all 3 lanes (plain/aspect/color). Aspect lanes size from post-rotation dimensions. Color-converter enum ORs fixed with C++ casts (build error resolved)
- **ETR pause freeze**: `elapsedActiveMs()` (pause intervals excluded). Progress line, tick, heartbeat, report times unified
- **updateLastScan**: completed scans only
- **Cleanups**: header `ScanCancelled` removed + comment fixed, `saveMatches` union comment, 3 dead members removed, Pairs complete-graph assumption documented
- Version strings unified → 0.9.2.66

## Resolved situation
- Full candidacy→temporal path covered e2e. Fingerprint/display agree on rotated photos. ETR frozen on pause. Cancelled scans no longer claim freshness
