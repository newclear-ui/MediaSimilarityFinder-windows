# 0.9.2.8 — 빌드 로그

## 0.9.2.7 → 0.9.2.8

**중요 변경:** 시스템 트레이 상주형 실시간 미디어 중복 감시의 첫 구현 단계입니다.

### 구현
- 다중 감시 폴더 / 비교 인덱스 구조 추가
- 파일 크기와 수정 시간이 일정 시간 유지되는지 확인하는 Stable-file Detector 추가
- CPU·메모리·GPU 사용률을 확인하는 System Load Monitor 추가
- 부하가 높으면 분석을 보류하여 사용자의 작업을 우선 보호
- Windows 감시 스레드를 `THREAD_PRIORITY_LOWEST`로 실행
- 기존 `MediaSearchEngine`의 영구 인덱스를 이용한 신규 파일 fingerprint 비교 API 추가
- 이미지와 비디오 모두 실시간 fingerprint 분석 경로 추가
- 시스템 트레이에서 모니터 시작/중지/폴더 설정 가능
- 유사 파일 발견 시 새 파일 열기 / 기존 파일 탐색기 표시 / 새 파일 휴지통 이동 / Skip 제공
- Skip 항목은 SHA-256 기반 키로 설정에 저장
- 기존 파일과 자기 자신을 비교하는 경우를 제외

### 설계상 보수적 선택
이번 버전은 이식성과 안정성을 우선하여 폴더 polling을 기본 감시 방식으로 사용합니다. Windows native filesystem event API와 CandidateIndex 직접 재사용은 다음 단계에서 최적화합니다.

### 검증
- 핵심 관련 회귀 테스트 8/8 PASS
- CandidateIndex benchmark: N=6000, indexed 1708.25 ms, linear 5847.09 ms, 약 3.42x
- CUDA toolkit은 현재 빌드 환경에서 없어 CPU backend로 구성됨
- Qt6 Windows GUI와 실제 NVIDIA GPU 런타임은 현재 환경에서 검증하지 못함
