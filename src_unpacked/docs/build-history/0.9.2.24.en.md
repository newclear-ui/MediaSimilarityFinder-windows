# MediaSimilarityFinder 0.9.2.24

## IMPORTANT CHANGES

### Monitor stability and recovery hardening
- Coalesces consecutive filesystem events for the same path into one pending job.
- Resolves removal/create-modify races so stale removal work cannot delete a newly recreated file.
- Preserves pending state across Pause/Resume and deferred scheduling.
- Adds a maximum retry count (`maxRetries`, default 8) for stability/load deferrals.
- When the retry limit is reached, only that file is reported as failed; the monitor continues running.
- Records the last error path and message in `MonitorStatus`.

## Workload protection
The existing foreground workload protection and LoadState policy remain unchanged. The monitor analysis thread continues to run at low priority on Windows.
