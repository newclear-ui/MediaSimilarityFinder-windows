# MediaSimilarityFinder v0.9.4.136 — 미리보기 크기 게이지: 1.0 기준선 + 드래그 비율 + 리스트 보기 비활성

기준선 `0.9.4.135` → 본 빌드 `0.9.4.136`.
CPU CTest **125/125**, GPU CTest **126/126**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` 불변 (판정 불변, 표시 전용).

## 1. 변경 필요성

- 실기 요청: 우측 패널의 미리보기 크기 게이지(슬라이더)에 ① 미리보기 크기의 기준인 **1.0 지점을 가시적으로 표시**(옅은 회색 세로 기준선 등), ② **드래그 도중 비율**(0.5, 1.1, 1.5 …) 표시, ③ **리스트 보기**로 전환하면 게이지를 회색으로 바꾸고 **이동 불가(비활성)**.
- 기존에는 1.0(기본 128px)의 위치를 알 수 없었고, 드래그 중 현재 배율 표시가 없으며, 리스트 보기에서도 슬라이더가 활성 상태로 남아 오해를 유발했다.

## 2. 기존 구조

- `zoom_`은 범용 `QSlider`(48..256, 기본 128, 폭 130). `zoomChanged(v)`가 파일 그리드 아이콘 크기를 바꾼다. `setViewMode(0/1)`은 스택(그리드/리스트)만 전환하고 슬라이더 상태는 건드리지 않았다.

## 3. 변경 구조

- **ZoomSlider**(QSlider 서브클래스, gui/mainwindow.h/.cpp):
  - `setReferenceValue(128)` 기준(1.0×)에 **옅은 회색 세로선 + 작은 삼각 틱**을 그린다. 비활성 시 알파를 낮춰 흐리게.
  - 핸들 드래그 중(mousePress~mouseRelease) 핸들 위에 **비율 버블**(`value / 128`, 소수 1자리: 0.5/1.1/1.5)을 그린다. 핸들 위치는 groove/핸들 메트릭으로 추적하고 위젯 경계로 클램프. 버블 공간을 위해 최소 높이 30.
  - 마커·버블은 QStyle의 groove 좌표를 사용하므로 스타일이 바뀌어도 위치가 일관된다.
- **리스트 보기 비활성**: `setViewMode(i)`가 `zoom_->setEnabled(i == 0)`을 호출 — 리스트 보기에서는 Qt 비활성 스타일로 **회색 + 값 변경 불가**, 그리드 복귀 시 재활성.
- 신규 툴팁 키 `zoomTip`("미리보기 크기 (1.0 = 기본)") — 언어 전환 시 갱신. objectName `zoomSlider`(자동화 훅).

## 4. 해결된 상황

- 게이지에서 1.0 기준 위치가 즉시 보이고, 드래그 중 배율을 숫자로 확인할 수 있다. 리스트 보기에서는 게이지가 회색·비활성이라 "효과가 없는 조작"이 사라졌다.
