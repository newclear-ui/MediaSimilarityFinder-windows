# MediaSimilarityFinder v0.9.4.12 — Node C4: Calibration Gate

C4 검증 기준점. 기능 추가 없이 프롬프트의 17조합을 증거에
연결하고 Node C를 닫는다. 엔진 1.5.0·DB 1.0.3·캐시 v9·schema 2 불변.

## 변경 필요성
- C1~C3의 증거가 각 버전 history에 흩어져 있어, 게이트 판정에 필요한
  17조합 커버리지를 한눈에 확인할 수 없었다. 감사 결과 갭 2건이
  있었다.

## 기존 구조
- 실패 후보의 수용 판정이 엔진 람다 내 인라인 조건이었다(테스트 불가).
- Exact 장기 재사용 무발화가 명시 단언이 없었다.

## 변경 구조
- `calibrationUsableForUpdate()` 헬퍼 신설: 엔진이 쓰던 조건과
  동일식. 엔진 람다는 호출로 교체(동작 동일).
- C4 추가 단언: Exact 10연속 무발화, 실패/부분 후보 불가 판정,
  실패 시 파일 무수정 reload 동일, usable 후보 통과.
- 17조합 매핑(아래 검증 참조). 판정 경로·정책 변경 없음.

## 선택 이유
- 게이트는 새 기능이 아니라 증거 연결이다. 코드 변경은 테스트
  가능성을 위한 최소 추출 1건으로 한정했다.

## 해결된 문제
- Node C 종료. 다음 게이트 D.

## 정확성 영향

## 호환성 영향
