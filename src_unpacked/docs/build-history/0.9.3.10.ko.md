# MediaSimilarityFinder v0.9.3.10 — 그룹 목록 스크롤 anchor 복원

## 변경 필요성
- thumbnail catch-up과 streaming refresh 중 그룹 widget 전체를 재생성하면서, 아래로 스크롤한 목록이 선택 그룹 복원 과정에서 그룹 1번으로 되돌아가는 현상이 남아 있었다.

## 기존 구조
- `fillPair()`가 pixel scrollbar 값만 저장했다.
- 목록 재생성 중 `setCurrentItem()`이 선택 그룹으로 viewport를 이동한 뒤, 이전 pixel offset을 복원하려고 했다.
- item layout이 완료되기 전 offset을 적용하면 Qt가 값을 다시 clamp할 수 있었다.

## 변경 구조
- 재생성 전 tree/grid viewport 상단 item의 그룹 ID를 anchor로 저장한다.
- 재생성 후 선택 그룹 처리와 무관하게 같은 anchor 그룹을 `PositionAtTop`으로 복원한다.
- anchor를 찾을 수 없는 초기/빈 목록만 기존 pixel offset을 fallback으로 사용한다.

## 해결된 상황
- 아래로 스크롤한 그룹 목록이 catch-up refresh 후 그룹 1번으로 반복 이동하지 않는다.
- 검색·정렬·thumbnail refresh의 기존 전체 rebuild 구조는 유지했다.

## 검증
- GUI target 및 thumbnail/UI regression targets Release 빌드: PASS.
- 실제 목록 스크롤 장시간 자동 테스트는 아직 없음.

## 향후 영향
- 향후 item-level icon 갱신으로 전체 rebuild를 제거하면 이 anchor 보정은 fallback 안전장치로 남는다.
