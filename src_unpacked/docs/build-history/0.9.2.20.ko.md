# MediaSimilarityFinder 0.9.2.20

## 중요 변경
이미지 Crop-Aware 2차 비교를 정밀화했다.

### 변경 내용
- 4:3, 1:1, 9:16 crop fingerprint를 각각 독립된 비율 그룹으로 비교.
- Full ↔ Crop 비교는 유지.
- Crop ↔ Crop은 동일한 종횡비끼리만 비교.
- 4:3 ↔ 1:1, 1:1 ↔ 9:16 등 임의의 crop↔crop 교차 비교를 차단해 오탐 가능성을 낮춤.
- mirror fingerprint를 각 crop 비율별로 함께 처리.
- crop 후보 검색과 최종 similarity 계산의 의미를 동일하게 정렬.

### 테스트
- 전체 CTest: 33/33 PASS
- crop fingerprint 회귀 테스트 강화
- crop-aware SearchEngine 후보 검색 테스트 추가
- 서로 다른 crop 비율만 가진 항목이 동일하다고 판정되지 않는 회귀 테스트 추가
- 기존 mirror / video / monitor / GPU policy 테스트 모두 통과

## 유지 사항
- 영상은 0.9.2.19와 동일하게 normal + mirror 빠른 경로 유지.
- 실시간 Monitor의 사용자 작업 보호(load gate)는 변경하지 않음.
- 실제 Windows Qt6 GUI 및 NVIDIA CUDA 런타임은 이 Linux 테스트 환경에서 검증하지 않음.
