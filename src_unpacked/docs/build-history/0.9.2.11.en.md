# MediaSimilarityFinder 0.9.2.11 — Build History

## IMPORTANT CHANGE
The resident real-time monitor queue was upgraded to a condition-variable based deferred scheduler.

### Main changes
- Replaced idle polling sleeps with condition-variable waiting to reduce unnecessary CPU wake-ups.
- Added exponential backoff when analysis is deferred because a file is still changing or system-load protection is active.
- Maximum retry delay is capped at 30 seconds.
- New file events wake the worker immediately when work becomes available.
- Stopping the monitor wakes waiting threads for fast shutdown.
- Retry state is cleared after successful analysis, comparison-index updates, and removal handling.
- Added a scheduler-specific regression test.

## Design intent
For real-time monitoring, protecting foreground user workloads is more important than minimizing analysis latency. The scheduler prevents busy loops when a download is still being written or the system is under heavy load.
