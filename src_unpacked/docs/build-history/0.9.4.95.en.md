`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` unchanged.

## 1. Why

Three user requests:

1. Keep the 0.9.4.94 Stable-rescan log review (`detailed-log-2026-10-13T200015.json`) as an **example measurement record**.
2. Keep recording later scan measurements taken with **other settings** in the same format.
3. **Show** the pair-verify total count and verified count in the GUI's bottom-left search summary panel (result-oriented: total = candidate pairs, verified = confirmed duplicate pairs).

## 2. Previous structure

- The left summary panel had only total / read-complete / index-complete / groups / dup files / time / GPU / CPU / RAM rows. Pair-verify input (`verifyCalls`) and output (`pairs`) lived only in the detailed-log JSON, invisible at a glance after a scan.
- The user-dataset measurement record ended at `database-verification-benchmark` §7.1 (0.9.4.92 cold scan).

## 3. New structure

- **New summary row** (`gui/mainwindow.cpp`, `gui/mainwindow.h`): `sumVerify_` / `sumValVerify_` after the dup-files row. Label `sumVerify` ("쌍검증 (전체/확정)" / "Pair verify (total/confirmed)"), value `"total / confirmed"` (e.g. `19234 / 15193`), `-` with no record.
- **Data source**: `onDetailedLog()` parses `matches.candidates` / `matches.pairs` from the same telemetry record into `lastVerifyTotal_` / `lastVerifyDone_`. The panel never depends on the dialog being opened or saved. Reset at scan/load start.
- **The finished message is untouched**: the positional-parsing contract stays.
- **Measurement record**: §7.2 added to `docs/architecture/database-verification-benchmark.{ko,en}.md` (0.9.4.94 Stable rescan example: 80 of 177,581 changed, wall 980.6 s = walk 347 s + verify 592 s, DBV-1 holds, 34 s fingerprint, Fast recommended). Fast/Auto measurements follow the same format from §7.3.
- Translation key `sumVerify` + `ui_translation_keys_test` key list (63 keys).

## 4. Result

- After a scan the summary panel shows pair-verify input (candidate pairs) and output (confirmed pairs) at a glance. `-` with no record.
- The Stable-rescan cost structure is preserved as a measurement example, with room reserved for per-setting follow-ups.
