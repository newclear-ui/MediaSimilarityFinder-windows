# MediaSimilarityFinder v0.9.2.86 — Fast pHash, Reveal Fallback, ffprobe DLLs

## Need for change
1. CPU pHash cost ~0.6ms per hash (direct-sum DCT), and mirror plus 6 crops always took the CPU path, hiding GPU gains.
2. `ffprobe.exe` raised system errors for missing `avdevice-63.dll` / `avfilter-12.dll`. Build outputs only carried the 5 directly linked libraries.
3. With no open Explorer window, "Reveal in Explorer" showed a status message and opened nothing.

## Previous structure
- `perceptual_hash()` recomputed 2·64·1024 cosines per hash; mirrors re-ran the DCT on flipped images.
- Build outputs shipped the ffmpeg tools without `avdevice`/`avfilter` DLLs.
- `revealPath()` did nothing on `NoWindow`.

## New structure
- Fast pHash (externally contributed patch, applied and verified): one-time cosine tables (thread-safe), separable DCT in the same order as the CUDA kernel, mirror via odd-horizontal-frequency sign flip yielding `normal`+`mirrored` from one DCT (`perceptual_hash_pair[_32]`). Three call sites changed (`media_pipeline`, `crop_fingerprint`, `video_fingerprint`); CUDA kernel untouched.
- `avdevice-*`/`avfilter-*` DLLs deployed to build outputs (globbed, ffmpeg-upgrade-proof). The portable package already carries all vcpkg bin DLLs (verified).
- `revealPath()`: reuse open windows first, open `explorer.exe /select` when none matches.
- Version strings unified → 0.9.2.86, DB version 1.0.1→1.0.2 (fingerprint-semantics diagnostic stamp), 57 tests.

## Resolved situation
- Bit-identical to legacy on natural, noisy, and non-32 inputs. Flat/symmetric patterns get deterministic hashes (0x7fff…) via the 1e-7 snap; stored hashes of such files persist until rescanned.
- Engine and video-cache versions unchanged: verdict rules identical, and the low-variance frame filter already excludes degenerate frames, so no cache invalidation is needed.

## Validation
- Core+GUI Release build: PASS, **CTest 57/57 PASS** (new `fingerprint_fast_test`; `cuda_backend_test`, `mirror_similarity_test`, `search_engine_test` included)
- `cuda_backend_test`: all 56 natural images bit-exact CPU vs GPU. Only synthetic lattice pattern #5 diverges (19 bits, root-caused below) → structured bound recalibrated to ≤24. Broken-kernel detection is preserved by the exact-match gate on natural images.
- Portable `--smoke`/`--version` exit 0, `avdevice`/`avfilter` confirmed bundled.

## Future impact
- No snap in the CUDA kernel (CUDA-invariance rule). Flat images may hash deterministically on CPU and noisily on GPU, a pre-existing class of mismatch with no natural-image impact. One kernel line could align them if desired.
- Stored hashes of flat/checkerboard files refresh only when those files are re-analyzed.
