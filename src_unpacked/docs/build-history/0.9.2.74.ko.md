# MediaSimilarityFinder v0.9.2.74 — 모니터 툴바 정리 (일시정지 삭제·토글 하이라이트·메뉴 우측)

## 변경 필요성
툴바 우측 모니터 2버튼의 역할 정리 요구: (1) 일시정지(⏸) 버튼의 용도 — 실시간 분석 일시중단(워처 유지). 시작/중지로 커버되는 중복 기능이라 삭제, (2) 모니터 버튼은 설정창 자동 오픈을 걷어내고 실행 여부 하이라이트 토글로, (3) 메뉴(☰) 버튼을 맨 오른쪽으로 이동·확대.

## 기존 구조
- `monBtn_` 토글 + 설정 미구성 시 `configureMonitor()` 자동 오픈. `monPauseBtn_` 별도 일시정지. 메뉴 버튼이 모니터 버튼 좌측에 소형 배치

## 변경 구조
- **일시정지 삭제**: 버튼·슬롯·멤버 제거. `MediaMonitor::setPaused` 엔진 API와 테스트는 유지 (향후 재노출 가능)
- **모니터 토글 순수화**: 설정 자동 오픈 제거, 미구성 시 상태 메시지로 안내. 체크 시 녹색 굵은 하이라이트 스타일
- **메뉴 우측 배치**: spacer 뒤로 이동해 항상 우측 고정. 폰트 +4·굵게·최소 46×32
- 버전 표기 통일 → 0.9.2.74

## 해결된 상황
- 툴바 버튼 1개 감소. 모니터 상태가 버튼 색으로 즉시 판별. 메뉴 접근성 향상
