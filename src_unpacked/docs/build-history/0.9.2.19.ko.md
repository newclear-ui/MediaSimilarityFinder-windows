# 0.9.2.19 — 중앙 크롭 기반 2차 후보 검색 기반

## 중요 변경

이미지에 대해 4:3, 1:1, 9:16 중앙 크롭 fingerprint를 생성하고 별도 CandidateIndex에 등록하는 기반을 추가했다. 원본 전체 fingerprint 검색을 통과하지 못하는 크롭본도 저비용 crop signature 후보 검색으로 2차 비교 대상이 될 수 있다.

### 변경 사항
- 원본 이미지의 실제 종횡비를 유지한 저해상도 디코드 경로 추가.
- 4:3 / 1:1 / 9:16 중앙 크롭을 32×32로 정규화해 pHash 생성.
- 각 크롭에 좌우 반전 fingerprint도 생성.
- SQLite에 6개 crop fingerprint 컬럼 추가 및 기존 DB 자동 마이그레이션.
- 이미지 crop CandidateIndex 3개를 추가해 전체 이미지 쌍 탐색 전에 후보를 축소.
- 실시간 Monitor도 동일한 crop fingerprint를 생성해 비교/인덱스 갱신에 사용.
- 최종 비교에서는 전체↔전체, crop↔전체, 동일 crop 비율 간 비교를 중심으로 평가해 서로 다른 crop 비율끼리의 불필요한 교차 비교를 줄였다.
- 동영상은 이번 단계에서 기존 fast normal/mirror 경로를 유지한다. 동영상 중앙 크롭은 후속 2단계 시간축 샘플링과 함께 구현한다.

## 설계 의도

모든 미디어에 무거운 임의 크롭 탐색을 수행하지 않는다. 이미지에서는 스캔 시 저비용 중앙 crop signature를 만들어 인덱싱하고, 실제 최종 유사도 계산은 후보에 대해서만 수행한다. 4:3, 1:1, 9:16을 우선 지원하며 향후 오프센터 crop은 별도 후보가 필요한 경우에만 추가한다.

## 검증

Linux Release core build 및 전체 테스트를 수행한다. CUDA/Qt6 Windows 런타임은 이 환경에서 검증하지 않는다.
