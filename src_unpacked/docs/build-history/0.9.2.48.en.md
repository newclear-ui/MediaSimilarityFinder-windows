# MediaSimilarityFinder v0.9.2.48 — No Console Window + Splitter Warning Fix

## Need for change
Launch opened a console window showing `QSplitter::setCollapsible: Index 0/1/2 out of range`. Two separate causes.

## Previous structure
- `qt_add_executable` without a subsystem setting linked as console subsystem → console window on launch, Qt warnings printed there
- `setCollapsible(0/1/2)` called before child widgets were added → three index warnings

## New structure
- `WIN32_EXECUTABLE TRUE` links the GUI subsystem. `--version`/`--help`/`--smoke` from a console use `AttachConsole(ATTACH_PARENT_PROCESS)` + `CONOUT$` reopening to keep working. Double-click launch has no console
- `setCollapsible` moved after `addWidget`. Warnings eliminated at the root
- Version strings unified → 0.9.2.48

## Resolved situation
- No console window on double-click. No Qt warnings. CLI flags keep working from consoles

## Validation
- Core Release build: PASS, **CTest 40/40 PASS**, `--smoke` exit 0, `--version` 0.9.2.48
- Subsystem check: confirm GUI (`subsystem 2`) via `dumpbin /headers`. Console popup absence needs on-machine confirmation

## Future impact
- Qt warnings are invisible without a console now; use `qInstallMessageHandler` or VS debug output on debug builds. Unrelated to the release log (`msf_scan.log`)
