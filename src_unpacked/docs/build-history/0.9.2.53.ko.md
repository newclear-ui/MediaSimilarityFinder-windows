# MediaSimilarityFinder v0.9.2.53 — 미리보기 토글 크래시 수정 + 탐색기식 타일 보기

## 변경 필요성
유사 그룹 보기 탭의 보기 메뉴에서 "미리보기 창으로 보기"를 클릭하면 프로그램이 크래시됐다. 동시에 Windows 탐색기의 타일 보기와 같은 표시 방식 요구가 있었다.

## 기존 구조
- 보기 메뉴 7종(0-5 아이콘/리스트/자세히 + 6 미리보기 토글). `groupViewChanged(6)`이 `rightPane_->setVisible()` 호출
- `rightPane_`는 `nullptr`으로 선언만 되고 어디서도 할당되지 않음 → 널 역참조 크래시

## 변경 구조
- **크래시 항목 삭제**: `viewPreview` 메뉴·문자열·idx 6 토글 분기·미사용 `rightPane_` 멤버 전부 제거. 기존 설정에 저장된 6은 타일로 자동 이행되어 크래시 없음
- **타일 보기 추가 (idx 6, 메뉴명 "타일")**: `TileDelegate(QStyledItemDelegate)` 신규. 320×76 타일에 48px 아이콘 좌측 + 3줄 라벨 우측(첫 줄 굵게), 선택/포커스 배경은 표준 `PE_PanelItemViewItem`, 체크박스는 표준 위치·메트릭으로 그려서 뷰 내장 히트테스트가 mark 토글을 그대로 처리
- 모드 전환 시 delegate/gridSize/iconSize를 함께 교체. 타일 외 모드는 `setGridSize(QSize())`로 자동 레이아웃 복귀, delegate `nullptr` 복원
- 버전 표기 통일 → 0.9.2.53

## 해결된 상황
- 보기 메뉴 클릭 크래시 원천 제거 (문제 코드 자체가 없어짐)
- 탐색기 타일과 같은 보기 방식 제공. 체크박스·선택·정렬·검색 필터 기존 동작 유지
