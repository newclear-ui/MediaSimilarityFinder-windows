# MediaSimilarityFinder v0.9.4.119 — Throughput display bases clarified (analysis-stage label + overall/new rates)

Baseline `0.9.4.118` -> this build `0.9.4.119`.
CPU CTest **123/123**, GPU CTest **124/124**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` unchanged.

## 1. Why it was needed

In the 0.9.4.118 field cross-check (06:40 session, a 177,781-file AB scan) the detailed-log summary showed two "throughput" values built on different bases under similar names.

- Images/videos line `throughput: 39.8 files/sec` = analyzed / analysis-stage time (`imageStageMs`)
- File line `(0.0 files/s)` = analyzed / total wall (`filesPerSec`) - a scan of 177,781 files reading as "0.0 files/s"

Both values are correct by definition, but the basis was invisible in the label and invited misreading (recorded in the cross-check report).

## 2. Previous structure

`showDetailedLogDialog` (gui/mainwindow.cpp) printed both numbers with no basis label. The JSON fields (`summary.filesPerSec` etc.) are a measurement contract and are deliberately unchanged.

## 3. New structure

- Images/videos label: `throughput` -> **`throughput (analysis stage)`** / `처리량(분석 단계)`.
- File line: `(overall X files/s · new Y files/s)` - **overall** = scanned/wall (how fast the scan actually ran), **new** = analyzed/wall (`filesPerSec`, newly analyzed per second). Two new translation keys (`detailLogRateOverall` / `detailLogRateNew`, list total **75**).
- Regression pin: `scan_detailed_log_acceptance_test` captures the rendered dialog text and checks (a) the analysis-stage label, (b) the overall/new labels, (c) `files/s` occurrences >= 4 (two from the images/videos `files/sec` prefix plus the new file line's two). The pre-fix text fails both checks by construction (no label; count 3).

## 4. What is fixed

- The basis is visible in the label itself: e.g. images `throughput (analysis stage): 39.8 files/sec`, file line `(overall 507.8 files/s · new 0.0 files/s)`.
- JSON, verdicts, and engine semantics are unchanged (display only).
