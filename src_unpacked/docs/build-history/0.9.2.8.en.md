# 0.9.2.8 — Build Log

## 0.9.2.7 → 0.9.2.8

**IMPORTANT:** First implementation stage of the resident system-tray real-time media duplicate monitor.

### Implemented
- Multiple watched folders and comparison roots
- Stable-file detector based on settled size/write time
- CPU, memory, and optional GPU load monitoring
- Deferred analysis when system load is high to protect foreground workloads
- Windows monitor thread runs at `THREAD_PRIORITY_LOWEST`
- Fingerprint comparison API backed by the existing persistent `MediaSearchEngine` index
- Real-time image and video fingerprint paths
- System-tray start/stop/configuration controls
- Match actions: open new file / reveal existing file / recycle new file / skip
- Skip decisions persisted using SHA-256 keys
- Self-comparison excluded when watch and comparison roots overlap

### Conservative design choice
Polling is the portable baseline in this version. Native Windows filesystem events and direct CandidateIndex reuse are planned for the next optimization stage.

### Verification
- 8/8 relevant regression tests passed
- CandidateIndex benchmark: N=6000, indexed 1708.25 ms, linear 5847.09 ms, about 3.42x
- CUDA toolkit was unavailable in the current build environment, so the CPU backend was used
- Qt6 Windows GUI and real NVIDIA GPU runtime remain unverified in this environment
