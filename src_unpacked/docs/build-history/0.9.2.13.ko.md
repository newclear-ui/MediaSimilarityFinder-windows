# MediaSimilarityFinder 0.9.2.13 — 빌드 기록

## 중요 변경
0.9.2.13은 상주 실시간 모니터에서 **사용자 작업 보호를 최우선으로 하는 부하 상태 기반 분석 게이트**를 도입한다.

### 변경 사항
- CPU/메모리/GPU 상태를 Idle / Light / Busy / Heavy / Critical로 분류한다.
- Gaming 모드에서는 더 큰 여유 자원을 확보하며 Light 상태에서도 실시간 분석을 시작하지 않는다.
- Balanced 이상에서도 현재 사용량에 안전 여유폭을 더해 분석 허용 여부를 판단한다.
- GPU가 비활성화된 경우 GPU 사용률을 분석 차단 조건으로 사용하지 않는다.
- Windows CPU/GPU 샘플 상태는 `SystemLoadMonitor` 인스턴스별로 유지한다.
- 부하 상태 판정과 정책 게이트 회귀 테스트를 추가한다.

### 설계 원칙
실시간 분석 속도보다 사용자의 게임/전경 작업 및 기존 시스템 부하에 대한 비간섭을 우선한다. 분석이 지연되는 것은 정상적인 보호 동작이며 대기 큐에서 재시도한다.

## 검증
- Linux Release core build
- 전체 회귀 테스트 통과 여부는 `BUILD_STATUS.md`에 기록한다.
- 실제 Windows/NVIDIA 환경의 부하 측정은 별도 검증이 필요하다.
