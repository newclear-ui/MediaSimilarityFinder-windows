# MediaSimilarityFinder v0.9.2.60 — Icon/List View Restore + Favorites Dedup + Color Previews

## Need for change
Three reports: (1) lists visible only in Tiles and Details; the 4 icon modes + List render blank, (2) recent scanned folders duplicated in favorites, (3) previews render grayscale-only.

## Previous structure
- (1) Tiles (v0.9.2.53) set a custom delegate and restored with `setItemDelegate(nullptr)`. Headless probe verdict: `nullptr` does NOT restore the default delegate — null visuals (-1x-1), whole mode blank. Matches exactly that Tiles (explicit delegate) and the tree (unaffected) worked
- (2) Recent folders appended without comparing against the fixed favorites (Downloads etc.) → same folder twice
- (3) Display relied on fingerprint grayscale: QImageReader failures (PNG etc., no qpng in portable) fell to WIC Gray; videos fell to gray FFmpeg frames on shell miss → monochrome

## New structure
- **Explicit delegate restore**: `defaultDelegate_ (QStyledItemDelegate)` set for icon/list/details modes. No `nullptr` restores remain. The probe (`view_mode_probe`) permanently guards the pattern
- **Favorites dedup**: skip recent entries matching any of the 6 standard paths (case-insensitive normalized compare). Missing folders skipped as before
- **Color display lanes**: new `ImageDecoder::decodeColorAspect` (WIC 32bppBGRA → ARGB32), new `VideoDecoder::frameAtColor` (FFmpeg RGB24 single frame). `fileThumb` image lane: QImageReader (color) → WIC color → file icon; video lane: shell (color) → RGB24 → file icon. Gray decoders stay fingerprint-only, removed from display
- New `color_thumb_test` (red BMP → red pixels; testsrc bars → colorful pixels). Version strings unified → 0.9.2.60

## Resolved situation
- Lists render in all 7 view modes. Tiles↔icons round-trip proven headlessly
- Favorites duplicates gone. PNG/video previews in color

## Validation
- Core+GUI Release build: PASS, **CTest 47/47 PASS** (incl. `color_thumb_test`, `view_mode_probe`)
- `--version` 0.9.2.60, `--smoke` exit 0 (offscreen)
- CUDA algorithms unchanged (common layers only)

## Future impact
- Never restore delegates via `nullptr` (probe watches). Keep explicit delegates when adding modes
- WIC color is Windows-only. Non-Windows keeps file icons (unchanged)
- Shipping more Qt plugins (qpng etc.) is a separate candidate (unneeded with WIC cover)
