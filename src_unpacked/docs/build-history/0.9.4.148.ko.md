# MediaSimilarityFinder v0.9.4.148 — 재검증 버튼 툴바 배치 누락 수정

기준선 `0.9.4.147` → 본 빌드 `0.9.4.148`.
CPU CTest **125/125**, GPU CTest **126/126**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` 불변 (표시 전용).

## 1. 변경 필요성

- 실기 제보: 재검증("재검증") 버튼이 주소 경로줄 뒤에 겹쳐 보인다.
- 원인: 0.9.4.134에서 버튼 객체(`reverifyBtn_`)를 생성하고 툴바 순서에도 쓰지 않아(`toolBar_->addWidget` 누락), 버튼이 레이아웃에 포함되지 않고 툴바 (0,0) 위치에 떠 있었다. 앞선 요소(폴더 경로 입력줄) 뒤에 가려져 일부만 보이는 상태였다.
- 실제 사용자는 버튼을 클릭할 수 없었으므로, 재검증 기능 자체가 GUI에서 도달 불가능했다.

## 2. 기존 구조

- 생성: `buildToolbar()`에서 `reverifyBtn_ = new QPushButton(...)` 후 `setObjectName`/`setToolTip`/`connect`까지 연결.
- 배치 누락: `toolBar_->addWidget(reverifyBtn_)` 호출이 없어 어떤 레이아웃에도 소속되지 않음.
- e2e(`backend_e2e_test` test1c)는 `findChild("reverifyBtn")`로 찾아 클릭하므로 레이아웃 여부와 무관하게 통과했고, 이 결함을 가리지 못했다.

## 3. 변경 구조

- `toolBar_->addWidget(reverifyBtn_)` 1줄 추가. 순서: 불러오기(Load) > 재검증 > 검색 시작(생성 순서 및 패널 데이터 흐름과 동일).
- 그 외 코드 변경 없음(시그널·enable/disable 로직은 이미 연결돼 있었음).

## 4. 해결된 상황

- 재검증 버튼이 툴바에 정상 배치되어 보이고 클릭 가능하다.
- 툴바 레이아웃 순서 단언을 `ui_settings_test`에 추가해 회귀를 방지한다(Load > 재검증 > 검색 시작).

## 5. 검증
