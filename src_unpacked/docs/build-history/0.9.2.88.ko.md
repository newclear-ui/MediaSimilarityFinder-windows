# MediaSimilarityFinder v0.9.2.88 — 탐색기 보기 근본 수정(CLSCTX_ALL)

## 변경 필요성
- “탐색기에서 보기”가 어떤 경우에도 경로를 열지 않았다. 상태바 메시지만 남고 새 창도 뜨지 않았다.
- 실제 Explorer 창을 띄워 `revealPath`를 검증하는 임시 프로브를 만들자 원인 2개가 드러났다.

## 기존 구조
- `revealInOpenExplorer()`가 `CoCreateInstance(..., CLSCTX_INPROC_SERVER, ...)`로 `IShellWindows`를 생성했다.

## 변경 구조
- `CLSCTX_INPROC_SERVER` → `CLSCTX_ALL`. ShellWindows는 out-of-proc(local server) 등록이라 INPROC 지정 시 `REGDB_E_CLASSNOTREG`로 항상 실패했고, `revealInOpenExplorer()`는 무조건 `Failed`를 반환했다. 그래서 열린 창 재사용도, `NoWindow` 폴백(새 창 열기)도 절대 동작하지 않았다.
- 임시 프로브를 정식 회귀 테스트 `reveal_window_test`로 승격했다: 새 폴더 폴백(창 생성+파일 선택 확인)과 기존 창 재사용(창 개수 불변·동일 HWND·선택 유지)을 실제 Explorer 창으로 검증한다. Windows 전용.
- 버전 표기 통일 → 0.9.2.88.

## 해결된 상황
- `reveal_window_test` PASS: 폴백으로 새 창이 열리며 파일이 선택되고, 재호출 시 같은 창이 재사용된다.
- 사용자가 겪은 “버튼 무반응”은 구 버전(.87 이전) 실행 때문이기도 했다. `.87` 이전에는 자가진단 경로 버그로 플러그인이 있어도 실패 대화상자가 떴다.

## 검증
