# MediaSimilarityFinder v0.9.2.69 — Toolbar Cleanup + Live Intermediate Results + Summary/Count Fixes

## Need for change
Twelve field reports from screenshots: (1) the toolbar "···" is Qt's overflow button (auto-created when crowded, not deletable) — crowding is the cause, (2) no intermediate results during scan/pause (critical), (3) the headline "n/m (100%)" denominator grows mid-walk, (4) summary shows only time+GPU, (5) delete-button naming, (6) detail path stretching, (7) no labels without selection, (8) long/short filename row misalignment.

## Previous structure
- Streaming: `refreshStreaming()` ran full `rebuildGroups()` every tick (outside the gate) + per-group SQLite disk reads + widget churn → paint starvation. Pause only set a dirty flag, delaying up to 3s behind the gate
- Counts: engine streaming total as denominator → grows mid-walk, spurious 100%
- Summary: `updateStatusCounts` refreshed groups/files/marks only, rest at finish

## New structure
- **Streaming restore**: `rebuildGroups()` moved inside the gate. Mid-scan fills decode real thumbs for the first 60 rows only; the rest get cheap file icons with no DB hit (the list itself always renders). Pause forces `refreshStreaming(true)` immediately
- **Fixed denominator**: worker pre-walk (same kind/ignore filters, engine-identical `isVideoExt`) emits target via `targetCount`. Headline becomes scanned/target, falling back when unknown. `scan_streaming_test` asserts target==4
- **Live summary**: total/done/groups/dups written live during scans. CPU/RAM stay with the monitor timer
- **Toolbar**: ⚙+☰ merged into one ☰ menu (monitor settings/help). Target menu renamed Photos/Videos; button label mirrors selection, bold when filtered. GPU checkbox shortened to "Monitor GPU" (full text in tooltip). CPU/GPU spins use prefix + "%" suffix. Presets carry % (Maximum 90% etc.). Folder input 240→200
- **Middle bar**: view button minimum 110×30, group search capped at 280, stretch removed
- **Delete**: renamed "Move to Trash" + trash icon (fileBar). Behavior unchanged: SHFileOperation with FOF_ALLOWUNDO already moved to Recycle Bin
- **Detail**: full path as a fixed two-line read-only field (wraps, drag-selectable, never stretches). All 9 labels show "-" with no selection
- **Right rows**: filename elision width set to the icon width (uniform cells)
- Version strings unified → 0.9.2.69

## Resolved situation
- Lists render live during scans and on pause (thumbs progressively from the top, file icons elsewhere). Per-tick caps keep paints and buttons responsive
- Fixed denominator makes % track truthfully. Five summary fields live. Trash naming matches behavior

## Validation
- Core+GUI Release build: PASS, **CTest 52/52 PASS** (incl. streaming target assertion)
- `--version` 0.9.2.69, `--smoke` exit 0 (offscreen)
- CUDA algorithms unchanged (common layers only)

## Future impact

- Post-60-row thumbs fill on pause/finish. Background decode threads remain the next candidate
- The "···" overflow returns if the toolbar crowds again. Check width budget when adding toolbar items
