# MediaSimilarityFinder v0.9.4.139 — EXE 아이콘 삽입 + 그룹 정렬 개편(그룹 크기·방향 선택, Load 후 잠금 해제)

기준선 `0.9.4.138` → 본 빌드 `0.9.4.139`.
CPU CTest **125/125**, GPU CTest **126/126**.
`kEngineVersion 1.5.1` / `kDatabaseVersion 1.0.6` / `kBenchmarkSchemaVersion 9` / `kCacheFormatVersion 9` 불변 (표시/패키징 전용).

## 1. 변경 필요성

- 실기 요청 (1): GUI와 Backend 실행 파일에 앱 아이콘이 없다(탐색기·작업관리자에 기본 아이콘). 후보 E2(`candidate_E2_photo_video_lens`)와 G(`candidate_G_split_cards`)를 채택해 **GUI=`app.ico`, Backend=`backend.ico`**를 EXE 리소스로 심고, 창/작업표시줄 아이콘도 같은 아트를 쓰게 한다.
- 실기 요청 (2): 정렬이 (a) Load 후 잠겨 사용자가 바꿀 수 없고, (b) 유사도/이름 두 종류뿐이며, (c) 오름/내림차순 선택이 없다. 또한 "그룹 파일 수(유사그룹 숫자)" 기준 정렬이 필요하다.

## 2. 기존 구조

- 정렬: `sortBox_` 단일 콤보(항목 없음/유사도/이름), 라벨에 방향이 박혀 있었음(`유사도 내림차순`, `이름 오름차순`). `loadLockSort_` 플래그가 Load/재검증 후 `updateSortEnabled()`에서 콤보를 비활성화했고, 스캔 시작 시에도 None으로 잠갔다.
- `rebuildGroups()`는 `kSortName`(paths[0] 오름차순)과 `kSortSim`(best 내림차순)만 처리.
- 아이콘: GUI는 `WIN32_EXECUTABLE TRUE`만, Backend는 콘솔 실행 파일. 리소스(.rc/.qrc) 없음.

## 3. 변경 구조

- **아이콘**: `resources/`에 `app.ico`(E2 256px 기반, 16/24/32/48/64/128/256 PNG 엔트리), `backend.ico`(G 256px 기반), `app_icon.rc`/`backend_icon.rc`(`IDI_APPICON`/`IDI_BACKENDICON`), `icons.qrc`(`:/icons/app.ico`) 추가. CMake GUI 타깃에 `.rc`+`.qrc`와 `AUTORCC ON`, Backend 타깃에 `.rc` 추가. `gui/main.cpp`에서 `QApplication::setWindowIcon(QIcon(":/icons/app.ico"))`로 창/작업표시줄 아이콘 설정(EXE와 동일 아트).
- **정렬**: 타입(`sortBox_`) + 방향(`sortDirBox_`) 분리. 상수 `kSortNone=0, kSortSize=1, kSortSim=2, kSortName=3`, 메뉴 순서 **없음 → 그룹 크기 → 유사도 → 이름**. 방향 콤보는 **내림차순(0)/오름차순(1)**.
  - 그룹 크기 = 그룹 구성 파일 수(`paths.size()`), 기본 내림차순(큰 그룹 먼저). 유사도 기본 내림차순, 이름 기본 오름차순 — 타입 변경 시 기본 방향 자동 적용, 사용자가 즉시 뒤집을 수 있다.
  - `rebuildGroups()` 비교자에 방향 반영, 동률은 경로 오름차순으로 안정 정렬. `None`에서는 방향 콤보 비활성.
  - **Load/재검증 잠금 제거**: `loadLockSort_` 삭제. Load는 여전히 초기 정렬을 None(저장 순서)로 두지만 사용자가 즉시 바꿀 수 있다. 스캔 중에는 기존대로 None 잠금(스트리밍 append 보존)이며 스캔 종료 시 이전 선택 복원.
- 번역 키 `sortSize`/`sortDesc`/`sortAsc` 추가, 기존 `sortSim`/`sortName` 라벨에서 방향 문구 제거. `sortBox`/`sortDirBox` objectName 추가(자동화 훅).

## 4. 해결된 상황

- 탐색기·작업관리자에서 두 EXE가 각자의 아트(E2/G)로 보인다. 창/작업표시줄도 동일 아트다.
- Load 직후에도 정렬을 바꿀 수 있고, 그룹 크기 기준 정렬과 오름/내림차순 선택이 가능하다.

## 6. 향후 영향 및 한계

- 표시/패키징 전용(판정·저장·프로토콜·engine/DB/schema/cache 불변).
- 그룹 크기 정렬은 "구성 파일 수" 기준이다(디스크 용량 합계 기준이 필요하면 별도 항목).
- 방향 기본값은 타입 변경 시 재설정된다(직전 방향 유지가 필요하면 후속 조정).
- 아이콘 원본/생성 스크립트는 작업 스크래치에 있으며, 저장소에는 최종 `.ico`/`.png`/`.rc`/`.qrc`만 포함한다.
