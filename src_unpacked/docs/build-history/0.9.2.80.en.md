# MediaSimilarityFinder v0.9.2.80 — Reference Tie-break (Resolution, then Size)

## Need for change
- Each similar group's reference file was ordered by `bestPct_` (highest similarity to any group member) only, so exact ties fell back to effectively arbitrary sort order.
- Promoting the requested resolution/size rule to first priority would let upscaled files outrank originals and let quality-unrelated size differences decide the representative.
- The compromise keeps similarity first and applies resolution-then-size only to exact ties.

## Previous structure
- `rebuildGroups()` sorted `g.paths` by `bestPct_` descending with no secondary rule.
- The reference (`paths[0]`) drives the group representative display, the 100% marker, and the representative thumbnail.

## New structure
- First key unchanged: `bestPct_` descending.
- Runs of exactly equal `bestPct_` are re-sorted by resolution pixel count descending, then file size descending.
- `filePixels()` parses the cached `fileResolution()` string (`WxH`); sizes reuse `fileSizeCached()`.
- Resolution/size lookups run only for tied-run members, avoiding unnecessary decoder/ffprobe calls.
- The ordering kernel is split out as the testable static `MainWindow::sortTiedReferencePaths()`.
- No matching-logic or CUDA algorithm changes. Version strings unified → 0.9.2.80.

## Resolved situation
- Different similarities behave exactly as before.
- On ties, the higher-resolution file becomes the reference; if resolutions also match, the larger file wins.
- "Detail" has no defined metric, so it stays a preview-time check, not a rule.

## Validation
- Core+GUI Release build: PASS, **CTest 56/56 PASS** (new `ui_reference_order_test`: 400px/9B > 400px/5B > 100px/10B > unknown/99B)
- `--version` 0.9.2.80, `--smoke` exit 0 (offscreen)

## Future impact
- Reference changes affect display/selection marking only, not automatic deletion. A separate keep-candidate marker is recommended if needed.
- Ties require exact `bestPct_` double equality; near-ties keep similarity order (by design).
