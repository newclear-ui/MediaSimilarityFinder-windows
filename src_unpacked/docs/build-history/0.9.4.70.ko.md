## 5. 검증

### §15 체크리스트 대조 (증거 포함)

1. index DB 직접 open/write: `thumbDb_` 멤버·open·put·prune·flush 전부 삭제됨 (grep 0건). Backend가 유일 writer.
2. thumbnail 경로 충돌 없음: GUI는 요청+memory cache만, 생성은 Backend만.
3. GUI thumbnail fallback 없음: shell/QImageReader/WIC/VideoDecoder 분기 전부 삭제됨. EXIF text tag만 잔류 (문자열 메타데이터).
4. BackendClient 동기 wait API 없음: 인터페이스에 waitFor 계열 없음 (grep 확인).
5. GUI thread waitFor/blocking read 없음: supervisor는 QTimer 에스컬레이션만 사용. 유일한 예외는 `shutdown()`의 3초 bounded msleep loop (앱 종료 경로, 문서화된 G3 예외, event pump 없음).
6. scan의 IPC 종속 없음: Backend write는 Qt 버퍼 비동기, MATCHES chunking, GUI는 절대 블로킹 대기 없음 (E2E 스캔 완료가 증명).
7. MATCHES/FINISHED/FAILED 유실 없음: chunking + overflow 시 drop 코드 없음. E2E rescan이 전량 전달을 증명.
8. old Backend 생존 중 spawn 없음: `spawn()` + `onRestartTimeout()` 양쪽 가드 (코드) + E2E에서 PID 순차 교체만 관측.
9. escalation 비차단: QTimer 기반 (shutdown() 문서화 예외 제외).
10. orphan 없음: Job Object KILL_ON_JOB_CLOSE (코드) + Backend stdin-EOF 자진 종료 (E2E SHUTTING_DOWN 경로로 실측됨: 파이프 종료 시 정상 종료 확인).
11. UTF-8/framing: `backend_ipc_test` 7 checks (UTF-8 경로 round-trip, malformed/oversize/protocol reject).
12. stale nonce 폐기: 코드 + E2E restart 폭풍 속 정상 동작으로 간접 증명.
13. Backend Qt 의존성: **dumpbin 실측 — Qt6Core.dll + turbojpeg만. Qt6Widgets/Qt6Gui 없음.**
14. Loopback/real 분리: unit GUI 테스트는 loopback 기본값 무수정 통과, `backend_e2e_test`만 실프로세스.
15. P1→P4 독립 검증: 각 버전이 CPU/GPU 전체 CTest 통과 후 릴리즈됨 (.67: 114/115, .68: 114/115, .69: 116/117, .70: 116/117).

### 숫자 확정 (E2E 실측 기반)

- heartbeat 1s / health timeout 10s (E2E: 5s 단축판에서도 false positive 0).
- READY timeout 15s (E2E: handshake ~1s, 여유 15x).
- restart 3회, backoff 2s/5s/10s (E2E Test 3a/3b에서 3회 소진 후 FAILED 확인).
- kill grace 3s / kill wait 5s / shutdown wait 3s.
- thumb 256px·200KB cap (실측 JPEG 수십KB, 여유 5x 이상).
- MATCHES 500/batch, RESULTS 2000/page (E2E·대규모 스캔 없이도 파이프 stall 0).
