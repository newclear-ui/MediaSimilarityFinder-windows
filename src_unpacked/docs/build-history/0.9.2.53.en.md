# MediaSimilarityFinder v0.9.2.53 — Preview-Toggle Crash Fix + Explorer-Style Tiles View

## Need for change
Clicking "Show preview pane" in the similar-groups view menu crashed the app. A Windows Explorer-style Tiles view was also requested.

## Previous structure
- 7 view modes (0-5 icons/list/details + 6 preview toggle). `groupViewChanged(6)` called `rightPane_->setVisible()`
- `rightPane_` was declared as `nullptr` and never assigned anywhere → null dereference crash

## New structure
- **Crash item removed**: `viewPreview` menu entry, string key, idx-6 toggle branch, and the unused `rightPane_` member all deleted. A previously saved 6 now lands on tiles instead of crashing
- **Tiles view added (idx 6, "Tiles")**: new `TileDelegate(QStyledItemDelegate)`. 320×76 tiles with a 48px icon on the left and the 3-line label on the right (first line bold), standard `PE_PanelItemViewItem` selection/focus background, check box painted at the standard leading position with standard metrics so the view's built-in hit testing keeps toggling marks
- Mode switches swap delegate/gridSize/iconSize together. Non-tile modes restore automatic layout via `setGridSize(QSize())` and a `nullptr` delegate
- Version strings unified → 0.9.2.53

## Resolved situation
- View-menu crash eliminated at the source (the offending code no longer exists)
- Explorer-like Tiles view added. Check boxes, selection, sorting, and search filter behave as before

## Validation
- Core+GUI Release build: PASS, **CTest 42/42 PASS**
- `--version` 0.9.2.53, `--smoke` exit 0 (offscreen)
- CUDA algorithms unchanged (common layers only)

## Future impact
- Tile size (320×76) and icon (48px) are fixed. Could follow the zoom slider if user control is wanted
- The same delegate pattern could unify preview rows in the file detail pane
