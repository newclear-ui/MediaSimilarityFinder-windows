# MediaSimilarityFinder v0.9.3.4 — 벤치마크 항상 기록·검색 로그 버튼·스크롤 개선

## 변경 필요성
1. 토글이 꺼져 있으면 로그 자체가 없어 팝업도, 나중에 볼 방법도 없었다.
   켜짐·꺼짐과 무관하게 검색 결과 로그를 확인할 수 있어야 했다.
2. 재검증 단계에서 중지하면 스캔이 시작되기 전이라 팝업이 전혀 뜨지 않았다.
3. 팝업이 뜨지 않을 경우를 대비해 로그를 수동으로 여는 버튼이 필요했다.
4. 스캔 종료 후 그룹창 스크롤이 끊기고 썸네일이 비어 있었다.

## 기존 구조
- 토글 OFF면 레코더를 시작하지 않아 `hasBenchmark()`가 거짓이었다.
- 재검증은 레코더 시작 전이라 조기 취소 경로에 확정할 데이터가 없었다.
- 그룹 그리드(`imgGrid_`/`vidGrid_`)에 균일 크기·배치 레이아웃이 없었다(파일 그리드는 있음).

## 변경 구조
- 스캔마다 항상 최소 기록한다. OFF여도 개수·시간 골격은 확정하고,
  샘플러·개별 항목·slowest 같은 상세만 건너뛴다. JSON `config.detail`로 구분하고
  팝업에 “상세 기록 꺼짐”을 표시한다. OFF 오버헤드는 사실상 0이다.
- 워커가 재검증 전에 레코더를 미리 시작한다. 조기 취소면 `abortBenchmark()`로
  0값 확정 후 팝업을 띄운다(토글 ON일 때).
- 툴바에 “검색 로그” 버튼을 추가했다. 로그가 있으면 활성화+하이라이트,
  없으면 비활성화(회색)다. 마지막 로그를 다시 연다.
- 그룹 그리드에 `setUniformItemSizes(true)` + `setLayoutMode(Batched)`를 적용해
  대량 행 스크롤 재배치를 줄였다.
- 버전 표기 통일 → 0.9.3.4.

## 해결된 상황
- 토글 상태와 무관하게 스캔이 끝나면 결과 로그를 볼 수 있다.
- 재검증 중지에도 빈 로그가 아닌 확정된 중단 로그 팝업이 뜬다.
- 스크롤이 배치 단위로 그려져 끊김이 준다.
