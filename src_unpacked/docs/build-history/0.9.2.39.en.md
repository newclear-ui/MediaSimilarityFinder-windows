# MediaSimilarityFinder v0.9.2.39 — Screenshot Feedback Round (Toolbar Cleanup, Folder Tab Removal)

## Need for change
The v0.9.2.38 on-machine screenshot review raised 4 items. The Settings/Help buttons overflowed into the toolbar `⋯` menu instead of sitting next to CPU/GPU, the refresh button had no text label, and the standalone folder icon button, the Folders tab, its browse/scan-here buttons, and the Mark/Space toolbar-bar item were judged unnecessary.

## Previous structure
Toolbar order: folder input, refresh (icon only), scan/pause/resume/stop, preset/CPU/GPU/GPU-check, monitor buttons, [stretch], settings/help (→ overflowed on narrow windows). Middle tabs: Folders/Images/Videos/Ignored. File action bar ended with a Mark/Space button.

## New structure
- Settings/Help buttons moved directly after the GPU checkbox (always visible before overflow). Monitor buttons stay after them
- Refresh button labeled: `🔄 새로고침` / Refresh (retranslated on language switch)
- Standalone 📁 folder icon button deleted (duplicates the `…` browse button)
- Folders tab deleted (Images/Videos/Ignored remain). Recent-folders UI removed with it. Folder selection unified to the top path edit + `…` button
- Mark/Space item removed from the file action bar (Space shortcut and context menu kept)
- Version strings unified → 0.9.2.39. Mockup B tab row updated the same way

## Resolved situation
- Settings/Help visible without overflow at 1536 px. Toolbar, tabs, and action bar match the review

## Validation
- Core Release build: PASS, **CTest 37/37 PASS**, `--smoke` exit 0, `--version` 0.9.2.39
- On-machine click behavior needs user-side confirmation

## Future impact
- Tab indices: 0=images, 1=videos, 2=ignored. The `QSettings(ui/recentFolders)` key is no longer written (leftover values harmless)
