# MediaSimilarityFinder v0.9.4.8 — Execution Binding + Node B7 Gate

Addresses the core finding of the external Node B review (against
v0.9.4.7) and closes the B7 final gate. Engine 1.5.0, DB 1.0.3, cache
v9, schema 1 unchanged.

## Why the change was needed
- Review verified: a `const bool schedUseGpu` pinned the scan-start
  verdict. Re-evaluations updated shares while execution kept the initial
  value, so telemetry and actual execution could diverge on a mid-scan
  flip.

## Previous structure
- One `decide()` → `const bool schedUseGpu` → image/video gates reused
  the same value for the whole scan.

## New structure
- A `schedUseGpuNow()` reader of the current published decision. Image
  batches read fresh right after re-evaluation; the video range reads
  once per range entry and captures the value into the async lambda. The
  stale const is deleted (grep-verified).
- Only B4-hold/B6-band-approved publications change, so execution cannot
  flap. Sub-2 s scans never re-evaluate: byte-identical behavior.
- `scan_streaming_test` gains an engine-level scheduler-record assertion
  (`scheduler.measured` + `selectedBackend`, no product change).
- B7 coverage audit:
  - Function (OFF/ON/fallback/modes/Manual) — existing suites plus
    scheduler_test. Slow-hardware and under-load Gaming execution cannot
    be reproduced deterministically: covered by units + parity (stated).
  - Stability (hold/band/long-run) — synthetic ticks. No wall-clock
    long test: unsuitable for CTest (stated).
  - Accuracy — parity suites on both trees.
  - Performance — wall/filesPerSec recorded in benchmark JSON; no
    comparative gate (environment-dependent, stated).
    `video_gpu_benchmark_test` exists.
  - Observability — measured scheduler section plus streaming assertion.

## Why this shape
- Closes inside B with no D upfront. Workers, queues, barriers untouched.
- The three stale-value connection points were consolidated around fresh reads through schedUseGpuNow().

## Resolved state
- Decision-execution divergence eliminated. Every B7 gate item is tied
  to evidence.

## Accuracy impact
- None. Short-scan behavior unchanged; long scans follow stabilized
  publications only. Identical `scan_workflow_test` on both trees.

## Compatibility impact
- Benchmark JSON keys unchanged, schemaVersion kept.

- GPU Release build PASS, **CTest 65/65 PASS**.
- `--version` 0.9.4.8 and `--smoke` PASS on both.

## Future impact
