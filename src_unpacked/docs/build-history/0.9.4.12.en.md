# MediaSimilarityFinder v0.9.4.12 — Node C4: Calibration Gate

Validation baseline for C4: no new features, the prompt's 17
combinations tied to evidence, Node C closed. Engine 1.5.0, DB 1.0.3,
cache v9, schema 2 unchanged.

## Why the change was needed
- C1–C3 evidence was scattered across version histories; the 17-gate
  coverage could not be checked at a glance. The audit found 2 gaps.

## Previous structure
- The failed-candidate acceptance rule was an inline condition in the
  engine lambda (untestable). Long Exact reuse had no explicit assertion.

## New structure
- New `calibrationUsableForUpdate()` helper: the identical rule the
  engine used. The lambda now calls it (behavior identical).
- C4 assertions: 10-run Exact silence, failed/partial rejection,
  file-untouched reload after failure, usable-candidate pass.
- 17-combination mapping (see Validation). No verdict or policy changes.

## Why this shape
- A gate connects evidence; it adds no features. Code change is one
  minimal testability extraction.

## Resolved state
- Node C done. Next gate D.
