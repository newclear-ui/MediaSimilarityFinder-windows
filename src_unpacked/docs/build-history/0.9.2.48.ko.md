# MediaSimilarityFinder v0.9.2.48 — 콘솔 창 제거 + 스플리터 경고 수정

## 변경 필요성
실행 시 콘솔 창이 함께 뜨고, 그 안에 `QSplitter::setCollapsible: Index 0/1/2 out of range` 메시지가 출력됐다. 두 가지 다른 원인이다.

## 기존 구조
- `qt_add_executable`에 서브시스템 지정이 없어 콘솔 서브시스템으로 링크 → 실행 시 콘솔 창 생성, Qt 경고가 그리로 출력
- `setCollapsible(0/1/2)`를 자식 위젯 추가 전에 호출 → 인덱스 없음 경고 3건

## 변경 구조
- `WIN32_EXECUTABLE TRUE`로 GUI 서브시스템 링크. 콘솔에서 실행한 `--version`/`--help`/`--smoke`는 `AttachConsole(ATTACH_PARENT_PROCESS)` + `CONOUT$` 재연결로 출력 유지. 더블클릭 실행 시에는 콘솔 없음
- `setCollapsible`를 `addWidget` 이후로 이동. 경고 원천 제거
- 버전 표기 통일 → 0.9.2.48

## 해결된 상황
- 더블클릭 실행 시 콘솔 창 없음. Qt 경고 없음. CLI 플래그는 콘솔에서 그대로 동작

## 검증
- Core Release 빌드 PASS, **CTest 40/40 PASS**, `--smoke` exit 0, `--version` 0.9.2.48
- 서브시스템 확인: `dumpbin /headers`에서 GUI(`subsystem 2`) 확인 예정. 콘솔 팝업 여부는 실머신에서 확인 필요

## 향후 영향
- Qt 경고는 이제 콘솔이 없어 보이질 않으니, 디버그 빌드에서는 `qInstallMessageHandler`나 VS 디버그 출력으로 확인. 릴리스 로그(`msf_scan.log`)와 무관
