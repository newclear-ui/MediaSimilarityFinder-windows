# MediaSimilarityFinder v0.9.2.37 — UI 피드백 반영 (설정 내 언어, 그룹 보기 전환, 키보드 mark)

## 변경 필요성
v0.9.2.36 UI 리뷰에서 4건이 지적됐다. Language 콤보가 툴바에 노출되어 있고, 2번째 화면에 탐색기식 보기 전환이 없고, 3분할 크기 조절 상태가 저장되지 않으며, 검색 결과 화면에서 방향키+Space mark가 동작하지 않았다(파일 화면 전용이었다).

## 기존 구조
- 툴바에 Language 콤보 상시 표시, 설정 팝업은 단일 화면(언어 행 + 모니터 항목 혼재)
- 가운데 그룹 화면 = `QTreeWidget` 자세히 보기 단일 모드, 체크박스 없음
- `QSplitter` 크기 고정(복원 없음)
- Space 단축키 = 파일 mark 전용

## 변경 구조
- 툴바에서 Language 콤보 제거. 설정 팝업을 `QTabWidget`(일반/모니터)으로 분리하고 언어 선택은 **일반 탭**으로 이동. 저장 시 즉시 전환
- 가운데 화면에 보기 전환 콤보 추가: **아주 큰 아이콘(256)/큰 아이콘(128)/보통(64)/작은(32)/리스트/자세히**. 아이콘·리스트 모드는 `QListWidget`(대표 썸네일+그룹명·파일수·유사도%), 자세히는 기존 `QTreeWidget`. `QStackedWidget` 전환, 선택 동기화, `QSettings(ui/groupView)` 저장
- 그룹 행/아이템에 체크박스 추가 (전체 mark=Checked, 일부=PartiallyChecked). 체크 변경 시 그룹 전체 파일 mark 반영
- Space 포커스 인식: 가운데 화면에 포커스가 있으면 **그룹 전체 mark 토글**, 파일 화면이면 기존 파일 mark. 방향키는 네이티브 위젯 이동 그대로 사용
- `QSplitter` 좌우 이동 + 상태 저장/복원 (`QSettings(ui/splitter)`). 상단 컴퓨팅 자원 선택(프리셋/CPU·GPU 스핀/GPU 체크)은 기존 유지
- 목업 갱신: `uimock/mockup-A-ko-grid.html` (보기 콤보 + 설정 팝업 목업), `mockup-C-en-grid.html` (툴바 언어 제거 + 보기 콤보)
