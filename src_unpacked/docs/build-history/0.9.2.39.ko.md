# MediaSimilarityFinder v0.9.2.39 — 실행 화면 피드백 반영 (툴바 정리, 폴더 탭 삭제)

## 변경 필요성
0.9.2.38 실머신 스크린샷 리뷰에서 4건이 지적됐다. 설정/도움말 버튼이 툴바 오버플로(`⋯`)로 밀려나 CPU/GPU 옆에 보이지 않았고, 새로고침 버튼에 글자가 없었으며, 폴더 아이콘 버튼·폴더 탭·폴더 탭의 찾아보기/이 폴더로 검색 버튼·파일 액션바의 Mark/Space 항목이 불필요하다고 판단됐다.

## 기존 구조
툴바 순서: 폴더입력…새로고침(아이콘のみ)·검색/일시정지/계속/중지·프리셋/CPU/GPU/GPU체크·모니터/일시정지…[여백]…설정/도움말(→창이 좁으면 오버플로). 가운데 탭: 폴더/결과:이미지/결과:비디오/무시 목록. 파일 액션바에 Mark/Space 버튼.

## 변경 구조
- 설정/도움말 버튼을 GPU 체크박스 바로 뒤로 이동 (오버플로 전 항상 표시). 모니터 버튼은 그 뒤 유지
- 새로고침 버튼에 글자 추가: `🔄 새로고침` (언어 전환 시 갱신)
- standalone 📁 폴더 아이콘 버튼 삭제 (`…` 찾아보기 버튼과 중복)
- 폴더 탭 삭제 (결과:이미지/결과:비디오/무시 목록 3탭). 최근 폴더 목록 UI도 함께 제거. 폴더 선택은 상단 경로 입력+`…` 버튼으로 일원화
- 파일 액션바에서 Mark/Space 항목 삭제 (Space 단축키·컨텍스트 메뉴는 유지)
- 버전 표기 통일 → 0.9.2.39. 목업B 탭 행도 동일하게 정리
