# MediaSimilarityFinder v0.9.2.65 — Video L1 Multi-Anchor + Variant Dedup Fix

## Need for change
Externally reported and code-confirmed structural defects: (1) whole-video frame hashes collapsed into one XOR 64-bit value, dropping re-encoded similars at candidacy; (2) `CandidateIndex` marked groups seen before the distance check, dropping mirror/crop variant matches. Direct causes of "3 hours, 0 results".

## Previous structure
- Single XOR `MediaFile.fingerprint` → one `videoIdx_` entry. Re-encode drift kills candidacy outright
- `forEachCandidatePair` marked groups even on failing variants, skipping passing variants in the same bucket
- Crop seeding inserted everything regardless of distance, excluding crop-only pairs from the crop stage

## New structure
- **Frame anchors**: `MediaFile.anchors` (read-only `loadPersistent` cache reads, never decoded, strided cap 16). Attached when `files_` is built in `scan()`; `analyze()` registers them into `videoIdx_` under the same index. Verdicts stay with existing `best()`+temporal, so false-positive structure is unchanged
- **Anchor gate**: when `best()` misses, max anchor-anchor similarity at/above trigger earns temporal verification (which must still pass threshold to yield)
- **Dedup order fix**: mark after passing the distance check; seed only passing pairs. Re-evaluation of identical pairs is meaningless (`best()` is deterministic per file pair)
- Cleanup: unused header `ScanCancelled` removed, `saveMatches` comment corrected to union semantics, 3 dead members (`matches_`, `lastDone_`, `lastTotal_`) removed
- Version strings unified → 0.9.2.65

## Resolved situation
- Re-encoded pairs: anchor collision enumerates → anchor gate runs temporal → match on temporal pass. Single-XOR-gate misses eliminated
- Mirror variants no longer blocked by failing variants (negative control: exit 30 pre-fix → pass post-fix)
- Crop-only pairs evaluated correctly in the crop stage

## Validation
- Core+GUI Release build: PASS, **CTest 49/49 PASS** (`scan_pipeline_test` extended with dedup + anchor-enumeration cases)
- `--version` 0.9.2.65, `--smoke` exit 0 (offscreen)
- CUDA algorithms unchanged (common layers only)

## Future impact
- Cache-miss videos degrade gracefully to XOR-only candidacy. Cache version bumps restore anchors via full rebuild
- Anchor cap 16 and 1024 poll interval tunable
- Grok L3 (thumb96+SSIM) can now layer on top of this L1
