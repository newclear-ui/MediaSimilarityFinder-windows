# 0.9.2.33-test — Windows CPU 테스트 중간판 (기준선 아님)

## 변경 필요성
v0.9.2.32 공식 기준선을 유지한 채 실제 Windows + Visual Studio 18 2026 + MSVC 환경에서 CPU 빌드/테스트를 수행하고, 플랫폼 공통 호환성 문제를 수집해야 했다.

## 기존 구조
Linux에서 검증된 0.9.2.32 기준선만 존재하고, Windows MSVC/Qt/FFmpeg/SQLite 경로의 실제 동작 검증 기록이 없었다.

## 변경 구조
Windows CPU 구성(`MSF_ENABLE_CUDA=OFF`)으로 configure/build/ctest를 수행하고, 발견된 공통 계층 문제(SQLite target, `NOMINMAX`/WIC/Qt, `M_PI`, FFmpeg 9 API, UTF-8 filesystem, `ReadDirectoryChangesW`, `std::popcount`, `SystemLoad` 충돌)를 정리했다. CUDA 알고리즘/커널은 변경하지 않았다.

## 해결된 상황
수집된 공통 수정 항목은 다음 검증선인 v0.9.2.34에 반영되었다. 0.9.2.33 자체는 별도 배포 기준선으로 유지하지 않는다.

## 검증
Windows CPU 환경에서 빌드/테스트 수행. 상세 공통 수정 내용은 `0.9.2.34.ko.md`를 참조한다.

## 향후 영향
이후 Windows 검증은 0.9.2.34를 기준으로 CPU→CUDA 순서로 수행한다. 공식 보존 기준선은 0.9.2.32로 유지한다.
