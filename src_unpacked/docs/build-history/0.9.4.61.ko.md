## 1. 변경 필요성

유사그룹 목록을 아래로 이동하면 느려지고 최상단으로 되돌아갔다.
원인은 anchor가 아니라 파괴 자체였다. `thumbStarved_` 하나만으로 매 tick
`tree->clear()/grid->clear()` 후 전체 재생성이 일어났고, 스크롤 드래그
순간에 widget tree가 파괴되면 anchor 복원도 안전하지 않았다.

## 2. 기존 구조

- `refreshStreaming()`: `force || thumbStarved_ || (신규 match)` 조건에서
  무조건 `rebuildGroups() + refreshGroupList()` (전체 재생성)
- `groupsDirty_`는 tick 시작 때 무조건 cleared → scroll-gated tick이
  있으면 데이터 변경이 유실될 수 있는 구조
- `matchSeq_/lastFillSig_`는 streaming 경로에서만 갱신 → 직접 refill
  (scanFinished 등) 뒤 첫 tick이 중복 rebuild

## 3. 변경 구조

- full rebuild는 group 데이터 변경 때만 (`groupsDirty_ || matchSeq_` advance).
  `thumbStarved_` 단독으로는 rebuild하지 않는다
- `thumbCatchUpVisible()`: 보이는 grid item의 icon만 `setIcon()` in-place
  갱신. viewport 범위 + 기존 thumb budget으로 bounded. 변경된 아이콘만
  교체 (cacheKey 비교). tree는 썸네일이 없어 스킵
- scroll gate: scrollbar `sliderPressed` 동안 + wheel/키보드 navigation 후
  500ms cooldown 동안 full rebuild 지연. 입력은 절대 block하지 않고
  rebuild만 다음 tick으로 미룸. `setValue/scrollToItem` 같은 프로그램
  이동은 `sliderPressed`를 발생시키지 않아 gate에 걸리지 않음
- `groupsDirty_` 정리는 `rebuildGroups()` 단일 지점 (직접 finish 경로 포함).
  `lastFillSig_/lastFillMs_` 갱신은 `refreshGroupList()` 단일 지점
- 0.9.3.10 anchor 코드는 그대로 유지 (구조적 rebuild의 최후 복구 수단)
- test-only 카운터 `fullRebuildCount_/thumbInPlaceCount_` + `testUiTick()`.
  telemetry/benchmark schema 노출 없음

## 4. 해결된 상황

- thumbnail catch-up N회 → full rebuild 0, 아이콘은 in-place로 채워짐
- group 데이터 변경 → full rebuild 1회 (한 번만, gate·interval 준수)
- 스크롤 위치·선택·위젯 identity가 tick 후에도 그대로 유지
- slider drag 중 tick이 와도 rebuild 0, 드래그 위치 유지

## 6. 향후 영향

- 스크롤 중 rebuild 금지는 `scrollGateActive()` 단일 조건. 향후 middle-pane
  구조 변경 시 이 gate를 유지해야 함
- 직접 refill 호출자 (sort/search/tab/ignore/finish)는 gate 대상이 아님.
  사용자 명시 조작에 대한 즉시 반영이므로 현 구조 유지. timer 경로의
  비자발 rebuild만 gate함
- 관측 (별도 작업 필요, 본 빌드 범위 밖): gradient 계열 픽스처에서 수천
  cross-match가 한 번에 stream되자 fill 이후 크래시 관측 (0xC0000005).
  엔진 단독 240-file 스캔은 정상이므로 GUI 측 match-storm 규모 문제로
  보이며, 재현·축소·별도 지시가 필요. scroll 회귀와는 다른 버그로 분리 기록
- 다음: S4 실제 화면 manual acceptance (offscreen 검증의 한계),
  `color_thumb` R1 (별도 작업)
