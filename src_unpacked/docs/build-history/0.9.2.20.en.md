# MediaSimilarityFinder 0.9.2.20

## IMPORTANT CHANGE
Refined the second-stage image Crop-Aware similarity comparison.

### Changes
- Treat 4:3, 1:1, and 9:16 crop fingerprints as separate aspect-ratio groups.
- Preserve Full ↔ Crop comparisons.
- Restrict Crop ↔ Crop comparisons to the same aspect-ratio group.
- Prevent unrestricted 4:3 ↔ 1:1, 1:1 ↔ 9:16, etc. crop-to-crop comparisons to reduce false positives.
- Preserve mirror-aware comparison independently for each crop ratio.
- Align candidate retrieval semantics with final similarity semantics.

### Tests
- Full CTest: 33/33 PASS
- Strengthened crop fingerprint regression tests.
- Added Crop-Aware SearchEngine candidate retrieval coverage.
- Added regression coverage ensuring cross-ratio crop-only matches are not accepted.
- Existing mirror, video, monitor, and GPU policy tests all pass.

## Preserved
- Video remains on the fast normal + mirror path from 0.9.2.19.
- Monitor foreground-workload protection/load gating is unchanged.
- Actual Windows Qt6 GUI and NVIDIA CUDA runtime remain unverified in this Linux test environment.
