# MediaSimilarityFinder 0.9.2.23

## IMPORTANT CHANGE

**Reduced decode overhead for the video Temporal Crop-Aware second stage and added real-time Monitor telemetry.**

### Changes

- Added `VideoDecoder::framesAt()` for multiple timestamps in one operation.
  - FFmpeg builds seek once to the first requested timestamp and decode forward sequentially.
  - Existing `frameAt()` now delegates to the new API.
- Optimized `VideoFingerprintEngine::build()`.
  - The 32×32 normal/mirror pass and 96×96 crop pass are now sequential decode passes instead of repeated timestamp seeks.
- `buildCropAware()` now uses one batch decode for its requested timestamps.
- Preserved the command-line FFmpeg fallback when FFmpeg is not linked.
- Added Monitor telemetry:
  - last analysis duration (ms)
  - average analysis duration (ms)
  - last analysis kind (image/video)
- Existing Load Protection and expensive-stage guard behavior remains enforced.

## Validation

- `msf_core` Release build succeeded.
- 4/4 focused regression tests passed:
  - video_crop_similarity_test
  - video_similarity_test
  - video_sampling_test
  - monitor_load_policy_test
- The full 34-test CTest suite was not completed because the environment reached the command time limit while building the remaining test targets. This release is therefore not labeled as a full-suite PASS.
