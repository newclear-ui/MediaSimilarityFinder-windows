# 이미지 Burst Shot 유사 판정 — 알고리즘 한계와 1.0 이후 고도화 계획

상태: **DEFERRED (post-1.0)**. v1.0 완성 전까지는 현행 동작을 유지한다.
코드 변경 없음. 본 문서는 분석 기록과 향후 계획의 기준이다.

## 1. 현상

동일 인물·동일 배경의 연속 촬영(burst shot) 2장이 유사율 95.8%로 같은
유사그룹에 묶였다. 두 파일은 바이트가 다르므로 별개 파일이지만, 제품의
유사 판정에서는 같은 그룹이 된다.

## 2. 현재 알고리즘의 한계

이미지 판정은 2단계다 (`src/similarity.cpp`, `src/image_verify.cpp`).

- L1: 64비트 pHash Hamming 유사율 `100*(64-다른비트수)/64` + 거리 gate.
- L2/L3: Hamming < 97.0이면 64×64 그레이 + 3종 crop(4:3·1:1·9:16) 10개
  윈도우 SSIM 최댓값과 혼합: `0.5×Hamming + 0.5×(100×SSIM)`.

95.8%는 1.5625의 배수가 아니므로 fast path가 아니라 검증 경로의 값이다.
즉 pHash가 3~5비트 어긋나고 SSIM이 ~0.96~0.99로 나왔다는 뜻이다.
포즈가 살짝 바뀌면 DCT 계수 몇 개가 뒤집히고, 배경이 같으니 SSIM은 1에
가깝다. 두 지표 모두 "전체 구조가 같은가"를 보므로, **동일 장면의 포즈
차이는 어느 지표에서도 감쇠되지 않는다**. 이것이 현재 구조의 한계다.

임계값(검색 거리)을 엄격하게 하면 해당 쌍은 분리되지만, 리인코드·리사이즈
같은 진성 near-duplicate도 함께 분리될 수 있다. 임계값 외에는 burst를
가려내는 수단이 현재 구조에 없다.

## 3. 대응 필요 사항 (1.0 이후)

동일 연사의 다른 포즈와, 리인코드·동일 사진 workers를 구분해야 한다.
"같은 burst인데 포즈가 다르다"와 "재부호화된 동일 사진"은 픽셀 통계상
겹치는 영역이 커서, 임계값 조정만으로는 깨끗이 갈라지지 않는다.

## 4. 계획: 설정 옵션 + 이중 알고리즘 선택 검색

v1.0 이후 다음을 구현한다 (본 문서 작성 시점에는 미구현).

1. **프로그램 설정에 옵션 추가**: 유사이미지 검색 시 burst 샷을 유사이미지로
   판단하지 않는 on/off 옵션. 기본값은 현행 동작 유지(하위 호환).
2. **현재 알고리즘 + 개선 알고리즘의 2중화**: 옵션에 따라 현행 pHash+SSIM
   경로 그대로, 또는 burst 분리를 강화한 strict 경로(예: full-full SSIM
   중심, 전 윈도우 하한 요구 등 — 상세 설계는 착수 시 확정)로 선택 검색.
3. 얼굴 랜드마크 같은 별도 모델 기반 판정은 후보로만 유지한다. 저장소에
   ML 모델 의존성이 없어 도입 비용이 크므로, 1차 개선은 기존 지표의
   조합·게이트 강화로 시도한다.
