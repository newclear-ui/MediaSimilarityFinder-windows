# CandidateIndex BK-tree snapshot — 0.9.2.25

This directory preserves the exact active `CandidateIndex` implementation from 0.9.2.25 before the 0.9.2.26 Multi-Index Hash replacement.

The files are documentation/history snapshots only. They are **not compiled by CMake** and are intentionally kept outside `src/`.

Reason for preservation: when a major architecture is replaced, the old implementation should remain inspectable for debugging, regression analysis, and future design comparison without leaving dead code in the active build.

Replacement version: 0.9.2.26.
