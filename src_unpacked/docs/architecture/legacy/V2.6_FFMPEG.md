# v2.6 FFmpeg backend
Adds an optional FFmpeg-backed VideoDecoder. The public API remains independent
of FFmpeg. When FFmpeg development libraries are available, CMake enables
MSF_HAS_FFMPEG and the decoder reads video metadata, seeks to requested
timestamps, decodes frames, scales them to 64x64 grayscale, and returns pixels.
When FFmpeg is not installed, the portable reference backend remains available
for fast core tests.
