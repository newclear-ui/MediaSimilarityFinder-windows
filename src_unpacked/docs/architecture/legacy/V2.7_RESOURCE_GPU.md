# v2.7 Resource/GPU layer
Adds four runtime resource modes:
1 Maximum: CPU/GPU 100%
2 Balanced: CPU 60%, GPU 70%
3 Light: CPU 30%, GPU 35%
4 Custom: user-selected 5-100%

The policy is runtime data rather than hard-coded worker behavior, so the
future UI can change it while a scan is running. GpuBackend provides a stable
CUDA/NVIDIA detection and batch-hash API; the current fallback executes the
same algorithm on CPU. NVDEC/CUDA kernels are the next performance step.
